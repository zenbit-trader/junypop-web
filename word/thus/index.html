thusคำวิเศษณ์

/ðʌs/ · ระดับ B2

ธัส

ดังนั้น (ทางการ)

ตัวอย่างประโยค

Costs fell, and thus profits rose.

ต้นทุนลด ด้วยเหตุนี้กำไรจึงเพิ่ม

จุดที่คนไทยพลาดบ่อย

thus — thus = therefore แบบสั้นและเป็นทางการ ใช้ในรายงานมากกว่าพูด — thus far = จนถึงตอนนี้ (so far)

คำอื่นในบทเดียวกัน (คำเชื่อมและกริยาทางการ)

  • in order to เพื่อที่จะ
  • provided that โดยมีเงื่อนไขว่า
  • regardless of โดยไม่คำนึงถึง
  • as well as รวมทั้ง / และยัง
  • in the event of ในกรณีที่เกิด
  • meanwhile ในขณะเดียวกัน
  • implement นำไปปฏิบัติ / เริ่มใช้จริง
  • accommodate รองรับ(จำนวน/ความต้องการ)
  • ensure ทำให้แน่ใจว่า / รับรองว่า
  • acquire ได้มา / ซื้อกิจการ
  • anticipate คาดการณ์ล่วงหน้า
  • accordingly ตามนั้น / อย่างสอดคล้องกัน
  • nevertheless ถึงกระนั้นก็ตาม

จำ thus ให้ติดด้วยการเล่น
