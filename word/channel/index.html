channelคำนาม

/ˈtʃænəl/ · ระดับ A2

แชน-แนล

ช่อง (ยูทูบ/สตรีม)

ตัวอย่างประโยค

His channel has funny game videos.

ช่องของเขามีคลิปเกมฮาๆ เพียบ

จุดที่คนไทยพลาดบ่อย

channel — ช่องทีวีและช่องยูทูบใช้ channel เหมือนกัน — เปิดช่องของตัวเอง = start a channel

คำอื่นในบทเดียวกัน (สตรีมและแชท)

  • stream สตรีม / ถ่ายทอดสด
  • streamer สตรีมเมอร์
  • live ถ่ายทอดสด / ไลฟ์
  • viewer ผู้ชม
  • chat แชท / คุยกัน
  • comment คอมเมนต์ / ความคิดเห็น
  • follower ผู้ติดตาม
  • subscribe กดติดตามช่อง
  • clip คลิปวิดีโอ
  • highlight ช่วงเด็ด / ไฮไลต์
  • donate โดเนท / บริจาค
  • emote อีโมท / ท่าแสดงอารมณ์ในเกม
  • go viral ดังเป็นไวรัล

จำ channel ให้ติดด้วยการเล่น

ทบทวนคำนี้พร้อมอีก 98 คำในหมวดเกมมิ่ง ฟรี ไม่ต้องติดตั้ง
