nobleคำคุณศัพท์

/ˈnoʊbl/ · ระดับ B2

โน-เบิล

สูงส่ง / มีคุณธรรม

ตัวอย่างประโยค

The noble knight gave his last coin to the beggar.

อัศวินผู้สูงส่งมอบเหรียญสุดท้ายของเขาให้ขอทาน

จุดที่คนไทยพลาดบ่อย

noble — noble = มีคุณธรรมสูงส่ง (a noble cause = จุดประสงค์อันสูงส่ง) และ = ชนชั้นสูง/ขุนนาง (a noble family) — รางวัล Nobel สะกดต่างกันและเน้นเสียงพยางค์หลัง

คำอื่นในบทเดียวกัน (บรรยายนิสัยตัวละคร)

  • modest ถ่อมตัว / ไม่โอ้อวด
  • reckless บุ่มบ่าม / ไม่ระวัง
  • cowardly ขี้ขลาด
  • ruthless โหดเหี้ยม / ไร้ความปรานี
  • talented มีพรสวรรค์
  • stern เข้มงวด / เคร่งขรึม
  • timid ขี้กลัว / ไม่กล้าแสดงออก
  • cunning เจ้าเล่ห์
  • cautious ระมัดระวัง / รอบคอบ
  • courageous องอาจ / กล้าหาญมาก
  • innocent บริสุทธิ์ / ไร้เดียงสา
  • mysterious ลึกลับ
  • wealthy ร่ำรวย / มั่งคั่ง
