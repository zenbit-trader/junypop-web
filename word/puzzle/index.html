Puzzle games make you think.

เกมปริศนาช่วยฝึกสมองให้คิด

จุดที่คนไทยพลาดบ่อย

puzzle — จิ๊กซอว์ = jigsaw puzzle — รู้สึกงงๆ ก็พูดได้ว่า I'm puzzled (ฉันงง)

คำที่มักสับสนกับ puzzle

  • pizza พิซซ่า
  • puddle แอ่งน้ำขังบนพื้น
  • muscle กล้ามเนื้อ

คำอื่นในบทเดียวกัน (เลือกแนวเกม)

  • genre แนวเกม / ประเภท
  • action แนวแอ็กชัน / ฉากบู๊
  • racing แนวแข่งรถ / แข่งความเร็ว
  • shooting game เกมยิง
  • horror แนวสยองขวัญ
  • sports game เกมกีฬา
  • strategy แนววางแผน / กลยุทธ์
  • role-playing แนวสวมบทบาท / RPG
  • simulation แนวจำลองชีวิต
  • arcade เกมตู้ / อาร์เคด
  • board game บอร์ดเกม / เกมกระดาน
  • casual เล่นง่ายๆ สบายๆ
  • mobile game เกมมือถือ
