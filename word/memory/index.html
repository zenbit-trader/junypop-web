memoryคำนาม

/ˈmeməri/ · ระดับ A2

เมม-เมอ-รี่

หน่วยความจำ / เมมโมรี่

ตัวอย่างประโยค

My phone is out of memory again.

มือถือฉันเมมเต็มอีกแล้ว

จุดที่คนไทยพลาดบ่อย

memory — out of memory / full memory = ความจำเต็ม และ memory ยังแปลว่าความทรงจำ เช่น good memories (ความทรงจำดีๆ)

คำที่มักสับสนกับ memory

  • battery แบตเตอรี่
  • history ประวัติศาสตร์

คำอื่นในบทเดียวกัน (แกดเจ็ตไอที)

  • mobile phone โทรศัพท์มือถือ
  • charger สายชาร์จ / ที่ชาร์จ
  • battery แบตเตอรี่
  • power bank พาวเวอร์แบงก์ / แบตสำรอง
  • warranty การรับประกัน
  • model รุ่น (สินค้า)
  • screen หน้าจอ
  • wireless ไร้สาย
  • gadget แกดเจ็ต / อุปกรณ์ไอทีชิ้นเล็ก
  • accessory อุปกรณ์เสริม
  • phone case เคสมือถือ
  • earbuds หูฟังไร้สายแบบใส่ในหู
  • smartwatch นาฬิกาอัจฉริยะ / สมาร์ทวอทช์

จำ memory ให้ติดด้วยการเล่น
