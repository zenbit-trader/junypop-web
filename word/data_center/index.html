data centerคำนาม

/ˈdeɪtə ˌsentər/ · ระดับ B1

เด-ตา เซน-เตอร์

ศูนย์ข้อมูล / ตึกเก็บเซิร์ฟเวอร์

ตัวอย่างประโยค

The company opened a data center near Bangkok last year.

บริษัทเปิดศูนย์ข้อมูลใกล้กรุงเทพฯ เมื่อปีที่แล้ว

จุดที่คนไทยพลาดบ่อย

data center — data center = ตึกที่วางเซิร์ฟเวอร์เป็นพันเครื่อง คลาวด์ทุกเจ้าทำงานจากที่นี่ — สะกด center (อเมริกัน) หรือ centre (อังกฤษ) ได้ทั้งคู่

คำที่มักสับสนกับ data center

  • database ฐานข้อมูล

คำอื่นในบทเดียวกัน (ข้อมูลและคลาวด์)

  • database ฐานข้อมูล
  • cloud คลาวด์ / เก็บข้อมูลบนอินเทอร์เน็ต
  • backup ข้อมูลสำรอง
  • spreadsheet ตารางคำนวณ (Excel)
  • dashboard แดชบอร์ด / หน้าสรุปข้อมูล
  • analytics การวิเคราะห์ข้อมูล / สถิติการใช้งาน
  • storage พื้นที่เก็บข้อมูล
  • API ช่องทางให้โปรแกรมคุยกัน
  • query คำสั่งค้นหาข้อมูล
  • big data บิ๊กดาต้า / ข้อมูลมหาศาล
  • cache แคช / ข้อมูลที่เก็บไว้ให้โหลดเร็ว
  • real-time แบบทันที / ตามเวลาจริง
  • archive เก็บเข้าคลัง / ย้ายไปเก็บถาวร
