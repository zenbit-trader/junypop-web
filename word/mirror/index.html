จุดที่คนไทยพลาดบ่อย

mirror — mirror = กระจกเงา (ส่องดูตัวเอง) ส่วนกระจกหน้าต่างคือ glass อย่าใช้สลับกัน

คำที่มักสับสนกับ mirror

  • glass แก้วน้ำ
  • window หน้าต่าง

คำอื่นในบทเดียวกัน (ซื้อเสื้อผ้า)

  • size ขนาด / ไซซ์
  • small เล็ก / ไซซ์ S
  • medium กลาง / ไซซ์ M
  • large ใหญ่ / ไซซ์ L
  • try on ลอง (เสื้อผ้า/รองเท้า)
  • fit พอดี (ขนาด)
  • tight คับ / แน่น
  • loose หลวม
  • color สี
  • style สไตล์ / แบบ
  • brand ยี่ห้อ / แบรนด์
  • fashion แฟชั่น
  • sweater เสื้อกันหนาวไหมพรม / สเวตเตอร์
