จุดที่คนไทยพลาดบ่อย

import — im (เข้า) + port = นำเข้า — ของนำเข้า = imported goods มักราคาแพงกว่าเพราะบวกภาษี

คำที่มักสับสนกับ import

  • export ส่งออก
  • report แจ้งความ / รายงาน

คำอื่นในบทเดียวกัน (ค้าขายทั่วโลก)

  • expand ขยายกิจการ
  • branch สาขา
  • export ส่งออก
  • wholesale ขายส่ง
  • retail ขายปลีก
  • supplier ซัพพลายเออร์ / ผู้ส่งวัตถุดิบ
  • factory โรงงาน
  • warehouse โกดัง / คลังสินค้า
  • stock สต็อกสินค้า
  • shipment สินค้าที่จัดส่ง / ล็อตส่งของ
  • demand ความต้องการซื้อ / ดีมานด์
  • supply ปริมาณสินค้า / ซัพพลาย
  • global ระดับโลก
