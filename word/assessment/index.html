assessmentคำนาม

/əˈsesmənt/ · ระดับ B2

อะ-เซส-เมนท์

การวัดผล(การเรียน)

ตัวอย่างประโยค

Continuous assessment is fairer than one final exam.

การวัดผลอย่างต่อเนื่องยุติธรรมกว่าการสอบปลายภาคครั้งเดียว

จุดที่คนไทยพลาดบ่อย

assessment — assessment = การประเมินความรู้/ความสามารถ กริยา assess — เถียงเรื่อง exams vs continuous assessment ใน Task 2 ได้ทั้งสองฝั่ง

คำที่มักสับสนกับ assessment

  • assignment งานที่ได้รับมอบหมาย
  • agreement ข้อตกลง / สัญญา

คำอื่นในบทเดียวกัน (การศึกษา)

  • curriculum หลักสูตร
  • tuition ค่าเล่าเรียน
  • academic ทางวิชาการ
  • literacy การอ่านออกเขียนได้
  • rote learning การเรียนแบบท่องจำ
  • discipline วินัย / สาขาวิชา
  • undergraduate นักศึกษาปริญญาตรี
  • postgraduate นักศึกษาระดับสูงกว่าปริญญาตรี
  • vocational สายอาชีพ
  • peer เพื่อนรุ่นเดียวกัน / คนระดับเดียวกัน
  • motivate สร้างแรงจูงใจ
  • distance learning การเรียนทางไกล
  • dropout ผู้ออกจากการเรียนกลางคัน

จำ assessment ให้ติดด้วยการเล่น
