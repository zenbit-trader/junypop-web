digitคำนาม

/ˈdɪdʒɪt/ · ระดับ B1

ดิ-จิท

หลัก / ตัวเลขหลักเดียว (0–9)

ตัวอย่างประโยค

A Thai phone number has ten digits.

เบอร์โทรศัพท์ไทยมีสิบหลัก

จุดที่คนไทยพลาดบ่อย

digit — digit = ตัวเลขหนึ่งตัว 0–9 (a 6-digit code = รหัส 6 หลัก) — digital ก็มาจากคำนี้ เพราะคอมพิวเตอร์ทำงานด้วยเลข 0 และ 1

คำที่มักสับสนกับ digit

  • digital ดิจิทัล
  • decimal ทศนิยม

คำอื่นในบทเดียวกัน (ตัวเลขใหญ่และลำดับที่)

  • zero ศูนย์
  • dozen โหล (สิบสอง)
  • hundred ร้อย
  • thousand พัน
  • million ล้าน
  • billion พันล้าน
  • number ตัวเลข / จำนวน
  • count นับ
  • first ที่หนึ่ง / แรก
  • second ที่สอง
  • third ที่สาม
  • fifth ที่ห้า
  • twentieth ที่ยี่สิบ
