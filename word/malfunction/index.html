malfunctionคำกริยา

/ˌmælˈfʌŋkʃn/ · ระดับ B2

แมล-ฟังค์-ชั่น

ทำงานผิดปกติ / ขัดข้อง

ตัวอย่างประโยค

The printer began to malfunction after the power cut.

เครื่องพิมพ์เริ่มทำงานผิดปกติหลังไฟดับ

จุดที่คนไทยพลาดบ่อย

malfunction — mal- = ไม่ดี + function = ทำงาน; เป็นคำนามได้ (a malfunction) — ใน Part 3 มักเป็นสาเหตุที่ต้องโทรเรียกช่าง

คำที่มักสับสนกับ malfunction

  • function ฟังก์ชัน / ชุดคำสั่งที่เรียกใช้ซ้ำได้

คำอื่นในบทเดียวกัน (การผลิตและคุณภาพ)

  • manufacture ผลิต(ในโรงงาน)
  • assembly line สายการประกอบ
  • inspect ตรวจสอบอย่างละเอียด
  • defect ข้อบกพร่อง / ตำหนิ(ในสินค้า)
  • durable ทนทาน
  • raw material วัตถุดิบ
  • machinery เครื่องจักร(โดยรวม)
  • output ผลผลิต / ปริมาณที่ผลิตได้
  • standard มาตรฐาน
  • efficient มีประสิทธิภาพ(ไม่สิ้นเปลือง)
  • shortage การขาดแคลน(สินค้า/แรงงาน)
  • component ชิ้นส่วนประกอบ
  • recall เรียกคืนสินค้า

จำ malfunction ให้ติดด้วยการเล่น
