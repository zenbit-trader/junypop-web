liabilityคำนาม

/ˌlaɪəˈbɪləti/ · ระดับ B2

ไล-อะ-บิ-ลิ-ที

ความรับผิด(ตามกฎหมาย) / หนี้สิน

ตัวอย่างประโยค

The company accepts no liability for lost items.

บริษัทไม่รับผิดชอบต่อสิ่งของที่สูญหาย

จุดที่คนไทยพลาดบ่อย

liability — liability = ความรับผิดทางกฎหมาย (liability insurance) และในบัญชี = หนี้สิน ตรงข้าม asset — liable for = ต้องรับผิดต่อ

คำอื่นในบทเดียวกัน (นโยบายและกฎระเบียบ)

  • policy นโยบาย
  • guideline แนวทางปฏิบัติ
  • mandatory บังคับ / ต้องทำ
  • compliance การปฏิบัติตามกฎ
  • violation การฝ่าฝืน / ละเมิด
  • restrict จำกัด / ควบคุมไม่ให้เกิน
  • code of conduct จรรยาบรรณ / ระเบียบความประพฤติ
  • impose กำหนด(ภาษี/ค่าปรับ)ให้ต้องรับ
  • strictly อย่างเคร่งครัด
  • exempt ได้รับยกเว้น
  • sanction มาตรการลงโทษ
  • disclose เปิดเผย(ข้อมูล)
  • in accordance with ตามที่กำหนดใน

จำ liability ให้ติดด้วยการเล่น
