reactคำกริยา

/riˈækt/ · ระดับ B1

รี-แอค

แสดงความรู้สึกด้วยไอคอนอารมณ์

ตัวอย่างประโยค

Everyone reacted to her news with a heart.

ทุกคนกดหัวใจให้ข่าวของเธอ

จุดที่คนไทยพลาดบ่อย

react — กริยาคือ react คำนามคือ reaction — คนไทยพูดทับศัพท์ว่ากดรีแอค

คำที่มักสับสนกับ react

  • reach จำนวนคนที่เห็นโพสต์

คำอื่นในบทเดียวกัน (ไลก์และรีแอค)

  • like กดถูกใจ
  • emoji อีโมจิ รูปหน้าแสดงอารมณ์
  • sticker สติกเกอร์
  • repost โพสต์ซ้ำ เอาของคนอื่นมาลงต่อ
  • quote ยกโพสต์คนอื่นมาแล้วเขียนความเห็นเพิ่ม
  • thread ชุดโพสต์ที่ต่อกันเป็นเรื่องเดียว
  • poll โพลสำรวจความเห็น
  • bookmark บันทึกเก็บไว้ดูทีหลัง
  • screenshot ภาพถ่ายหน้าจอ
  • swipe ปัดหน้าจอซ้ายขวา
  • double-tap แตะสองครั้งเร็ว ๆ (เพื่อกดไลก์)
  • timeline ไทม์ไลน์ หน้ารวมโพสต์เรียงตามเวลา
  • trending กำลังมาแรง ติดอันดับคนพูดถึง

จำ react ให้ติดด้วยการเล่น
