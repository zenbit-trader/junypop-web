locationคำนาม

/loʊˈkeɪʃn/ · ระดับ A2

โล-เค-ชั่น

ตำแหน่งที่อยู่ (ตอนนี้)

ตัวอย่างประโยค

Tell the operator your exact location first.

บอกตำแหน่งที่อยู่ของคุณให้เจ้าหน้าที่ก่อนเป็นอย่างแรก

จุดที่คนไทยพลาดบ่อย

location — location = จุดที่คุณอยู่ตอนนี้ สิ่งแรกที่ต้องบอกเวลาโทรฉุกเฉิน — ไม่รู้ที่อยู่? บอกชื่อถนน ร้านใกล้ๆ หรือแชร์ location จากมือถือ (share my location)

คำที่มักสับสนกับ location

  • vacation วันหยุดพักผ่อน
  • local ท้องถิ่น / คนท้องถิ่น

คำอื่นในบทเดียวกัน (โทรขอความช่วยเหลือ)

  • emergency number เบอร์โทรฉุกเฉิน
  • call for help ร้องขอความช่วยเหลือ
  • operator เจ้าหน้าที่รับสาย
  • hotline สายด่วน
  • stay calm ใจเย็นไว้ / ตั้งสติ
  • stay on the line ถือสายรอ อย่าวางสาย
  • emergency contact ผู้ติดต่อกรณีฉุกเฉิน
  • describe บรรยาย / อธิบายลักษณะ
  • rescue ช่วยชีวิต / กู้ภัย
  • victim ผู้ประสบเหตุ / เหยื่อ
  • unconscious หมดสติ
  • breathing การหายใจ
  • panic ตื่นตระหนก
