featureคำนาม

/ˈfiːtʃər/ · ระดับ A2

ฟี-เจอร์

ฟีเจอร์ / ฟังก์ชันการใช้งาน

ตัวอย่างประโยค

The best feature is that it works offline.

ฟีเจอร์ที่ดีที่สุดคือใช้ได้แบบออฟไลน์

จุดที่คนไทยพลาดบ่อย

feature — feature = ความสามารถหนึ่งอย่างของแอป ส่วน function = การทำงานในเชิงเทคนิค — new feature ออกมาใน update และ feature request = ลูกค้าขอให้เพิ่มฟีเจอร์

คำที่มักสับสนกับ feature

  • future อนาคต
  • figure ตัวเลข (สถิติ) / จำนวนเงิน

คำอื่นในบทเดียวกัน (ซอฟต์แวร์และแอป)

  • software ซอฟต์แวร์ / โปรแกรม
  • app แอปพลิเคชัน
  • operating system ระบบปฏิบัติการ
  • interface หน้าจอการใช้งาน / ส่วนติดต่อผู้ใช้
  • version เวอร์ชัน / รุ่น
  • compatible ใช้ร่วมกันได้ / รองรับ
  • default ค่าเริ่มต้น / ค่าตั้งต้น
  • plugin ปลั๊กอิน / ส่วนเสริมโปรแกรม
  • sync ซิงก์ / ทำให้ข้อมูลตรงกันทุกเครื่อง
  • permission สิทธิ์การเข้าถึง / การอนุญาต
  • open source โอเพนซอร์ส / เปิดโค้ดให้ใช้ฟรี
  • upgrade อัปเกรด / เปลี่ยนเป็นรุ่นดีขึ้น
  • user-friendly ใช้งานง่าย
