จุดที่คนไทยพลาดบ่อย

project — เน้นพยางค์แรกเมื่อเป็นคำนาม "พรอ-เจ็คท์" — คนคุมโปรเจกต์ = project manager (PM) ตำแหน่งยอดฮิตในไทย

คำที่มักสับสนกับ project

  • product สินค้า / ผลิตภัณฑ์

คำอื่นในบทเดียวกัน (งานประจำวัน)

  • work ทำงาน
  • task งาน (ชิ้นหนึ่ง)
  • deadline กำหนดส่งงาน / เดดไลน์
  • busy ยุ่ง
  • schedule ตารางงาน / กำหนดการ
  • priority สิ่งสำคัญอันดับแรก
  • finish ทำเสร็จ
  • submit ส่งงาน (อย่างเป็นทางการ)
  • check ตรวจสอบ
  • solve แก้ปัญหา
  • overtime การทำงานล่วงเวลา / โอที
  • break พักเบรก
  • day off วันหยุด (ของเรา)

จำ project ให้ติดด้วยการเล่น
