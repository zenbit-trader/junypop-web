place an orderวลี

/pleɪs ən ˈɔːrdər/ · ระดับ A2

เพลส แอน ออร์-เดอร์

สั่งซื้อสินค้า

ตัวอย่างประโยค

You can place an order online or by phone.

คุณสั่งซื้อได้ทางออนไลน์หรือโทรศัพท์

จุดที่คนไทยพลาดบ่อย

place an order — place an order ไม่ใช่ make an order — คู่กับ fill an order = จัดของตามคำสั่งซื้อ และ cancel an order = ยกเลิก

คำอื่นในบทเดียวกัน (คำสั่งซื้อและใบแจ้งหนี้)

  • purchase order ใบสั่งซื้อ
  • quotation ใบเสนอราคา
  • merchandise สินค้า(ที่วางขาย)
  • retailer ผู้ค้าปลีก
  • payment terms เงื่อนไขการชำระเงิน
  • wire transfer การโอนเงินผ่านธนาคาร
  • prepaid ชำระล่วงหน้าแล้ว
  • discrepancy ความไม่ตรงกัน(ของตัวเลข)
  • surcharge ค่าธรรมเนียมเพิ่ม
  • net สุทธิ(หลังหักแล้ว)
  • itemized แยกรายการ(ทีละชิ้น)
  • backorder สินค้าสั่งจองรอของเข้า
  • remit ส่งเงินชำระ

จำ place an order ให้ติดด้วยการเล่น
