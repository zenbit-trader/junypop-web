จุดที่คนไทยพลาดบ่อย

animation — animation คือตัวงาน ส่วนคนทำเรียก animator — การ์ตูนญี่ปุ่นเรียกเฉพาะว่า anime

คำอื่นในบทเดียวกัน (แนวหนัง)

  • comedy หนังหรือละครแนวตลก
  • drama หนังหรือละครแนวชีวิตเข้มข้น
  • romance หนังหรือนิยายแนวรัก
  • thriller หนังแนวระทึกขวัญ
  • sci-fi แนววิทยาศาสตร์ล้ำยุค
  • fantasy แนวจินตนาการ เวทมนตร์
  • mystery แนวปริศนาสืบสวน
  • superhero ยอดมนุษย์ ซูเปอร์ฮีโร่
  • documentary สารคดี
  • based on a true story สร้างจากเรื่องจริง
  • plot เนื้อเรื่อง โครงเรื่อง
  • plot twist จุดหักมุมของเรื่อง
  • main character ตัวละครหลัก
