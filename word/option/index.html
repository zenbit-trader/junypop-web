optionคำนาม

/ˈɑːpʃn/ · ระดับ B1

อ็อพ-ชั่น

ตัวเลือก

ตัวอย่างประโยค

Only one option is correct, so read all four.

มีเพียงตัวเลือกเดียวที่ถูก ดังนั้นอ่านให้ครบทั้งสี่ข้อ

จุดที่คนไทยพลาดบ่อย

option — option = ตัวเลือก a–d ในข้อสอบ (answer options/choices) — เทคนิค: ตัวเลือกที่มีคำว่า always, never, all, only มักผิด เพราะบทความไม่ค่อยพูดสุดโต่งขนาดนั้น

คำที่มักสับสนกับ option

  • opinion ความคิดเห็น
  • portion ปริมาณต่อจาน / หนึ่งที่

คำอื่นในบทเดียวกัน (คำสั่งในข้อสอบ)

  • choose เลือก
  • complete เติมให้สมบูรณ์ / ทำให้เสร็จ
  • blank ช่องว่าง (ให้เติมคำ)
  • underline ขีดเส้นใต้
  • correct ถูกต้อง
  • incorrect ไม่ถูกต้อง / ผิด
  • according to ตามที่ (…กล่าว)
  • the following ต่อไปนี้ / ดังต่อไปนี้
  • except ยกเว้น
  • synonym คำที่มีความหมายเหมือนกัน
  • antonym คำที่มีความหมายตรงข้าม
  • true or false ถูกหรือผิด (ข้อสอบแบบ T/F)
  • open-ended ปลายเปิด / อัตนัย
