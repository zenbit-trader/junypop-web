จุดที่คนไทยพลาดบ่อย

highlight — high + light = จุดที่เด่นที่สุด — ไฮไลต์บอล ไฮไลต์เกม คนไทยใช้ตรงกับฝรั่งเป๊ะ ปากกาเน้นข้อความก็ชื่อ highlighter

คำอื่นในบทเดียวกัน (สตรีมและแชท)

  • stream สตรีม / ถ่ายทอดสด
  • streamer สตรีมเมอร์
  • live ถ่ายทอดสด / ไลฟ์
  • viewer ผู้ชม
  • chat แชท / คุยกัน
  • comment คอมเมนต์ / ความคิดเห็น
  • follower ผู้ติดตาม
  • subscribe กดติดตามช่อง
  • channel ช่อง (ยูทูบ/สตรีม)
  • clip คลิปวิดีโอ
  • donate โดเนท / บริจาค
  • emote อีโมท / ท่าแสดงอารมณ์ในเกม
  • go viral ดังเป็นไวรัล
