cloudคำนาม

/klaʊd/ · ระดับ A2

คลาวด์

คลาวด์ / เก็บข้อมูลบนอินเทอร์เน็ต

ตัวอย่างประโยค

All our files live in the cloud, not on one computer.

ไฟล์ทั้งหมดของเราอยู่บนคลาวด์ ไม่ได้อยู่ในคอมเครื่องเดียว

จุดที่คนไทยพลาดบ่อย

cloud — the cloud = เซิร์ฟเวอร์ของคนอื่นที่เราเช่าผ่านเน็ต (Google Drive, iCloud) — ใช้ in the cloud ไม่ใช่ on the cloud และ cloud storage = พื้นที่เก็บไฟล์บนคลาวด์

คำที่มักสับสนกับ cloud

  • crowd ฝูงชนผู้ชม
  • cloudy มีเมฆมาก

คำอื่นในบทเดียวกัน (ข้อมูลและคลาวด์)

  • database ฐานข้อมูล
  • backup ข้อมูลสำรอง
  • data center ศูนย์ข้อมูล / ตึกเก็บเซิร์ฟเวอร์
  • spreadsheet ตารางคำนวณ (Excel)
  • dashboard แดชบอร์ด / หน้าสรุปข้อมูล
  • analytics การวิเคราะห์ข้อมูล / สถิติการใช้งาน
  • storage พื้นที่เก็บข้อมูล
  • API ช่องทางให้โปรแกรมคุยกัน
  • query คำสั่งค้นหาข้อมูล
  • big data บิ๊กดาต้า / ข้อมูลมหาศาล
  • cache แคช / ข้อมูลที่เก็บไว้ให้โหลดเร็ว
  • real-time แบบทันที / ตามเวลาจริง
  • archive เก็บเข้าคลัง / ย้ายไปเก็บถาวร
