moduleคำนาม

/ˈmɑːdʒuːl/ · ระดับ B1

มอด-ดูล

วิชาย่อยในหลักสูตร (อังกฤษ)

ตัวอย่างประโยค

Each module is worth fifteen or thirty credits.

วิชาย่อยแต่ละวิชามีค่าสิบห้าหรือสามสิบหน่วยกิต

จุดที่คนไทยพลาดบ่อย

module — module = วิชาหนึ่งในหลักสูตรของมหาวิทยาลัยอังกฤษ (เทียบกับ course ของอเมริกา) — ปีหนึ่งเรียนราว 120 credits ประกอบด้วย 6–8 modules

คำที่มักสับสนกับ module

  • model รุ่น (สินค้า)
  • molecule โมเลกุล

คำอื่นในบทเดียวกัน (ลงทะเบียนเรียน)

  • course วิชา / รายวิชา
  • credit หน่วยกิต
  • elective วิชาเลือก
  • compulsory วิชาบังคับ / ภาคบังคับ
  • register ลงทะเบียน (เรียน)
  • syllabus ประมวลรายวิชา
  • academic year ปีการศึกษา
  • advisor อาจารย์ที่ปรึกษา
  • minor วิชาโท
  • core course วิชาแกนของสาขา
  • drop ถอนวิชา
  • course catalog คู่มือรายวิชาทั้งหมด
  • coursework งานเก็บคะแนนระหว่างเทอม

จำ module ให้ติดด้วยการเล่น
