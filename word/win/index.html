winคำกริยา

/wɪn/ · ระดับ A1

วิน

ชนะ

ตัวอย่างประโยค

We won the match in the last minute!

เราชนะแมตช์ในนาทีสุดท้าย!

จุดที่คนไทยพลาดบ่อย

win — win-won-won — ระวัง: ชนะ "ใคร" ใช้ beat (I beat my brother) ไม่ใช่ win my brother!

คำอื่นในบทเดียวกัน (สู้เพื่อชัยชนะ)

  • lose แพ้
  • victory ชัยชนะ
  • defeat เอาชนะ / ความพ่ายแพ้
  • challenge ความท้าทาย / คำท้า
  • opponent คู่แข่ง / ฝ่ายตรงข้าม
  • rank แรงค์ / อันดับ
  • tournament ทัวร์นาเมนต์ / การแข่งขัน
  • champion แชมป์
  • prize รางวัล
  • high score คะแนนสูงสุด
  • level up เลเวลอัป / อัปเลเวล
  • practice ฝึกซ้อม
  • improve เก่งขึ้น / พัฒนา
