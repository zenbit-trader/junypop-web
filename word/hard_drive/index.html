hard driveคำนาม

/ˈhɑːrd draɪv/ · ระดับ A2

ฮาร์ด ไดรฟ์

ฮาร์ดดิสก์ / ที่เก็บข้อมูลในเครื่อง

ตัวอย่างประโยค

My hard drive is full, so I deleted old videos.

ฮาร์ดดิสก์เต็มแล้ว ฉันเลยลบวิดีโอเก่าทิ้ง

จุดที่คนไทยพลาดบ่อย

hard drive — คนไทยเรียกฮาร์ดดิสก์ ฝรั่งเรียก hard drive (หรือ HDD/SSD) — ที่เก็บข้อมูลภายนอกเรียก external hard drive

คำที่มักสับสนกับ hard drive

  • hardware ฮาร์ดแวร์ / อุปกรณ์คอมพิวเตอร์

คำอื่นในบทเดียวกัน (อุปกรณ์และเครือข่าย)

  • hardware ฮาร์ดแวร์ / อุปกรณ์คอมพิวเตอร์
  • device อุปกรณ์ / เครื่อง
  • network เครือข่าย
  • router เราเตอร์ / ตัวกระจายสัญญาณ
  • modem โมเด็ม
  • cable สายเคเบิล / สายไฟ
  • port ช่องเสียบ / พอร์ต
  • bandwidth แบนด์วิดท์ / ความกว้างช่องสัญญาณ
  • hotspot ฮอตสปอต / จุดแชร์เน็ตจากมือถือ
  • Bluetooth บลูทูธ
  • USB ยูเอสบี / แฟลชไดรฟ์
  • processor หน่วยประมวลผล / ซีพียู
  • Ethernet อีเทอร์เน็ต / เน็ตแบบสาย LAN
