bandwidthคำนาม

/ˈbændwɪdθ/ · ระดับ B2

แบนด์-วิดธ์

แบนด์วิดท์ / ความกว้างช่องสัญญาณ

ตัวอย่างประโยค

Video calls use a lot of bandwidth, so the internet feels slow.

วิดีโอคอลกินแบนด์วิดท์เยอะ เน็ตเลยรู้สึกช้า

จุดที่คนไทยพลาดบ่อย

bandwidth — ในออฟฟิศฝรั่งยังใช้เปรียบเทียบคน: "I don't have the bandwidth" = ไม่มีเวลา/แรงพอจะรับงานเพิ่ม — เป็นคำปฏิเสธงานแบบสุภาพ

คำที่มักสับสนกับ bandwidth

  • bandage ผ้าพันแผล
  • width ความกว้าง

คำอื่นในบทเดียวกัน (อุปกรณ์และเครือข่าย)

  • hardware ฮาร์ดแวร์ / อุปกรณ์คอมพิวเตอร์
  • device อุปกรณ์ / เครื่อง
  • network เครือข่าย
  • router เราเตอร์ / ตัวกระจายสัญญาณ
  • modem โมเด็ม
  • cable สายเคเบิล / สายไฟ
  • port ช่องเสียบ / พอร์ต
  • hotspot ฮอตสปอต / จุดแชร์เน็ตจากมือถือ
  • Bluetooth บลูทูธ
  • USB ยูเอสบี / แฟลชไดรฟ์
  • hard drive ฮาร์ดดิสก์ / ที่เก็บข้อมูลในเครื่อง
  • processor หน่วยประมวลผล / ซีพียู
  • Ethernet อีเทอร์เน็ต / เน็ตแบบสาย LAN
