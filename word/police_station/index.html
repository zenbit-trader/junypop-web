police stationคำนาม

/pəˈliːs ˌsteɪʃn/ · ระดับ A2

โพ-ลีส สเต-ชั่น

สถานีตำรวจ

ตัวอย่างประโยค

You can report the theft at any police station in the city.

คุณแจ้งความเรื่องถูกขโมยได้ที่สถานีตำรวจทุกแห่งในเมือง

จุดที่คนไทยพลาดบ่อย

police station — police station = สถานีตำรวจ (อเมริกาเรียก precinct ด้วย) — ไปแจ้งความให้พูดว่า "I'd like to report a theft" หลายประเทศแจ้งออนไลน์ได้เลยไม่ต้องไปสถานี

คำที่มักสับสนกับ police station

  • police ตำรวจ

คำอื่นในบทเดียวกัน (ตำรวจและอาชญากรรม)

  • crime อาชญากรรม
  • thief ขโมย (คน)
  • robbery การปล้น / ชิงทรัพย์
  • burglary การงัดแงะบ้าน / ลักทรัพย์ในเคหสถาน
  • bystander คนที่อยู่ในเหตุการณ์ / ผู้เห็นเหตุการณ์
  • suspect ผู้ต้องสงสัย
  • police report ใบแจ้งความ / บันทึกประจำวัน
  • arrest จับกุม
  • case number หมายเลขคดี
  • break in งัดเข้าไป (บ้าน/รถ)
  • assault การทำร้ายร่างกาย
  • harassment การคุกคาม / ก่อกวน
  • CCTV กล้องวงจรปิด

จำ police station ให้ติดด้วยการเล่น
