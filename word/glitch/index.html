glitchคำนาม

/ɡlɪtʃ/ · ระดับ B2

กลิตช์

ข้อผิดพลาดชั่วคราว / อาการรวน

ตัวอย่างประโยค

A small glitch made the prices show as zero for a minute.

อาการรวนเล็กๆ ทำให้ราคาแสดงเป็นศูนย์อยู่หนึ่งนาที

จุดที่คนไทยพลาดบ่อย

glitch — glitch = ปัญหาเล็กๆ ที่เกิดแวบเดียวแล้วหาย ส่วน bug = ข้อผิดพลาดที่อยู่ในโค้ดถาวร — ใช้ในชีวิตได้: a glitch in the plan = แผนสะดุดนิดหน่อย

คำที่มักสับสนกับ glitch

  • switch สวิตช์ไฟ

คำอื่นในบทเดียวกัน (ซัพพอร์ตและแก้ปัญหา)

  • troubleshoot ไล่หาสาเหตุปัญหา / แก้ปัญหาทีละขั้น
  • crash โปรแกรมเด้ง / ล่มกะทันหัน
  • freeze ค้าง / หน้าจอไม่ขยับ
  • reboot บูตเครื่องใหม่
  • factory reset ล้างเครื่องกลับเป็นค่าโรงงาน
  • error ข้อผิดพลาด (ข้อความแจ้งเตือน)
  • help desk ฝ่ายช่วยเหลือไอที
  • reset รีเซ็ต / ตั้งค่าใหม่
  • technician ช่างเทคนิค
  • downtime ช่วงที่ระบบใช้งานไม่ได้
  • workaround วิธีแก้ชั่วคราว / ทางเลี่ยงปัญหา
  • overheat เครื่องร้อนเกินไป
  • corrupted ไฟล์เสีย / เปิดไม่ได้
