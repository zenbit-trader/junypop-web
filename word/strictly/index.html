strictlyคำวิเศษณ์

/ˈstrɪktli/ · ระดับ B1

สทริคท์-ลี

อย่างเคร่งครัด

ตัวอย่างประโยค

Smoking is strictly prohibited inside the warehouse.

ห้ามสูบบุหรี่ในคลังสินค้าโดยเด็ดขาด

จุดที่คนไทยพลาดบ่อย

strictly — strictly prohibited / strictly confidential / strictly speaking (พูดอย่างเคร่งครัด) — เป็นคำเน้นที่ป้ายเตือนภาษาอังกฤษใช้ตลอด

คำที่มักสับสนกับ strictly

  • strict เข้มงวด

คำอื่นในบทเดียวกัน (นโยบายและกฎระเบียบ)

  • policy นโยบาย
  • guideline แนวทางปฏิบัติ
  • mandatory บังคับ / ต้องทำ
  • compliance การปฏิบัติตามกฎ
  • violation การฝ่าฝืน / ละเมิด
  • restrict จำกัด / ควบคุมไม่ให้เกิน
  • code of conduct จรรยาบรรณ / ระเบียบความประพฤติ
  • impose กำหนด(ภาษี/ค่าปรับ)ให้ต้องรับ
  • liability ความรับผิด(ตามกฎหมาย) / หนี้สิน
  • exempt ได้รับยกเว้น
  • sanction มาตรการลงโทษ
  • disclose เปิดเผย(ข้อมูล)
  • in accordance with ตามที่กำหนดใน

จำ strictly ให้ติดด้วยการเล่น
