cabin crewคำนาม

/ˈkæbɪn kruː/ · ระดับ B1

แค-บิ่น-ครูว์

ลูกเรือ / พนักงานต้อนรับบนเครื่องบิน

ตัวอย่างประโยค

The cabin crew will serve drinks shortly.

ลูกเรือจะเสิร์ฟเครื่องดื่มในอีกสักครู่

จุดที่คนไทยพลาดบ่อย

cabin crew — cabin crew คือพนักงานต้อนรับทั้งทีม ถ้าพูดถึงคนเดียวใช้ flight attendant คำว่า แอร์ / สจ๊วต ที่คนไทยใช้มาจาก air hostess / steward ซึ่งเป็นคำเก่าแล้ว

คำที่มักสับสนกับ cabin crew

  • pilot นักบิน

คำอื่นในบทเดียวกัน (บนเครื่องบิน)

  • seatbelt เข็มขัดนิรภัย
  • fasten รัด / คาด (เข็มขัด)
  • turbulence สภาพอากาศแปรปรวน / อาการเครื่องสั่น
  • overhead bin ช่องเก็บสัมภาระเหนือศีรษะ
  • tray table โต๊ะพับหน้าที่นั่ง
  • landing การลงจอด
  • take off ถอด (เสื้อผ้า รองเท้า)
  • meal มื้ออาหาร
  • pilot นักบิน
  • headphones หูฟัง
  • lavatory ห้องน้ำ (บนเครื่องบิน)
  • blanket ผ้าห่ม
  • airplane เครื่องบิน

จำ cabin crew ให้ติดด้วยการเล่น
