จุดที่คนไทยพลาดบ่อย

download — คนไทยพูด "โหลดเกม โหลดแอป" ย่อจาก download — ตรงข้ามคือ upload (อัปโหลด ส่งขึ้นเน็ต)

คำที่มักสับสนกับ download

  • upload อัปโหลด ส่งไฟล์ขึ้นเน็ต

คำอื่นในบทเดียวกัน (เล่นออนไลน์)

  • online ออนไลน์
  • offline ออฟไลน์
  • install ติดตั้ง
  • update อัปเดต
  • server เซิร์ฟเวอร์
  • lag อาการแล็ก / หน่วง
  • connection การเชื่อมต่อ / สัญญาณเน็ต
  • account บัญชีผู้ใช้ / แอคเคานต์
  • log in เข้าสู่ระบบ
  • username ชื่อผู้ใช้
  • avatar อวตาร / ตัวแทนในเกม
  • match แมตช์ / เกมหนึ่งตา
  • teammate เพื่อนร่วมทีม
