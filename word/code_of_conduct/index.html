code of conductวลี

/koʊd əv ˈkɑːndʌkt/ · ระดับ B2

โคด ออฟ คอน-ดัคท์

จรรยาบรรณ / ระเบียบความประพฤติ

ตัวอย่างประโยค

Every new employee signs the code of conduct.

พนักงานใหม่ทุกคนลงนามรับจรรยาบรรณบริษัท

จุดที่คนไทยพลาดบ่อย

code of conduct — code ในที่นี้ = ชุดกฎ ไม่ใช่รหัส: dress code, code of conduct — conduct = ความประพฤติ (นาม) / ดำเนินการ (กริยา)

คำที่มักสับสนกับ code of conduct

  • conductor ตัวนำ (ไฟฟ้า / ความร้อน)

คำอื่นในบทเดียวกัน (นโยบายและกฎระเบียบ)

  • policy นโยบาย
  • guideline แนวทางปฏิบัติ
  • mandatory บังคับ / ต้องทำ
  • compliance การปฏิบัติตามกฎ
  • violation การฝ่าฝืน / ละเมิด
  • restrict จำกัด / ควบคุมไม่ให้เกิน
  • impose กำหนด(ภาษี/ค่าปรับ)ให้ต้องรับ
  • liability ความรับผิด(ตามกฎหมาย) / หนี้สิน
  • strictly อย่างเคร่งครัด
  • exempt ได้รับยกเว้น
  • sanction มาตรการลงโทษ
  • disclose เปิดเผย(ข้อมูล)
  • in accordance with ตามที่กำหนดใน

จำ code of conduct ให้ติดด้วยการเล่น
