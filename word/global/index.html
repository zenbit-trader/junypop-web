globalคำคุณศัพท์

/ˈɡloʊbəl/ · ระดับ B1

โกล-เบิ่ล

ระดับโลก

ตัวอย่างประโยค

Her snack brand went global last year.

แบรนด์ขนมของเธอไปตลาดโลกเมื่อปีที่แล้ว

จุดที่คนไทยพลาดบ่อย

global — globe (ลูกโลก) + al = ระดับโลก — go global = บุกตลาดโลก ความฝันของทุกแบรนด์ไทย

คำที่มักสับสนกับ global

  • local ท้องถิ่น / คนท้องถิ่น

คำอื่นในบทเดียวกัน (ค้าขายทั่วโลก)

  • expand ขยายกิจการ
  • branch สาขา
  • export ส่งออก
  • import นำเข้า
  • wholesale ขายส่ง
  • retail ขายปลีก
  • supplier ซัพพลายเออร์ / ผู้ส่งวัตถุดิบ
  • factory โรงงาน
  • warehouse โกดัง / คลังสินค้า
  • stock สต็อกสินค้า
  • shipment สินค้าที่จัดส่ง / ล็อตส่งของ
  • demand ความต้องการซื้อ / ดีมานด์
  • supply ปริมาณสินค้า / ซัพพลาย
