จุดที่คนไทยพลาดบ่อย

skill — คนไทยพูด "สกิล" ตรงกับฝรั่งเลย — soft skills = ทักษะคน (สื่อสาร ทีมเวิร์ค) / hard skills = ทักษะเทคนิค

คำอื่นในบทเดียวกัน (คนและตำแหน่ง)

  • manager ผู้จัดการ
  • assistant ผู้ช่วย
  • intern นักศึกษาฝึกงาน
  • staff พนักงาน (รวมๆ)
  • team ทีม
  • teamwork การทำงานเป็นทีม
  • department แผนก
  • position ตำแหน่งงาน
  • responsible รับผิดชอบ
  • get promoted ได้เลื่อนตำแหน่ง
  • hire จ้าง / รับเข้าทำงาน
  • fire ไล่ออก
  • resign ลาออก
