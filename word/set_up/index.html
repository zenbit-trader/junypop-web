set upวลี

/set ʌp/ · ระดับ A2

เซ็ท อัพ

ติดตั้ง จัดเตรียม ก่อตั้ง

ตัวอย่างประโยค

IT will set up your email on the first day.

ฝ่ายไอทีจะติดตั้งอีเมลให้คุณในวันแรก

จุดที่คนไทยพลาดบ่อย

set up — แยกได้: set up a meeting / set it up — ใช้กับระบบ ประชุม บริษัท (set up a company) ส่วนคำนาม setup = การตั้งค่าหรือโต๊ะทำงาน

คำอื่นในบทเดียวกัน (ที่ทำงาน)

  • carry out ดำเนินการ ปฏิบัติตามแผน
  • come up with คิดไอเดียขึ้นมาได้
  • figure out คิดออก หาคำตอบได้
  • work on กำลังทำ (งาน) อยู่
  • sort out จัดการให้เรียบร้อย แก้ไข
  • take over เข้ามารับช่วงต่อ ครอบครอง
  • take on รับงานเพิ่ม รับคนเข้าทำงาน
  • call off ยกเลิก (นัด งาน)
  • put off เลื่อนออกไป ผัดวันประกันพรุ่ง
  • wrap up สรุปปิดงาน ทำให้เสร็จ
  • catch up ตามให้ทัน / คุยอัปเดตชีวิต
  • keep up with ตามให้ทันตลอด ไม่ตกขบวน
  • deal with รับมือ จัดการกับ

จำ set up ให้ติดด้วยการเล่น
