run in the familyวลี

/rʌn ɪn ðə ˈfæməli/ · ระดับ B2

รัน อิน เดอะ แฟม-มิ-ลี่

เป็นกรรมพันธุ์ / มีกันทั้งตระกูล

ตัวอย่างประโยค

Curly hair and bad eyesight run in the family.

ผมหยิกกับสายตาไม่ดีเป็นกันทั้งตระกูล

จุดที่คนไทยพลาดบ่อย

run in the family — X runs in the family = X ถ่ายทอดในครอบครัว ใช้ได้ทั้งโรค หน้าตา พรสวรรค์ — หมอถามว่า Does diabetes run in your family? = มีประวัติเบาหวานในครอบครัวไหม

คำอื่นในบทเดียวกัน (ความสัมพันธ์ในครอบครัว)

  • close-knit สนิทแน่นแฟ้น
  • rely on พึ่งพา
  • take after เหมือน (พ่อแม่) ทางหน้าตาหรือนิสัย
  • reconcile คืนดี / ปรับความเข้าใจกัน
  • estranged ตัดขาดกัน (ในครอบครัว)
  • devoted ทุ่มเทรัก / อุทิศตนให้
  • stick together อยู่เคียงข้างกัน / ไม่ทิ้งกัน
  • supportive คอยสนับสนุน / เป็นกำลังใจ
  • overprotective ปกป้องมากเกินไป / หวงลูก
  • distant ห่างเหิน
  • black sheep แกะดำ (คนที่แตกต่างจากครอบครัว)
  • sibling rivalry การแข่งขันระหว่างพี่น้อง
  • eldest คนโตสุด (ในครอบครัว)

จำ run in the family ให้ติดด้วยการเล่น
