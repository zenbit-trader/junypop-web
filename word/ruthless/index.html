ruthlessคำคุณศัพท์

/ˈruːθləs/ · ระดับ B2

รูธ-เลิส

โหดเหี้ยม / ไร้ความปรานี

ตัวอย่างประโยค

The ruthless general showed no mercy to the prisoners.

แม่ทัพผู้โหดเหี้ยมไม่แสดงความปรานีต่อเชลยเลย

จุดที่คนไทยพลาดบ่อย

ruthless — ruth (ความสงสาร คำโบราณ) + -less (ไร้) = ไร้ความปรานี — ใช้กับนักธุรกิจและตัวร้ายในเรื่อง: a ruthless businessman = นักธุรกิจที่ทำทุกอย่างเพื่อชนะ

คำอื่นในบทเดียวกัน (บรรยายนิสัยตัวละคร)

  • modest ถ่อมตัว / ไม่โอ้อวด
  • reckless บุ่มบ่าม / ไม่ระวัง
  • cowardly ขี้ขลาด
  • talented มีพรสวรรค์
  • stern เข้มงวด / เคร่งขรึม
  • timid ขี้กลัว / ไม่กล้าแสดงออก
  • cunning เจ้าเล่ห์
  • cautious ระมัดระวัง / รอบคอบ
  • noble สูงส่ง / มีคุณธรรม
  • courageous องอาจ / กล้าหาญมาก
  • innocent บริสุทธิ์ / ไร้เดียงสา
  • mysterious ลึกลับ
  • wealthy ร่ำรวย / มั่งคั่ง
