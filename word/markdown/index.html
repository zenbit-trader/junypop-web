markdownคำนาม

/ˈmɑːrkdaʊn/ · ระดับ B2

มาร์ค-ดาวน์

การปรับราคาลงจากป้ายเดิม

ตัวอย่างประโยค

A thirty percent markdown cleared the winter jackets.

การลดราคาลงสามสิบเปอร์เซ็นต์ทำให้แจ็กเก็ตหน้าหนาวขายหมด

จุดที่คนไทยพลาดบ่อย

markdown — markdown = ลดจากราคาตั้งเดิม ตรงข้ามกับ markup — กริยาคือ mark down: mark the price down; ใช้ในร้านค้าปลีกมากกว่าคำว่า discount เพราะพูดถึงการตัดสินใจของร้าน

คำที่มักสับสนกับ markdown

  • markup ส่วนบวกเพิ่มจากต้นทุน

คำอื่นในบทเดียวกัน (ราคาและโปรโมชัน)

  • pricing การตั้งราคา
  • markup ส่วนบวกเพิ่มจากต้นทุน
  • margin ส่วนต่างกำไร (ต่อราคาขาย)
  • bundle ชุดสินค้าขายรวมกัน
  • upsell ชวนซื้อรุ่นที่แพงกว่า
  • cross-sell ชวนซื้อสินค้าอื่นที่เข้ากัน
  • loyalty program โปรแกรมสะสมแต้มลูกค้าประจำ
  • limited edition รุ่นผลิตจำนวนจำกัด
  • clearance การลดล้างสต็อก
  • freemium โมเดลใช้ฟรี จ่ายเพิ่มถ้าอยากได้มากกว่า
  • free trial ช่วงทดลองใช้ฟรี
  • referral การแนะนำเพื่อนมาใช้ (รับรางวัล)
  • early bird ราคาพิเศษสำหรับคนจองก่อน
