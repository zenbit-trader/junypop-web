จุดที่คนไทยพลาดบ่อย

inventory — inventory = รายการของทุกชิ้นในห้องพร้อมสภาพ ใช้เทียบตอนย้ายออก — ถ่ายรูปรอยขีดข่วนที่มีอยู่แล้วส่งให้เจ้าของบ้านทางอีเมล จะได้ไม่โดนหักมัดจำ

คำที่มักสับสนกับ inventory

  • invention สิ่งประดิษฐ์
  • investment การลงทุน
  • interview การสัมภาษณ์งาน

คำอื่นในบทเดียวกัน (สัญญาเช่า)

  • lease สัญญาเช่า
  • tenancy การเช่าอยู่ / ระยะเวลาเช่า
  • security deposit เงินประกันห้อง
  • guarantor ผู้ค้ำประกัน
  • break clause ข้อสัญญาให้ยกเลิกก่อนกำหนด
  • fixed-term แบบกำหนดระยะเวลาแน่นอน
  • extend ต่ออายุ / ขยายเวลา (สัญญา)
  • break the lease ยกเลิกสัญญาเช่าก่อนกำหนด
  • written notice หนังสือแจ้งล่วงหน้าเป็นลายลักษณ์อักษร
  • reference หนังสือรับรอง / คนรับรอง
  • sublet ปล่อยเช่าช่วง
  • fine print ข้อความตัวเล็กในสัญญา
  • in advance ล่วงหน้า
