police reportคำนาม

/pəˈliːs rɪˌpɔːrt/ · ระดับ B1

โพ-ลีส ริ-พอร์ท

ใบแจ้งความ / บันทึกประจำวัน

ตัวอย่างประโยค

The insurance company needs a police report before paying.

บริษัทประกันต้องการใบแจ้งความก่อนจ่ายเงิน

จุดที่คนไทยพลาดบ่อย

police report — police report = เอกสารที่ตำรวจออกให้หลังแจ้งความ (อังกฤษเรียก crime reference number) — จำเป็นสำหรับเคลมประกันและขอพาสปอร์ตใหม่ ขอสำเนาไว้เสมอ

คำที่มักสับสนกับ police report

  • police ตำรวจ

คำอื่นในบทเดียวกัน (ตำรวจและอาชญากรรม)

  • police station สถานีตำรวจ
  • crime อาชญากรรม
  • thief ขโมย (คน)
  • robbery การปล้น / ชิงทรัพย์
  • burglary การงัดแงะบ้าน / ลักทรัพย์ในเคหสถาน
  • bystander คนที่อยู่ในเหตุการณ์ / ผู้เห็นเหตุการณ์
  • suspect ผู้ต้องสงสัย
  • arrest จับกุม
  • case number หมายเลขคดี
  • break in งัดเข้าไป (บ้าน/รถ)
  • assault การทำร้ายร่างกาย
  • harassment การคุกคาม / ก่อกวน
  • CCTV กล้องวงจรปิด
