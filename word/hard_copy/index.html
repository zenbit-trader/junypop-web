hard copyวลี

/hɑːrd ˈkɑːpi/ · ระดับ B1

ฮาร์ด ค็อป-ปี้

สำเนากระดาษ(ฉบับพิมพ์)

ตัวอย่างประโยค

Please bring a hard copy of your passport to the interview.

กรุณานำสำเนาพาสปอร์ตแบบกระดาษมาในวันสัมภาษณ์

จุดที่คนไทยพลาดบ่อย

hard copy — hard copy = ฉบับพิมพ์บนกระดาษ ตรงข้าม soft copy / digital copy = ไฟล์ — ออฟฟิศไทยพูด "ฮาร์ดก็อปปี้" ตรงตัว

คำที่มักสับสนกับ hard copy

  • hardware ฮาร์ดแวร์ / อุปกรณ์คอมพิวเตอร์

คำอื่นในบทเดียวกัน (เอกสารและสัญญา)

  • duplicate สำเนาคู่ฉบับ
  • letterhead หัวจดหมาย(ที่มีชื่อบริษัท)
  • effective มีผลบังคับใช้ / ได้ผล
  • checklist รายการตรวจสอบ
  • approve อนุมัติ
  • endorse รับรอง / สนับสนุนอย่างเป็นทางการ
  • enclosed แนบมาด้วย(ในซอง)
  • legible อ่านออก(ลายมือ/ตัวพิมพ์)
  • proposal ข้อเสนอ(โครงการ)
  • paperwork งานเอกสาร
  • memo บันทึกข้อความภายใน
  • comply with ปฏิบัติตาม(กฎ)
  • specification รายละเอียดคุณสมบัติ / สเปก

จำ hard copy ให้ติดด้วยการเล่น
