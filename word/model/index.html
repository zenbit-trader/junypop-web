modelคำนาม

/ˈmɑːdəl/ · ระดับ A2

มา-เดิ้ล

รุ่น (สินค้า)

ตัวอย่างประโยค

Is this the latest model?

นี่รุ่นล่าสุดหรือเปล่าครับ

จุดที่คนไทยพลาดบ่อย

model — the latest model = รุ่นล่าสุด / an older model = รุ่นเก่า และ model ยังแปลว่านายแบบ/นางแบบได้ด้วย

คำอื่นในบทเดียวกัน (แกดเจ็ตไอที)

  • mobile phone โทรศัพท์มือถือ
  • charger สายชาร์จ / ที่ชาร์จ
  • battery แบตเตอรี่
  • power bank พาวเวอร์แบงก์ / แบตสำรอง
  • warranty การรับประกัน
  • screen หน้าจอ
  • memory หน่วยความจำ / เมมโมรี่
  • wireless ไร้สาย
  • gadget แกดเจ็ต / อุปกรณ์ไอทีชิ้นเล็ก
  • accessory อุปกรณ์เสริม
  • phone case เคสมือถือ
  • earbuds หูฟังไร้สายแบบใส่ในหู
  • smartwatch นาฬิกาอัจฉริยะ / สมาร์ทวอทช์

จำ model ให้ติดด้วยการเล่น

ทบทวนคำนี้พร้อมอีก 98 คำในหมวดช้อปปิ้ง ฟรี ไม่ต้องติดตั้ง
