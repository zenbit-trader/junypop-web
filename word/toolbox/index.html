toolboxคำนาม

/ˈtuːlbɑːks/ · ระดับ A2

ทูล-บ็อกซ์

กล่องเครื่องมือ

ตัวอย่างประโยค

My toolbox has a hammer, a saw and some screws.

กล่องเครื่องมือของฉันมีค้อน เลื่อย และสกรู

จุดที่คนไทยพลาดบ่อย

toolbox — tool = เครื่องมือ (ออกเสียง ทูล ยาว) — power tools คือเครื่องมือไฟฟ้า และ toolkit ก็แปลว่าชุดเครื่องมือเหมือนกัน

คำที่มักสับสนกับ toolbox

  • mailbox ตู้จดหมาย

คำอื่นในบทเดียวกัน (เครื่องมือช่าง)

  • bolt น็อตตัวผู้ / สลักเกลียว
  • nail ตะปู
  • screw สกรู / น็อตเกลียว
  • screwdriver ไขควง
  • drill สว่าน
  • wrench ประแจ
  • pliers คีม
  • saw เลื่อย
  • tape measure ตลับเมตร
  • ladder บันไดพาด
  • box cutter มีดคัตเตอร์
  • duct tape เทปผ้ากาว
  • sandpaper กระดาษทราย
