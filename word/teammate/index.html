teammateคำนาม

/ˈtiːmmeɪt/ · ระดับ A2

ทีม-เมท

เพื่อนร่วมทีม

ตัวอย่างประโยค

Good teammates always share items.

เพื่อนร่วมทีมที่ดีต้องแบ่งไอเทมกัน

จุดที่คนไทยพลาดบ่อย

teammate — team + mate (เพื่อน) — mate ประกอบคำได้เพียบ: classmate (เพื่อนร่วมห้อง) roommate (รูมเมท)

คำที่มักสับสนกับ teammate

  • classmate เพื่อนร่วมชั้น
  • teamwork การทำงานเป็นทีม

คำอื่นในบทเดียวกัน (เล่นออนไลน์)

  • online ออนไลน์
  • offline ออฟไลน์
  • download ดาวน์โหลด
  • install ติดตั้ง
  • update อัปเดต
  • server เซิร์ฟเวอร์
  • lag อาการแล็ก / หน่วง
  • connection การเชื่อมต่อ / สัญญาณเน็ต
  • account บัญชีผู้ใช้ / แอคเคานต์
  • log in เข้าสู่ระบบ
  • username ชื่อผู้ใช้
  • avatar อวตาร / ตัวแทนในเกม
  • match แมตช์ / เกมหนึ่งตา

จำ teammate ให้ติดด้วยการเล่น
