authorคำนาม

/ˈɔːθər/ · ระดับ A2

ออ-เธอร์

ผู้เขียน / ผู้แต่ง

ตัวอย่างประโยค

The author of this book is a famous Thai doctor.

ผู้เขียนหนังสือเล่มนี้เป็นหมอชาวไทยที่มีชื่อเสียง

จุดที่คนไทยพลาดบ่อย

author — author = ผู้แต่งหนังสือ/บทความ ใช้แทน writer ได้ แต่ฟังดูเป็นทางการกว่า — ข้อสอบใช้สลับกัน "the author/the writer suggests..."

คำที่มักสับสนกับ author

  • actor นักแสดงชาย
  • editor บรรณาธิการ

คำอื่นในบทเดียวกัน (คำนามในข้อสอบ)

  • passage บทความ (ที่ให้อ่านในข้อสอบ)
  • paragraph ย่อหน้า
  • topic หัวข้อ
  • main idea ใจความสำคัญ
  • detail รายละเอียด
  • purpose จุดประสงค์
  • tone น้ำเสียง (ของผู้เขียน)
  • attitude ทัศนคติ / ท่าที
  • title ชื่อเรื่อง
  • column คอลัมน์ (ในหนังสือพิมพ์)
  • context บริบท
  • excerpt ข้อความตัดตอน / บางส่วนจากเรื่อง
  • origin ต้นกำเนิด / ที่มา
