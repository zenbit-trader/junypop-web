break clauseคำนาม

/ˈbreɪk klɔːz/ · ระดับ B2

เบรค คลอส

ข้อสัญญาให้ยกเลิกก่อนกำหนด

ตัวอย่างประโยค

Ask for a break clause so you can leave after six months.

ขอให้ใส่ข้อสัญญาให้ยกเลิกก่อนกำหนด จะได้ย้ายออกได้หลังหกเดือน

จุดที่คนไทยพลาดบ่อย

break clause — break clause = ข้อในสัญญาเช่าที่ให้ฝ่ายใดฝ่ายหนึ่งยกเลิกก่อนครบกำหนดได้ (เช่น หลัง 6 เดือน แจ้งล่วงหน้า 2 เดือน) — ไม่มีข้อนี้ = ต้องจ่ายค่าเช่าจนครบสัญญาแม้ย้ายออกแล้ว ขอใส่ตั้งแต่ก่อนเซ็น

คำที่มักสับสนกับ break clause

  • clause ข้อสัญญา / ข้อความแต่ละข้อ
  • brake เบรก

คำอื่นในบทเดียวกัน (สัญญาเช่า)

  • lease สัญญาเช่า
  • tenancy การเช่าอยู่ / ระยะเวลาเช่า
  • security deposit เงินประกันห้อง
  • guarantor ผู้ค้ำประกัน
  • fixed-term แบบกำหนดระยะเวลาแน่นอน
  • extend ต่ออายุ / ขยายเวลา (สัญญา)
  • break the lease ยกเลิกสัญญาเช่าก่อนกำหนด
  • written notice หนังสือแจ้งล่วงหน้าเป็นลายลักษณ์อักษร
  • reference หนังสือรับรอง / คนรับรอง
  • inventory รายการทรัพย์สินในห้อง
  • sublet ปล่อยเช่าช่วง
  • fine print ข้อความตัวเล็กในสัญญา
  • in advance ล่วงหน้า
