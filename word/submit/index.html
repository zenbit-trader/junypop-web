จุดที่คนไทยพลาดบ่อย

submit — submit = ส่งแบบทางการ (ฟอร์ม รายงาน ใบสมัคร) — ปุ่ม Submit ในเว็บก็คือคำนี้ / by Monday = ภายในวันจันทร์

  • deadline กำหนดส่งงาน / เดดไลน์
  • busy ยุ่ง
  • project โปรเจกต์ / โครงการ
  • schedule ตารางงาน / กำหนดการ
  • priority สิ่งสำคัญอันดับแรก
  • finish ทำเสร็จ
  • check ตรวจสอบ
  • solve แก้ปัญหา
  • overtime การทำงานล่วงเวลา / โอที
