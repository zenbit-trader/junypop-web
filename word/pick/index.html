pickคำกริยา

/pɪk/ · ระดับ A2

พิค

เด็ด / เก็บ (ผลไม้จากต้น)

ตัวอย่างประโยค

We picked strawberries on a farm in Chiang Mai.

เราไปเก็บสตรอว์เบอร์รี่ที่ไร่ในเชียงใหม่

จุดที่คนไทยพลาดบ่อย

pick — pick fruit = เด็ดผลไม้จากต้น และ pick ยังแปลว่าเลือก (pick a number) — pick up = หยิบขึ้น/ไปรับ, ส่วน harvest = เก็บเกี่ยวผลผลิตทั้งไร่

คำที่มักสับสนกับ pick

  • pack จัดกระเป๋า / เก็บของใส่กระเป๋า
  • kick เตะ

คำอื่นในบทเดียวกัน (จากสวนสู่ตลาด)

  • bunch พวง / หวี / เครือ (ผลไม้)
  • core แกนกลางผลไม้
  • rind เปลือกหนา (แตงโม / ส้ม / ชีส)
  • pit เมล็ดแข็งตรงกลางผลไม้
  • ripe สุก (ผลไม้)
  • rotten เน่า
  • wilted เหี่ยว (ผัก / ดอกไม้)
  • seedless ไม่มีเมล็ด
  • dried อบแห้ง / ตากแห้ง
  • orchard สวนผลไม้
  • farmer เกษตรกร / ชาวไร่ชาวนา
  • pickle ผักดอง / แตงกวาดอง
  • jam แยม

จำ pick ให้ติดด้วยการเล่น

ทบทวนคำนี้พร้อมอีก 98 คำในหมวดผลไม้และผัก · เล่นฟรี ไม่ต้องติดตั้ง
