royaltyคำนาม

/ˈrɔɪəlti/ · ระดับ B2

รอย-เอิล-ตี

ค่าลิขสิทธิ์ที่ได้ทุกครั้งที่งานถูกใช้

ตัวอย่างประโยค

The writer earns a royalty every time the book sells.

นักเขียนได้ค่าลิขสิทธิ์ทุกครั้งที่หนังสือขายได้

จุดที่คนไทยพลาดบ่อย

royalty — royalties (มักพหูพจน์) = ส่วนแบ่งที่เจ้าของผลงานได้ต่อการขายหรือเปิดเพลง — royalty-free = จ่ายครั้งเดียวใช้ได้ตลอด (ภาพ เพลงประกอบ) และ royalty ยังแปลว่าราชวงศ์

คำอื่นในบทเดียวกัน (ทรัพย์สินทางปัญญา)

  • intellectual property ทรัพย์สินทางปัญญา
  • copyright ลิขสิทธิ์
  • trademark เครื่องหมายการค้า
  • patent สิทธิบัตร
  • license ใบอนุญาต / สิทธิ์การใช้งาน
  • infringement การละเมิดสิทธิ์
  • invention สิ่งประดิษฐ์
  • fair use การใช้งานลิขสิทธิ์โดยชอบธรรม
  • piracy การละเมิดลิขสิทธิ์ / ของเถื่อน
  • trade secret ความลับทางการค้า
  • public domain สมบัติสาธารณะ / งานที่หมดลิขสิทธิ์แล้ว
  • exclusive แต่เพียงผู้เดียว
  • logo โลโก้ / ตราสัญลักษณ์
