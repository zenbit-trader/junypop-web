cargoคำนาม

/ˈkɑːrɡoʊ/ · ระดับ B1

คาร์-โก

สินค้าบรรทุก(บนเรือ/เครื่อง)

ตัวอย่างประโยค

The ship carries cargo from Laem Chabang to Shanghai.

เรือขนสินค้าจากแหลมฉบังไปเซี่ยงไฮ้

จุดที่คนไทยพลาดบ่อย

cargo — cargo = ของที่บรรทุกบนพาหนะ (cargo ship, cargo plane) นับไม่ได้ — ส่วน freight เน้นระบบขนส่งและค่าใช้จ่าย

คำที่มักสับสนกับ cargo

  • carriage ตู้โดยสารของรถไฟ
  • cardio การออกกำลังกายแบบเพิ่มอัตราการเต้นหัวใจ

คำอื่นในบทเดียวกัน (ขนส่งและโลจิสติกส์)

  • freight สินค้าขนส่ง / ค่าระวาง
  • dispatch จัดส่งออกจากคลัง
  • courier บริษัทขนส่งพัสดุด่วน
  • tracking number หมายเลขติดตามพัสดุ
  • consignment สินค้าที่ส่งเป็นล็อต
  • distribute กระจายสินค้า / แจกจ่าย
  • in transit อยู่ระหว่างขนส่ง
  • fragile แตกง่าย / เปราะบาง
  • customs clearance พิธีการศุลกากร
  • load บรรทุก / ขนของขึ้น
  • expedite เร่งดำเนินการ
  • lead time ระยะเวลารอสินค้า
  • bulk จำนวนมาก / ล็อตใหญ่
