backupคำนาม

/ˈbækʌp/ · ระดับ A2

แบ็ก-อัป

ข้อมูลสำรอง

ตัวอย่างประโยค

Make a backup before you delete anything on the server.

ทำข้อมูลสำรองก่อนลบอะไรบนเซิร์ฟเวอร์

จุดที่คนไทยพลาดบ่อย

backup — backup (น.) เขียนติดกัน ส่วน back up (ก.) แยกกัน: "Back up your phone tonight" — ยังหมายถึงกำลังเสริม/ตัวสำรองในทีมได้ด้วย

คำที่มักสับสนกับ backup

  • backpack กระเป๋าเป้
  • backlog งานค้างสะสม

คำอื่นในบทเดียวกัน (ข้อมูลและคลาวด์)

  • database ฐานข้อมูล
  • cloud คลาวด์ / เก็บข้อมูลบนอินเทอร์เน็ต
  • data center ศูนย์ข้อมูล / ตึกเก็บเซิร์ฟเวอร์
  • spreadsheet ตารางคำนวณ (Excel)
  • dashboard แดชบอร์ด / หน้าสรุปข้อมูล
  • analytics การวิเคราะห์ข้อมูล / สถิติการใช้งาน
  • storage พื้นที่เก็บข้อมูล
  • API ช่องทางให้โปรแกรมคุยกัน
  • query คำสั่งค้นหาข้อมูล
  • big data บิ๊กดาต้า / ข้อมูลมหาศาล
  • cache แคช / ข้อมูลที่เก็บไว้ให้โหลดเร็ว
  • real-time แบบทันที / ตามเวลาจริง
  • archive เก็บเข้าคลัง / ย้ายไปเก็บถาวร

จำ backup ให้ติดด้วยการเล่น
