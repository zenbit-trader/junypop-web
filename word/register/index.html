registerคำกริยา

/ˈredʒɪstər/ · ระดับ A2

เร-จิส-เตอร์

ลงทะเบียน (เรียน)

ตัวอย่างประโยค

You must register for your courses before Friday.

คุณต้องลงทะเบียนเรียนก่อนวันศุกร์

จุดที่คนไทยพลาดบ่อย

register — register for a course = ลงทะเบียนวิชา (คำนาม registration) — ต่างจาก enroll ที่เป็นการสมัครเข้าเป็นนักศึกษาครั้งแรก ลงช้าต้องเสีย late registration fee

คำที่มักสับสนกับ register

  • record บันทึก (เสียง/วิดีโอ)

คำอื่นในบทเดียวกัน (ลงทะเบียนเรียน)

  • course วิชา / รายวิชา
  • module วิชาย่อยในหลักสูตร (อังกฤษ)
  • credit หน่วยกิต
  • elective วิชาเลือก
  • compulsory วิชาบังคับ / ภาคบังคับ
  • syllabus ประมวลรายวิชา
  • academic year ปีการศึกษา
  • advisor อาจารย์ที่ปรึกษา
  • minor วิชาโท
  • core course วิชาแกนของสาขา
  • drop ถอนวิชา
  • course catalog คู่มือรายวิชาทั้งหมด
  • coursework งานเก็บคะแนนระหว่างเทอม
