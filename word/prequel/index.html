prequelคำนาม

/ˈpriːkwəl/ · ระดับ B1

พรี-เควิล

ภาคก่อนหน้า (ออกทีหลัง)

ตัวอย่างประโยค

The prequel tells how the wizard became evil.

ภาคก่อนหน้าเล่าว่าพ่อมดกลายเป็นคนชั่วได้อย่างไร

จุดที่คนไทยพลาดบ่อย

prequel — pre- = ก่อน ล้อกับ sequel (ภาคต่อ) — prequel คือเล่มที่ออกทีหลังแต่เล่าเหตุการณ์ก่อนหน้า เช่น The Hunger Games เล่มเกี่ยวกับสโนว์

คำที่มักสับสนกับ prequel

  • sequel ภาคต่อ
  • pretzel เพรทเซล (ขนมปังเกลียว)

คำอื่นในบทเดียวกัน (นักเขียนและการตีพิมพ์)

  • writer นักเขียน
  • publish ตีพิมพ์ / เผยแพร่
  • publisher สำนักพิมพ์
  • manuscript ต้นฉบับหนังสือ
  • editor บรรณาธิการ
  • pen name นามปากกา
  • trilogy นิยายไตรภาค
  • translate แปล (ภาษา)
  • translator นักแปล
  • book signing งานแจกลายเซ็นนักเขียน
  • writer's block อาการเขียนไม่ออก
  • royalties ค่าลิขสิทธิ์ที่นักเขียนได้ต่อเล่ม
  • ghostwriter นักเขียนเงา (เขียนให้คนอื่นใส่ชื่อ)
