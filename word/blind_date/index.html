blind dateคำนาม

/blaɪnd deɪt/ · ระดับ B2

ไบลนด์ เดท

เดตกับคนที่ไม่เคยเจอหน้ากันมาก่อน

ตัวอย่างประโยค

My friend set me up on a blind date.

เพื่อนจัดให้ไปเดตกับคนที่ไม่เคยเจอกันมาก่อน

จุดที่คนไทยพลาดบ่อย

blind date — blind ในที่นี้แปลว่ายังไม่เคยเห็นหน้ากัน ไม่ได้แปลว่าตาบอด — คนจัดให้เรียก set up

  • single โสด ยังไม่มีแฟน
  • taken มีแฟนแล้ว มีเจ้าของแล้ว
  • my type ตรงสเปกของฉัน
  • butterflies อาการใจเต้นตึกตักตอนตื่นเต้นหรือชอบใคร

  • shy ขี้อาย
  • attractive ดูดี น่าดึงดูด
  • charming มีเสน่ห์ ชวนหลงใหล
