optionalคำคุณศัพท์

/ˈɑːpʃənəl/ · ระดับ B1

อ็อพ-ชั่น-เนิล

ใส่หรือไม่ใส่ก็ได้

ตัวอย่างประโยค

The chili is optional if you do not like spicy food.

พริกจะใส่หรือไม่ใส่ก็ได้ถ้าไม่ชอบเผ็ด

จุดที่คนไทยพลาดบ่อย

optional — ในสูตรจะเขียน (optional) ต่อท้ายวัตถุดิบที่ไม่ใส่ก็ไม่เสียรส — ตรงข้ามคือ required หรือ compulsory ใช้กับวิชาเรียนก็ได้ optional course

คำที่มักสับสนกับ optional

  • option ตัวเลือก
  • original เอกสารตัวจริง / ฉบับจริง

คำอื่นในบทเดียวกัน (อ่านสูตรอาหาร)

  • recipe สูตรอาหาร
  • cookbook ตำราอาหาร
  • serving หนึ่งที่ (ปริมาณต่อคน)
  • from scratch ทำเองตั้งแต่ต้น (ไม่ใช้สำเร็จรูป)
  • pinch หยิบมือ (ปริมาณน้อยๆ)
  • dash นิดหน่อย (ของเหลว)
  • batch หนึ่งรอบการทำ / หนึ่งชุด
  • prep เตรียมวัตถุดิบ
  • leftovers อาหารเหลือ
  • garnish ตกแต่งจาน
  • to taste ปรุงตามชอบ
  • swap สลับใช้แทน
  • homemade ทำเองที่บ้าน
