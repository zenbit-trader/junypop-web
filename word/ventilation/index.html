ventilationคำนาม

/ˌventɪˈleɪʃn/ · ระดับ B2

เวน-ทิ-เล-ชั่น

การระบายอากาศ

ตัวอย่างประโยค

The warehouse needs better ventilation in the summer.

คลังสินค้าต้องระบายอากาศให้ดีขึ้นในหน้าร้อน

จุดที่คนไทยพลาดบ่อย

ventilation — ventilation system = ระบบระบายอากาศ (กริยา ventilate) — ในการตรวจอาคาร poor ventilation เป็นข้อร้องเรียนยอดฮิต

  • vacation วันหยุดพักผ่อน
  • vibration การสั่นสะเทือน

คำอื่นในบทเดียวกัน (อสังหาฯ และอาคารสถานที่)

  • commercial เชิงพาณิชย์ / เพื่อการค้า
  • occupancy การเข้าใช้พื้นที่ / อัตราการเข้าพัก
  • property อสังหาริมทรัพย์ / ทรัพย์สิน
  • facility สิ่งอำนวยความสะดวก / อาคารสถานที่
  • renovate ปรับปรุงซ่อมแซม(อาคาร)
  • floor space พื้นที่ใช้สอย
  • square meter ตารางเมตร
  • premises บริเวณสถานที่(ของบริษัท/ร้าน)
  • spacious กว้างขวาง
  • relocate ย้ายที่ตั้ง
  • plumbing ระบบประปา
  • real estate agent นายหน้าอสังหาริมทรัพย์
  • vacant ว่าง(ไม่มีคนอยู่/ใช้)
