จุดที่คนไทยพลาดบ่อย

points — สะสมแต้ม = collect/earn points, แลกแต้ม = redeem points เจอทุกร้านตั้งแต่เซเว่นถึงห้างใหญ่

คำอื่นในบทเดียวกัน (จ่ายเงินและคืนสินค้า)

  • refund การคืนเงิน
  • exchange เปลี่ยนสินค้า / แลกเปลี่ยน
  • return คืนสินค้า
  • installment การผ่อนชำระ / งวด
  • debit card บัตรเดบิต
  • mobile banking โมบายแบงก์กิ้ง / ธนาคารบนมือถือ
  • QR code คิวอาร์โค้ด
  • scan สแกน
  • member card บัตรสมาชิก
  • voucher บัตรกำนัล / เวาเชอร์
  • coupon คูปอง
  • out of stock สินค้าหมด
  • in stock มีสินค้า / ของพร้อมส่ง
