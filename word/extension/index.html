extensionคำนาม

/ɪkˈstenʃn/ · ระดับ B1

อิค-สเตน-ชั่น

การขอเลื่อนส่งงาน

ตัวอย่างประโยค

I asked for an extension because I was ill last week.

ฉันขอเลื่อนส่งงานเพราะป่วยเมื่อสัปดาห์ที่แล้ว

จุดที่คนไทยพลาดบ่อย

extension — ask for/request an extension = ขอเลื่อนกำหนดส่ง ต้องมีเหตุผลและหลักฐาน (ใบรับรองแพทย์) ขอก่อนถึงวันส่งเท่านั้น — extension ยังแปลว่าเบอร์ต่อภายในและปลั๊กพ่วง (extension cord)

คำอื่นในบทเดียวกัน (เขียนรายงานและวิจัย)

  • thesis วิทยานิพนธ์
  • dissertation สารนิพนธ์ / งานวิจัยจบ
  • citation การอ้างอิงในเนื้อหา
  • cite อ้างอิง (แหล่งที่มา)
  • bibliography บรรณานุกรม
  • plagiarism การลอกผลงาน
  • paraphrase เรียบเรียงใหม่ด้วยคำของตัวเอง
  • word count จำนวนคำที่กำหนด
  • proofread ตรวจทานคำผิด
  • outline โครงร่าง (ของรายงาน)
  • argument ข้อโต้แย้งเชิงวิชาการ / เหตุผลหลัก
  • source แหล่งข้อมูลอ้างอิง
  • abstract บทคัดย่อ
