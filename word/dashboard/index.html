จุดที่คนไทยพลาดบ่อย

dashboard — เดิมแปลว่าแผงหน้ารถ ตอนนี้ใช้กับหน้าจอรวมกราฟและตัวเลขสำคัญ — ผู้บริหารไทยชอบถามหา "แดชบอร์ด" เวลาอยากเห็นภาพรวมทีเดียว

คำที่มักสับสนกับ dashboard

  • whiteboard กระดานไวท์บอร์ด
  • keyboard คีย์บอร์ด / แป้นพิมพ์
  • billboard ป้ายโฆษณาขนาดใหญ่

คำอื่นในบทเดียวกัน (ข้อมูลและคลาวด์)

  • database ฐานข้อมูล
  • cloud คลาวด์ / เก็บข้อมูลบนอินเทอร์เน็ต
  • backup ข้อมูลสำรอง
  • data center ศูนย์ข้อมูล / ตึกเก็บเซิร์ฟเวอร์
  • spreadsheet ตารางคำนวณ (Excel)
  • analytics การวิเคราะห์ข้อมูล / สถิติการใช้งาน
  • storage พื้นที่เก็บข้อมูล
  • API ช่องทางให้โปรแกรมคุยกัน
  • query คำสั่งค้นหาข้อมูล
  • big data บิ๊กดาต้า / ข้อมูลมหาศาล
  • cache แคช / ข้อมูลที่เก็บไว้ให้โหลดเร็ว
  • real-time แบบทันที / ตามเวลาจริง
  • archive เก็บเข้าคลัง / ย้ายไปเก็บถาวร

จำ dashboard ให้ติดด้วยการเล่น
