จุดที่คนไทยพลาดบ่อย

borrow — จำทิศทาง: borrow = ยืมเข้าหาตัวเรา / lend = ให้คนอื่นยืม — คนไทยสลับสองคำนี้บ่อยที่สุด!

คำอื่นในบทเดียวกัน (เรื่องเงินต้องรู้)

  • money เงิน
  • income รายได้
  • expense รายจ่าย / ค่าใช้จ่าย
  • profit กำไร
  • loss การขาดทุน
  • savings เงินเก็บ / เงินออม
  • invest ลงทุน
  • loan เงินกู้
  • debt หนี้
  • interest ดอกเบี้ย
  • tax ภาษี
  • bank ธนาคาร
  • lend ให้ยืม

จำ borrow ให้ติดด้วยการเล่น
