machine learningคำนาม

/məˌʃiːn ˈlɜːrnɪŋ/ · ระดับ B2

มะ-ชีน เลิร์น-นิง

การเรียนรู้ของเครื่อง

ตัวอย่างประโยค

Machine learning helps the bank spot unusual spending on your card.

การเรียนรู้ของเครื่องช่วยให้ธนาคารจับการใช้จ่ายผิดปกติบนบัตรคุณได้

จุดที่คนไทยพลาดบ่อย

machine learning — ย่อว่า ML — คอมเรียนรู้จากตัวอย่างจำนวนมากแทนที่จะมีคนเขียนกฎให้ทุกข้อ เป็นเทคนิคหลักที่อยู่เบื้องหลัง AI ยุคนี้

คำอื่นในบทเดียวกัน (AI และระบบอัตโนมัติ)

  • artificial intelligence ปัญญาประดิษฐ์ (AI)
  • chatbot แชตบอต / โปรแกรมตอบแชตอัตโนมัติ
  • prompt พรอมต์ / คำสั่งที่พิมพ์บอก AI
  • automation ระบบอัตโนมัติ
  • automate ทำให้เป็นอัตโนมัติ
  • generate สร้างขึ้น (โดยโปรแกรม/AI)
  • bot บอต / โปรแกรมทำงานแทนคน
  • workflow ขั้นตอนการทำงาน / ลำดับงาน
  • dataset ชุดข้อมูล (สำหรับสอน AI)
  • predict ทำนาย / คาดการณ์
  • deepfake ดีปเฟก / วิดีโอปลอมที่ AI สร้าง
  • accuracy ความแม่นยำ
  • voice assistant ผู้ช่วยสั่งงานด้วยเสียง
