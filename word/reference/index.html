referenceคำนาม

/ˈrefrəns/ · ระดับ B1

เรฟ-เฟอ-เรินซ์

หนังสือรับรอง / คนรับรอง

ตัวอย่างประโยค

The landlord asked for a reference from my employer.

เจ้าของบ้านขอหนังสือรับรองจากนายจ้างของฉัน

จุดที่คนไทยพลาดบ่อย

reference — ตอนเช่าบ้านต่างประเทศมักถูกขอ references = เอกสารหรือคนรับรองว่าคุณจ่ายไหวและเป็นผู้เช่าที่ดี — เจ้าของบ้านเก่าเขียนให้ได้ (landlord reference)

คำที่มักสับสนกับ reference

  • referee ผู้ตัดสิน

คำอื่นในบทเดียวกัน (สัญญาเช่า)

  • lease สัญญาเช่า
  • tenancy การเช่าอยู่ / ระยะเวลาเช่า
  • security deposit เงินประกันห้อง
  • guarantor ผู้ค้ำประกัน
  • break clause ข้อสัญญาให้ยกเลิกก่อนกำหนด
  • fixed-term แบบกำหนดระยะเวลาแน่นอน
  • extend ต่ออายุ / ขยายเวลา (สัญญา)
  • break the lease ยกเลิกสัญญาเช่าก่อนกำหนด
  • written notice หนังสือแจ้งล่วงหน้าเป็นลายลักษณ์อักษร
  • inventory รายการทรัพย์สินในห้อง
  • sublet ปล่อยเช่าช่วง
  • fine print ข้อความตัวเล็กในสัญญา
  • in advance ล่วงหน้า
