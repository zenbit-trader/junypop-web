clutterคำนาม

/ˈklʌtər/ · ระดับ B1

คลัท-เทอร์

ของรกระเกะระกะ

ตัวอย่างประโยค

There is so much clutter on the desk that I cannot work.

บนโต๊ะมีของรกเต็มไปหมดจนฉันทำงานไม่ได้

จุดที่คนไทยพลาดบ่อย

clutter — clutter = กองของที่วางเกะกะไม่เป็นที่ นับไม่ได้ (ไม่เติม s) — ส่วน mess ก็แปลว่ารก แต่รวมถึงสกปรกเลอะเทอะด้วย

  • butter เนย

คำอื่นในบทเดียวกัน (จัดบ้านให้เป็นระเบียบ)

  • organize จัดให้เป็นระเบียบ
  • declutter กำจัดของรก
  • messy รก / เลอะเทอะ
  • container กล่องใส่ของ / ภาชนะมีฝา
  • cupboard ตู้เก็บของ (ในครัว)
  • cabinet ตู้ (ติดผนัง / มีลิ้นชัก)
  • storage box กล่องเก็บของ
  • label ติดป้ายชื่อ
  • junk ของเก่าไร้ค่า / ขยะ
  • shoe rack ชั้นวางรองเท้า

  • stack วางซ้อนกัน
