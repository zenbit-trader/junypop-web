chapterคำนาม

/ˈtʃæptər/ · ระดับ A2

แชพ-เทอร์

บท (ของหนังสือ)

ตัวอย่างประโยค

Read chapter five before class tomorrow.

อ่านบทที่ห้ามาก่อนเรียนพรุ่งนี้

จุดที่คนไทยพลาดบ่อย

chapter — chapter = บทในหนังสือ (chapter one/the first chapter) — สำนวน a new chapter in my life = ชีวิตบทใหม่

คำที่มักสับสนกับ chapter

  • character ตัวละคร
  • captain กัปตันทีม

คำอื่นในบทเดียวกัน (วรรณกรรมและเรื่องเล่า)

  • novel นวนิยาย
  • poem บทกวี / กลอน
  • poet กวี / นักกลอน
  • fiction เรื่องแต่ง / บันเทิงคดี
  • narrator ผู้เล่าเรื่อง
  • theme แก่นเรื่อง / แนวคิดหลัก
  • moral คติสอนใจ / ข้อคิด
  • villain ตัวร้าย
  • legend ตำนาน
  • myth เทพปกรณัม / ความเชื่อผิดๆ
  • fable นิทานสอนใจ (ตัวละครสัตว์)
  • metaphor อุปลักษณ์ / การเปรียบเป็น
  • tragedy โศกนาฏกรรม
