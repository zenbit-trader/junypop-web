ตัวอย่างประโยค

The app uses the bank's API to check your balance.

แอปใช้ API ของธนาคารเพื่อเช็กยอดเงินของคุณ

จุดที่คนไทยพลาดบ่อย

API — API (Application Programming Interface) = ประตูที่ให้โปรแกรมอื่นมาขอข้อมูลหรือสั่งงาน — เวลาแอปไทยเชื่อมกับ LINE หรือธนาคารก็ผ่าน API ทั้งนั้น

คำที่มักสับสนกับ API

  • app แอปพลิเคชัน

คำอื่นในบทเดียวกัน (ข้อมูลและคลาวด์)

  • database ฐานข้อมูล
  • cloud คลาวด์ / เก็บข้อมูลบนอินเทอร์เน็ต
  • backup ข้อมูลสำรอง
  • data center ศูนย์ข้อมูล / ตึกเก็บเซิร์ฟเวอร์
  • spreadsheet ตารางคำนวณ (Excel)
  • dashboard แดชบอร์ด / หน้าสรุปข้อมูล
  • analytics การวิเคราะห์ข้อมูล / สถิติการใช้งาน
  • storage พื้นที่เก็บข้อมูล
  • query คำสั่งค้นหาข้อมูล
  • big data บิ๊กดาต้า / ข้อมูลมหาศาล
  • cache แคช / ข้อมูลที่เก็บไว้ให้โหลดเร็ว
  • real-time แบบทันที / ตามเวลาจริง
  • archive เก็บเข้าคลัง / ย้ายไปเก็บถาวร
