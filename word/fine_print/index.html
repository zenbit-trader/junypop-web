fine printคำนาม

/ˌfaɪn ˈprɪnt/ · ระดับ B2

ไฟน์ พรินท์

ข้อความตัวเล็กในสัญญา

ตัวอย่างประโยค

Always read the fine print before you agree to anything.

อ่านข้อความตัวเล็กในสัญญาเสมอก่อนตกลงอะไร

จุดที่คนไทยพลาดบ่อย

fine print — fine print (หรือ small print) = เงื่อนไขตัวเล็กๆ ที่ซ่อนค่าใช้จ่ายไว้ — fine ตรงนี้แปลว่า "ละเอียด/เล็ก" ไม่ใช่ "ดี" และไม่ใช่ค่าปรับ

คำที่มักสับสนกับ fine print

  • fine ค่าปรับ

คำอื่นในบทเดียวกัน (สัญญาเช่า)

  • lease สัญญาเช่า
  • tenancy การเช่าอยู่ / ระยะเวลาเช่า
  • security deposit เงินประกันห้อง
  • guarantor ผู้ค้ำประกัน
  • break clause ข้อสัญญาให้ยกเลิกก่อนกำหนด
  • fixed-term แบบกำหนดระยะเวลาแน่นอน
  • extend ต่ออายุ / ขยายเวลา (สัญญา)
  • break the lease ยกเลิกสัญญาเช่าก่อนกำหนด
  • written notice หนังสือแจ้งล่วงหน้าเป็นลายลักษณ์อักษร
  • reference หนังสือรับรอง / คนรับรอง
  • inventory รายการทรัพย์สินในห้อง
  • sublet ปล่อยเช่าช่วง
  • in advance ล่วงหน้า
