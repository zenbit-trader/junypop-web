deviceคำนาม

/dɪˈvaɪs/ · ระดับ A2

ดิ-ไวซ์

ตัวอย่างประโยค

You can log in from any device, even your phone.

คุณล็อกอินได้จากอุปกรณ์ไหนก็ได้ แม้แต่มือถือ

จุดที่คนไทยพลาดบ่อย

device — device (n.) อุปกรณ์ กับ devise (v.) คิดค้น สะกดต่างกันตัวเดียว — ในแอปมักเจอ "this device" = เครื่องนี้ และ mobile device = มือถือ/แท็บเล็ต

คำที่มักสับสนกับ device

  • advice คำแนะนำ
  • divide หาร / แบ่ง

คำอื่นในบทเดียวกัน (อุปกรณ์และเครือข่าย)

  • hardware ฮาร์ดแวร์ / อุปกรณ์คอมพิวเตอร์
  • network เครือข่าย
  • router เราเตอร์ / ตัวกระจายสัญญาณ
  • modem โมเด็ม
  • cable สายเคเบิล / สายไฟ
  • port ช่องเสียบ / พอร์ต
  • bandwidth แบนด์วิดท์ / ความกว้างช่องสัญญาณ
  • hotspot ฮอตสปอต / จุดแชร์เน็ตจากมือถือ
  • Bluetooth บลูทูธ
  • USB ยูเอสบี / แฟลชไดรฟ์
  • hard drive ฮาร์ดดิสก์ / ที่เก็บข้อมูลในเครื่อง
  • processor หน่วยประมวลผล / ซีพียู
  • Ethernet อีเทอร์เน็ต / เน็ตแบบสาย LAN
