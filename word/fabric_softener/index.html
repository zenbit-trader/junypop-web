จุดที่คนไทยพลาดบ่อย

fabric softener — softener มาจาก soft + -ener = สิ่งที่ทำให้นุ่ม — ในซูเปอร์ฯ มักวางคู่กับ detergent และ bleach ดูฉลากคำพวกนี้ให้ออกจะซื้อไม่ผิดขวด

คำที่มักสับสนกับ fabric softener

  • conditioner ครีมนวดผม

คำอื่นในบทเดียวกัน (วันซักผ้า)

  • laundry basket ตะกร้าผ้า
  • detergent ผงซักฟอก / น้ำยาซักผ้า
  • soak แช่น้ำ
  • rinse ล้างน้ำเปล่า
  • spin ปั่นแห้ง / หมุน
  • dryer เครื่องอบผ้า
  • clothesline ราวตากผ้า
  • hanger ไม้แขวนเสื้อ
  • fold พับ
  • ironing board โต๊ะรีดผ้า
  • shrink หด
  • fade สีซีด / สีตก
  • bleach น้ำยาฟอกขาว
