componentคำนาม

/kəmˈpoʊnənt/ · ระดับ B2

คอม-โพ-เนินท์

ชิ้นส่วนประกอบ

ตัวอย่างประโยค

We import electronic components from Japan.

เรานำเข้าชิ้นส่วนอิเล็กทรอนิกส์จากญี่ปุ่น

จุดที่คนไทยพลาดบ่อย

component — component = ชิ้นส่วนที่ประกอบเป็นเครื่อง (ทางเทคนิค) ส่วน part ใช้ทั่วไป — spare parts = อะไหล่

คำที่มักสับสนกับ component

  • opponent คู่แข่ง / ฝ่ายตรงข้าม

คำอื่นในบทเดียวกัน (การผลิตและคุณภาพ)

  • manufacture ผลิต(ในโรงงาน)
  • assembly line สายการประกอบ
  • inspect ตรวจสอบอย่างละเอียด
  • defect ข้อบกพร่อง / ตำหนิ(ในสินค้า)
  • durable ทนทาน
  • raw material วัตถุดิบ
  • machinery เครื่องจักร(โดยรวม)
  • output ผลผลิต / ปริมาณที่ผลิตได้
  • standard มาตรฐาน
  • malfunction ทำงานผิดปกติ / ขัดข้อง
  • efficient มีประสิทธิภาพ(ไม่สิ้นเปลือง)
  • shortage การขาดแคลน(สินค้า/แรงงาน)
  • recall เรียกคืนสินค้า

จำ component ให้ติดด้วยการเล่น
