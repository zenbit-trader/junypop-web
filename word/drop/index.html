dropคำกริยา

/drɑːp/ · ระดับ A2

ดร็อพ

ถอนวิชา

ตัวอย่างประโยค

You can drop a course without penalty in the first two weeks.

ถอนวิชาได้โดยไม่มีบทลงโทษภายในสองสัปดาห์แรก

จุดที่คนไทยพลาดบ่อย

drop — drop a course = ถอนวิชา (ไทยก็พูดว่า "ดรอป") ช่วงเพิ่ม-ถอนเรียก add/drop period — ถอนหลังกำหนดจะติด W ใน transcript และไม่ได้ค่าเทอมคืน

คำที่มักสับสนกับ drop

  • drip หยดติ๋ง
  • withdraw ถอนตัวออกจากกระบวนการ
  • dropout ผู้ออกจากการเรียนกลางคัน

คำอื่นในบทเดียวกัน (ลงทะเบียนเรียน)

  • course วิชา / รายวิชา
  • module วิชาย่อยในหลักสูตร (อังกฤษ)
  • credit หน่วยกิต
  • elective วิชาเลือก
  • compulsory วิชาบังคับ / ภาคบังคับ
  • register ลงทะเบียน (เรียน)
  • syllabus ประมวลรายวิชา
  • academic year ปีการศึกษา
  • advisor อาจารย์ที่ปรึกษา
  • minor วิชาโท
  • core course วิชาแกนของสาขา
  • course catalog คู่มือรายวิชาทั้งหมด
  • coursework งานเก็บคะแนนระหว่างเทอม
