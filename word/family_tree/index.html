จุดที่คนไทยพลาดบ่อย

family tree — family tree = แผนผังแสดงญาติแต่ละรุ่นแตกกิ่งเหมือนต้นไม้ — เป็นการบ้านยอดฮิตของเด็กฝรั่ง และเว็บสืบเชื้อสายก็ใช้คำนี้

คำอื่นในบทเดียวกัน (วัยชราและรุ่นสู่รุ่น)

  • generation รุ่น (คนรุ่นเดียวกัน)
  • generation gap ช่องว่างระหว่างวัย
  • ancestor บรรพบุรุษ
  • descendant ลูกหลาน / ผู้สืบเชื้อสาย
  • senior citizen ผู้สูงอายุ (คำสุภาพ)
  • middle-aged วัยกลางคน
  • grow old แก่ตัวลง
  • nursing home บ้านพักคนชรา
  • caregiver ผู้ดูแล (ผู้ป่วย / ผู้สูงอายุ)
  • pass away เสียชีวิต (คำสุภาพ)
  • heir ทายาท (ผู้รับมรดก)
  • old age วัยชรา
  • legacy สิ่งที่ทิ้งไว้ให้คนรุ่นหลัง
