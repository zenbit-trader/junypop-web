จุดที่คนไทยพลาดบ่อย

lag — เกมเมอร์ไทยพูด "แล็ก/กระตุก" ตรงศัพท์ — เน็ตหน่วงเกมเลยแล็ก และ jet lag (เพลียจากบินไกล) ก็ lag เดียวกัน

  • leg ขา

  • offline ออฟไลน์
  • download ดาวน์โหลด
  • install ติดตั้ง
  • update อัปเดต
  • server เซิร์ฟเวอร์
  • connection การเชื่อมต่อ / สัญญาณเน็ต
  • account บัญชีผู้ใช้ / แอคเคานต์
  • log in เข้าสู่ระบบ
  • username ชื่อผู้ใช้
  • avatar อวตาร / ตัวแทนในเกม
  • match แมตช์ / เกมหนึ่งตา
