จุดที่คนไทยพลาดบ่อย

tracking number — track = ติดตามเส้นทาง — Part 3 มักมีลูกค้าโทรถาม tracking number เพราะของยังไม่ถึง

คำอื่นในบทเดียวกัน (ขนส่งและโลจิสติกส์)

  • freight สินค้าขนส่ง / ค่าระวาง
  • cargo สินค้าบรรทุก(บนเรือ/เครื่อง)
  • dispatch จัดส่งออกจากคลัง
  • courier บริษัทขนส่งพัสดุด่วน
  • consignment สินค้าที่ส่งเป็นล็อต
  • distribute กระจายสินค้า / แจกจ่าย
  • in transit อยู่ระหว่างขนส่ง
  • fragile แตกง่าย / เปราะบาง
  • customs clearance พิธีการศุลกากร
  • load บรรทุก / ขนของขึ้น
  • expedite เร่งดำเนินการ
  • lead time ระยะเวลารอสินค้า
  • bulk จำนวนมาก / ล็อตใหญ่

จำ tracking number ให้ติดด้วยการเล่น
