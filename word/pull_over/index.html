จุดที่คนไทยพลาดบ่อย

pull over — แยกไม่ได้เมื่อตัวเองจอด แต่ตำรวจ pull someone over = เรียกให้จอด — ภาพคือดึงพวงมาลัยเบี่ยงไปด้านข้าง

คำอื่นในบทเดียวกัน (ออกเดินทาง)

  • set off ออกเดินทาง (เริ่มทริป)
  • get away หนีไปพักผ่อน หลุดพ้น
  • get in ขึ้นรถ (เก๋ง แท็กซี่) / มาถึง
  • get out ลงจากรถ / ออกไปข้างนอก
  • slow down ชะลอความเร็ว ช้าลง
  • speed up เร่งความเร็ว
  • turn around กลับรถ หันกลับ
  • break down รถเสียกลางทาง / ร้องไห้ฟูมฟาย
  • look around เดินดูรอบๆ
  • show around พาเดินชม พาทัวร์
  • see off ไปส่งที่สนามบิน/สถานี
  • run into บังเอิญเจอ
  • come along ไปด้วยกัน ติดสอยห้อยตาม

จำ pull over ให้ติดด้วยการเล่น
