evaluateคำกริยา

/ɪˈvæljueɪt/ · ระดับ B2

อิ-แวล-ยู-เอท

ประเมิน / ประเมินค่า

ตัวอย่างประโยค

Evaluate the writer's argument: is it strong or weak?

ประเมินข้อโต้แย้งของผู้เขียนว่าหนักแน่นหรืออ่อน

จุดที่คนไทยพลาดบ่อย

evaluate — evaluate = ตัดสินว่าดีแค่ไหนหลังพิจารณาหลักฐาน (คำนาม evaluation) — ข้อสอบระดับสูงถาม "Evaluate the effectiveness of..." ต้องให้ทั้งข้อดีข้อเสียและสรุป

คำที่มักสับสนกับ evaluate

  • estimate ประเมิน / กะประมาณ

คำอื่นในบทเดียวกัน (กริยาอ่านจับใจความ)

  • skim อ่านผ่านๆ / อ่านคร่าวๆ
  • portray วาดภาพ / นำเสนอ (ตัวละคร)
  • convey สื่อ / ถ่ายทอด (ความหมาย)
  • define ให้คำจำกัดความ / นิยาม
  • identify ระบุ / ชี้ตัว
  • state กล่าว / ระบุไว้
  • illustrate แสดงให้เห็น / ยกตัวอย่างประกอบ
  • indicate บ่งชี้ / แสดงว่า
  • imply บอกเป็นนัย
  • infer อนุมาน / สรุปจากหลักฐาน
  • conclude สรุป / ลงความเห็น
  • interpret ตีความ
  • refer to หมายถึง / อ้างถึง
