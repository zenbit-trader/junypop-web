outlineคำนาม

/ˈaʊtlaɪn/ · ระดับ B1

เอาท์-ไลน์

โครงร่าง (ของรายงาน)

ตัวอย่างประโยค

Write an outline before you start the first draft.

เขียนโครงร่างก่อนเริ่มร่างแรก

จุดที่คนไทยพลาดบ่อย

outline — outline = โครงร่างหัวข้อหลัก-ย่อยก่อนเขียนจริง อาจารย์บางคนขอดูก่อนส่ง dissertation — เป็นกริยาได้: outline the main points = สรุปประเด็นหลักคร่าวๆ

คำที่มักสับสนกับ outline

  • online ออนไลน์
  • headline พาดหัว
  • outlet เต้ารับไฟฟ้า (รูปลั๊กที่ผนัง)

คำอื่นในบทเดียวกัน (เขียนรายงานและวิจัย)

  • thesis วิทยานิพนธ์
  • dissertation สารนิพนธ์ / งานวิจัยจบ
  • citation การอ้างอิงในเนื้อหา
  • cite อ้างอิง (แหล่งที่มา)
  • bibliography บรรณานุกรม
  • plagiarism การลอกผลงาน
  • paraphrase เรียบเรียงใหม่ด้วยคำของตัวเอง
  • word count จำนวนคำที่กำหนด
  • proofread ตรวจทานคำผิด
  • argument ข้อโต้แย้งเชิงวิชาการ / เหตุผลหลัก
  • source แหล่งข้อมูลอ้างอิง
  • abstract บทคัดย่อ
  • extension การขอเลื่อนส่งงาน
