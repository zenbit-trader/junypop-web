cruise controlคำนาม

/ˈkruːz kənˌtroʊl/ · ระดับ B1

ครูซ คอน-โทรล

ระบบควบคุมความเร็วอัตโนมัติ

ตัวอย่างประโยค

I set the cruise control to ninety on the long straight road.

ฉันตั้งครูซคอนโทรลไว้ที่เก้าสิบบนถนนตรงยาวๆ

จุดที่คนไทยพลาดบ่อย

cruise control — cruise = ล่องเรือ/แล่นสบายๆ ตั้งความเร็วแล้วยกเท้าได้ — ตั้งค่า = set the cruise control และแบบปรับตามคันหน้าคือ adaptive cruise control

คำอื่นในบทเดียวกัน (บนท้องถนน)

  • steer บังคับพวงมาลัย
  • turn signal ไฟเลี้ยว
  • merge แทรกเข้าเลน / รวมเข้าทาง
  • highway ทางหลวง
  • exit ramp ทางลงจากทางด่วน
  • blind spot จุดบอดที่กระจกมองไม่เห็น
  • tailgate ขับจี้ท้าย
  • reverse ถอยหลัง
  • dead end ทางตัน
  • bend ทางโค้ง
  • change lanes เปลี่ยนเลน
  • hazard lights ไฟฉุกเฉิน
  • high beam ไฟสูง

จำ cruise control ให้ติดด้วยการเล่น
