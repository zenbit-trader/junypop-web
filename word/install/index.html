จุดที่คนไทยพลาดบ่อย

install — install = ลงเกม/ลงแอป — ลบออกจากเครื่อง = uninstall ปุ่มที่เจอทุกวันใน App Store

  • installment การผ่อนชำระ / งวด

  • online ออนไลน์
  • offline ออฟไลน์
  • download ดาวน์โหลด
  • update อัปเดต
  • server เซิร์ฟเวอร์
  • lag อาการแล็ก / หน่วง
  • connection การเชื่อมต่อ / สัญญาณเน็ต
  • account บัญชีผู้ใช้ / แอคเคานต์
  • log in เข้าสู่ระบบ
  • username ชื่อผู้ใช้
  • avatar อวตาร / ตัวแทนในเกม
  • match แมตช์ / เกมหนึ่งตา
  • teammate เพื่อนร่วมทีม
