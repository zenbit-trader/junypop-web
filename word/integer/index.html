integerคำนาม

/ˈɪntɪdʒər/ · ระดับ B2

อิน-ทิ-เจอร์

จำนวนเต็ม

ตัวอย่างประโยค

An integer is a number without a fraction, like 3 or -7.

จำนวนเต็มคือตัวเลขที่ไม่มีเศษส่วน เช่น 3 หรือ -7

จุดที่คนไทยพลาดบ่อย

integer — integer = จำนวนเต็ม รวมเลขลบและศูนย์ (…-2, -1, 0, 1, 2…) ออกเสียง อิน-ทิ-เจอร์ — โปรแกรมเมอร์เจอคำนี้เป็นชนิดข้อมูล int ในทุกภาษา
