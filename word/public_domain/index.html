public domainคำนาม

/ˌpʌblɪk doʊˈmeɪn/ · ระดับ B2

พับ-ลิก โด-เมน

สมบัติสาธารณะ / งานที่หมดลิขสิทธิ์แล้ว

ตัวอย่างประโยค

Old classical music is in the public domain, so anyone can use it.

เพลงคลาสสิกเก่าเป็นสมบัติสาธารณะ ใครก็นำไปใช้ได้

จุดที่คนไทยพลาดบ่อย

public domain — in the public domain = งานที่ลิขสิทธิ์หมดอายุ (ในไทย 50 ปีหลังผู้สร้างเสียชีวิต) หรือเจ้าของยกให้ฟรี — domain ในที่นี้ = ขอบเขต ไม่ใช่ชื่อเว็บ

คำอื่นในบทเดียวกัน (ทรัพย์สินทางปัญญา)

  • intellectual property ทรัพย์สินทางปัญญา
  • copyright ลิขสิทธิ์
  • trademark เครื่องหมายการค้า
  • patent สิทธิบัตร
  • license ใบอนุญาต / สิทธิ์การใช้งาน
  • infringement การละเมิดสิทธิ์
  • invention สิ่งประดิษฐ์
  • royalty ค่าลิขสิทธิ์ที่ได้ทุกครั้งที่งานถูกใช้
  • fair use การใช้งานลิขสิทธิ์โดยชอบธรรม
  • piracy การละเมิดลิขสิทธิ์ / ของเถื่อน
  • trade secret ความลับทางการค้า
  • exclusive แต่เพียงผู้เดียว
  • logo โลโก้ / ตราสัญลักษณ์
