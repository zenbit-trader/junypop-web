role-playingคำนาม

/ˈroʊl pleɪɪŋ/ · ระดับ B1

โรล-เพลย์-อิ้ง

แนวสวมบทบาท / RPG

ตัวอย่างประโยค

In role-playing games, you become the hero.

ในเกม RPG คุณได้เป็นฮีโร่เสียเอง

จุดที่คนไทยพลาดบ่อย

role-playing — ย่อว่า RPG (role-playing game) — role = บทบาท เกมเก็บเลเวลตีมอนสเตอร์สายไทยชอบก็แนวนี้แหละ

คำที่มักสับสนกับ role-playing

  • racing แนวแข่งรถ / แข่งความเร็ว

คำอื่นในบทเดียวกัน (เลือกแนวเกม)

  • genre แนวเกม / ประเภท
  • action แนวแอ็กชัน / ฉากบู๊
  • racing แนวแข่งรถ / แข่งความเร็ว
  • puzzle เกมปริศนา
  • shooting game เกมยิง
  • horror แนวสยองขวัญ
  • sports game เกมกีฬา
  • strategy แนววางแผน / กลยุทธ์
  • simulation แนวจำลองชีวิต
  • arcade เกมตู้ / อาร์เคด
  • board game บอร์ดเกม / เกมกระดาน
  • casual เล่นง่ายๆ สบายๆ
  • mobile game เกมมือถือ
