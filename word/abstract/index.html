abstractคำนาม

/ˈæbstrækt/ · ระดับ B2

แอบ-สแตรคท์

บทคัดย่อ

ตัวอย่างประโยค

Read the abstract first to see if the article is useful.

อ่านบทคัดย่อก่อนเพื่อดูว่าบทความนั้นมีประโยชน์ไหม

จุดที่คนไทยพลาดบ่อย

abstract — abstract = บทคัดย่อ 150–300 คำต้นบทความวิจัยและวิทยานิพนธ์ อ่านแล้วรู้ว่าควรอ่านต่อไหม — ส่วนคำคุณศัพท์ abstract แปลว่านามธรรม เน้นเสียงพยางค์แรกทั้งสองแบบ

คำอื่นในบทเดียวกัน (เขียนรายงานและวิจัย)

  • thesis วิทยานิพนธ์
  • dissertation สารนิพนธ์ / งานวิจัยจบ
  • citation การอ้างอิงในเนื้อหา
  • cite อ้างอิง (แหล่งที่มา)
  • bibliography บรรณานุกรม
  • plagiarism การลอกผลงาน
  • paraphrase เรียบเรียงใหม่ด้วยคำของตัวเอง
  • word count จำนวนคำที่กำหนด
  • proofread ตรวจทานคำผิด
  • outline โครงร่าง (ของรายงาน)
  • argument ข้อโต้แย้งเชิงวิชาการ / เหตุผลหลัก
  • source แหล่งข้อมูลอ้างอิง
  • extension การขอเลื่อนส่งงาน
