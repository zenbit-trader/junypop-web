emergency numberคำนาม

/ɪˈmɜːrdʒənsi ˌnʌmbər/ · ระดับ A2

อิ-เมอร์-เจิน-ซี นัม-เบอร์

ตัวอย่างประโยค

Save the local emergency number before you travel.

บันทึกเบอร์โทรฉุกเฉินของประเทศนั้นไว้ก่อนเดินทาง

จุดที่คนไทยพลาดบ่อย

emergency number — เบอร์ฉุกเฉินแต่ละประเทศไม่เหมือนกัน: อเมริกา 911, อังกฤษ 999, ยุโรป 112, ออสเตรเลีย 000, ไทย 191/1669 — โทรได้แม้ไม่มีซิมหรือเครดิต

คำอื่นในบทเดียวกัน (โทรขอความช่วยเหลือ)

  • call for help ร้องขอความช่วยเหลือ
  • operator เจ้าหน้าที่รับสาย
  • hotline สายด่วน
  • stay calm ใจเย็นไว้ / ตั้งสติ
  • stay on the line ถือสายรอ อย่าวางสาย
  • location ตำแหน่งที่อยู่ (ตอนนี้)
  • emergency contact ผู้ติดต่อกรณีฉุกเฉิน
  • describe บรรยาย / อธิบายลักษณะ
  • rescue ช่วยชีวิต / กู้ภัย
  • victim ผู้ประสบเหตุ / เหยื่อ
  • unconscious หมดสติ
  • breathing การหายใจ
  • panic ตื่นตระหนก

จำ emergency number ให้ติดด้วยการเล่น
