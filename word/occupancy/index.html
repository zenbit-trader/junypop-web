occupancyคำนาม

/ˈɑːkjəpənsi/ · ระดับ B2

ออค-คิว-เพิน-ซี

การเข้าใช้พื้นที่ / อัตราการเข้าพัก

ตัวอย่างประโยค

Hotel occupancy reaches ninety percent in high season.

อัตราเข้าพักโรงแรมแตะเก้าสิบเปอร์เซ็นต์ในฤดูท่องเที่ยว

จุดที่คนไทยพลาดบ่อย

occupancy — occupancy rate = อัตราห้องที่มีคนใช้ (โรงแรม ออฟฟิศ) — maximum occupancy 50 = ป้ายจำกัดคนในห้อง; occupied = มีคนใช้อยู่

คำที่มักสับสนกับ occupancy

  • vacancy ห้องว่าง

คำอื่นในบทเดียวกัน (อสังหาฯ และอาคารสถานที่)

  • commercial เชิงพาณิชย์ / เพื่อการค้า
  • ventilation การระบายอากาศ
  • property อสังหาริมทรัพย์ / ทรัพย์สิน
  • facility สิ่งอำนวยความสะดวก / อาคารสถานที่
  • renovate ปรับปรุงซ่อมแซม(อาคาร)
  • floor space พื้นที่ใช้สอย
  • square meter ตารางเมตร
  • premises บริเวณสถานที่(ของบริษัท/ร้าน)
  • spacious กว้างขวาง
  • relocate ย้ายที่ตั้ง
  • plumbing ระบบประปา
  • real estate agent นายหน้าอสังหาริมทรัพย์
  • vacant ว่าง(ไม่มีคนอยู่/ใช้)
