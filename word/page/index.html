pageคำนาม

/peɪdʒ/ · ระดับ A1

เพจ

หน้าหนังสือ

ตัวอย่างประโยค

Turn to page forty and read the first paragraph.

เปิดไปหน้าสี่สิบแล้วอ่านย่อหน้าแรก

จุดที่คนไทยพลาดบ่อย

page — พลิกหน้า = turn the page ไม่ใช่ open the page — หนังสือ 300 หน้า = a 300-page book (ไม่เติม s เมื่อขยายคำนาม) และเพจเฟซบุ๊กก็คำเดียวกัน

คำที่มักสับสนกับ page

  • cage กรง
  • wage ค่าจ้าง(รายชั่วโมง/รายวัน)

คำอื่นในบทเดียวกัน (ส่วนประกอบของหนังสือ)

  • cover ปกหนังสือ
  • table of contents สารบัญ
  • preface คำนำ
  • prologue บทนำเรื่อง (ก่อนบทที่ 1)
  • blurb คำโปรยปกหลัง
  • spine สันหนังสือ
  • hardcover หนังสือปกแข็ง
  • paperback หนังสือปกอ่อน
  • illustration ภาพประกอบ
  • footnote เชิงอรรถ
  • glossary อภิธานศัพท์ท้ายเล่ม
  • edition ฉบับพิมพ์ / ครั้งที่พิมพ์
  • epilogue บทส่งท้าย
