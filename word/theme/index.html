themeคำนาม

/θiːm/ · ระดับ B1

ธีม

แก่นเรื่อง / แนวคิดหลัก

ตัวอย่างประโยค

The theme of the story is friendship.

แก่นเรื่องของเรื่องนี้คือมิตรภาพ

จุดที่คนไทยพลาดบ่อย

theme — theme = แก่นที่เรื่องต้องการสื่อ (love, courage, loss) ส่วน plot = ลำดับเหตุการณ์ — ตอบ theme เป็นคำนามนามธรรม ไม่ใช่เล่าเรื่อง

คำที่มักสับสนกับ theme

  • team ทีม
  • thesis วิทยานิพนธ์

คำอื่นในบทเดียวกัน (วรรณกรรมและเรื่องเล่า)

  • novel นวนิยาย
  • chapter บท (ของหนังสือ)
  • poem บทกวี / กลอน
  • poet กวี / นักกลอน
  • fiction เรื่องแต่ง / บันเทิงคดี
  • narrator ผู้เล่าเรื่อง
  • moral คติสอนใจ / ข้อคิด
  • villain ตัวร้าย
  • legend ตำนาน
  • myth เทพปกรณัม / ความเชื่อผิดๆ
  • fable นิทานสอนใจ (ตัวละครสัตว์)
  • metaphor อุปลักษณ์ / การเปรียบเป็น
  • tragedy โศกนาฏกรรม
