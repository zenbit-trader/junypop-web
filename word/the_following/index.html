the following — "Which of the following..." คือประโยคคำถามที่เจอบ่อยที่สุดในข้อสอบ = ตัวเลือกข้างล่างข้อไหน — follow = ตาม ดังนั้น the following = สิ่งที่ตามมา

คำอื่นในบทเดียวกัน (คำสั่งในข้อสอบ)

  • choose เลือก
  • complete เติมให้สมบูรณ์ / ทำให้เสร็จ
  • blank ช่องว่าง (ให้เติมคำ)
  • underline ขีดเส้นใต้
  • correct ถูกต้อง
  • incorrect ไม่ถูกต้อง / ผิด
  • option ตัวเลือก
  • according to ตามที่ (…กล่าว)
  • except ยกเว้น
  • synonym คำที่มีความหมายเหมือนกัน
  • antonym คำที่มีความหมายตรงข้าม
  • true or false ถูกหรือผิด (ข้อสอบแบบ T/F)
  • open-ended ปลายเปิด / อัตนัย
