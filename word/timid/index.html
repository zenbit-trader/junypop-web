timidคำคุณศัพท์

/ˈtɪmɪd/ · ระดับ B2

ทิม-มิด

ขี้กลัว / ไม่กล้าแสดงออก

ตัวอย่างประโยค

The timid kitten hid under the sofa all day.

ลูกแมวขี้กลัวซ่อนใต้โซฟาทั้งวัน

จุดที่คนไทยพลาดบ่อย

timid — timid = ขี้กลัว ไม่กล้า (กว่า shy ที่แค่เขิน) ตรงข้ามกับ bold/confident — ตัวละครที่ timid ตอนต้นเรื่องมักโตขึ้นกล้าขึ้นตอนจบ ซึ่งเป็นโจทย์ character development

คำอื่นในบทเดียวกัน (บรรยายนิสัยตัวละคร)

  • modest ถ่อมตัว / ไม่โอ้อวด
  • reckless บุ่มบ่าม / ไม่ระวัง
  • cowardly ขี้ขลาด
  • ruthless โหดเหี้ยม / ไร้ความปรานี
  • talented มีพรสวรรค์
  • stern เข้มงวด / เคร่งขรึม
  • cunning เจ้าเล่ห์
  • cautious ระมัดระวัง / รอบคอบ
  • noble สูงส่ง / มีคุณธรรม
  • courageous องอาจ / กล้าหาญมาก
  • innocent บริสุทธิ์ / ไร้เดียงสา
  • mysterious ลึกลับ
  • wealthy ร่ำรวย / มั่งคั่ง
