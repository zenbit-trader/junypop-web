exportคำกริยา

/ɪkˈspɔːrt/ · ระดับ B1

เอ็ค-สปอร์ต

ส่งออก

ตัวอย่างประโยค

Thailand exports rice all over the world.

ไทยส่งออกข้าวไปทั่วโลก

จุดที่คนไทยพลาดบ่อย

export — ex (ออก) + port (ท่าเรือ) = ส่งออก — สินค้าส่งออกดังของไทย: ข้าว ทุเรียน รถยนต์ อาหารทะเล

คำที่มักสับสนกับ export

  • import นำเข้า

คำอื่นในบทเดียวกัน (ค้าขายทั่วโลก)

  • expand ขยายกิจการ
  • branch สาขา
  • import นำเข้า
  • wholesale ขายส่ง
  • retail ขายปลีก
  • supplier ซัพพลายเออร์ / ผู้ส่งวัตถุดิบ
  • factory โรงงาน
  • warehouse โกดัง / คลังสินค้า
  • stock สต็อกสินค้า
  • shipment สินค้าที่จัดส่ง / ล็อตส่งของ
  • demand ความต้องการซื้อ / ดีมานด์
  • supply ปริมาณสินค้า / ซัพพลาย
  • global ระดับโลก

จำ export ให้ติดด้วยการเล่น
