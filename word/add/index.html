addคำกริยา

/æd/ · ระดับ A1

แอด

บวก / เพิ่ม

ตัวอย่างประโยค

Add the two numbers together to get the total.

บวกตัวเลขสองตัวเข้าด้วยกันเพื่อให้ได้ผลรวม

จุดที่คนไทยพลาดบ่อย

add — add A to B / add A and B together คำนาม addition (การบวก) — add up = บวกรวม และ it doesn't add up = มันไม่สมเหตุสมผล
