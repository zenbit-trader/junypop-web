complainคำกริยา

/kəmˈpleɪn/ · ระดับ B1

คอม-เพลน

ร้องเรียน / บ่น

ตัวอย่างประโยค

I'd like to complain about the noise.

ผมอยากร้องเรียนเรื่องเสียงดังครับ

จุดที่คนไทยพลาดบ่อย

complain — complain about + เรื่องที่ร้องเรียน ส่วนคำนามคือ complaint (มี t) เช่น make a complaint

คำที่มักสับสนกับ complain

  • compare เปรียบเทียบ

คำอื่นในบทเดียวกัน (แจ้งปัญหา)

  • broken พัง / แตก / เสีย
  • not working ใช้งานไม่ได้ / เสีย
  • fix ซ่อม
  • leak รั่ว
  • blocked ตัน / อุดตัน
  • noisy เสียงดัง / หนวกหู
  • dirty สกปรก
  • smelly เหม็น
  • no hot water น้ำอุ่นไม่ไหล / ไม่มีน้ำร้อน
  • lost my key ทำกุญแจ/คีย์การ์ดหาย
  • change rooms ขอย้ายห้อง
  • apologize ขอโทษ
  • maintenance งานซ่อมบำรุง / ช่างอาคาร

จำ complain ให้ติดด้วยการเล่น
