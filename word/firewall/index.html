firewallคำนาม

/ˈfaɪərwɔːl/ · ระดับ B1

ไฟร์-วอลล์

ไฟร์วอลล์ / กำแพงกันผู้บุกรุก

ตัวอย่างประโยค

The firewall blocked the website, so ask IT to open it.

ไฟร์วอลล์บล็อกเว็บนั้นไว้ ลองขอให้ไอทีเปิดให้

จุดที่คนไทยพลาดบ่อย

firewall — firewall = ระบบกรองว่าอะไรเข้าออกเครือข่ายได้ ชื่อมาจากกำแพงกันไฟลามในตึก — ออฟฟิศไทยหลายที่บล็อกเว็บเกมหรือโซเชียลด้วยไฟร์วอลล์นี่แหละ

คำที่มักสับสนกับ firewall

  • fireworks พลุ / ดอกไม้ไฟ
  • firefighter นักดับเพลิง

คำอื่นในบทเดียวกัน (ความปลอดภัยไซเบอร์)

  • cybersecurity ความปลอดภัยไซเบอร์
  • hacker แฮกเกอร์ / ผู้เจาะระบบ
  • malware มัลแวร์ / โปรแกรมประสงค์ร้าย
  • virus ไวรัสคอมพิวเตอร์
  • encrypt เข้ารหัสข้อมูล
  • data breach ข้อมูลรั่วไหล
  • authentication การยืนยันตัวตน
  • ransomware มัลแวร์เรียกค่าไถ่
  • patch แพตช์ / ตัวแก้ช่องโหว่
  • vulnerability ช่องโหว่ / จุดอ่อนของระบบ
  • antivirus โปรแกรมป้องกันไวรัส
  • VPN เครือข่ายส่วนตัวเสมือน / อุโมงค์เน็ตที่ปลอดภัย
  • access สิทธิ์เข้าใช้ / การเข้าถึง
