perคำบุพบท

/pɜːr/ · ระดับ A2

เพอร์

ต่อ (หน่วย)

ตัวอย่างประโยค

The room costs 1,200 baht per night.

ห้องราคาคืนละ 1,200 บาท

จุดที่คนไทยพลาดบ่อย

per — per = ต่อ (per hour, per person, per kilo) ไม่ต้องมี a/the ตามหลัง — ภาษาพูดใช้ a แทนได้: 50 baht a kilo และ per cent ก็คือ "ต่อร้อย"

คำที่มักสับสนกับ per

  • peer เพื่อนรุ่นเดียวกัน / คนระดับเดียวกัน

คำอื่นในบทเดียวกัน (คำนวณเงินในชีวิตจริง)

  • amount จำนวน / ยอดเงิน
  • quantity ปริมาณ / จำนวนชิ้น
  • each แต่ละ / ชิ้นละ
  • unit price ราคาต่อหน่วย
  • subtotal ยอดรวมย่อย (ก่อนภาษี)
  • VAT ภาษีมูลค่าเพิ่ม
  • altogether ทั้งหมดรวมกัน
  • twice สองเท่า / สองครั้ง
  • triple สามเท่า
  • exact ตรงเป๊ะ / แน่นอน
  • roughly คร่าวๆ / ราวๆ
  • figure ตัวเลข (สถิติ) / จำนวนเงิน
  • convert แปลงหน่วย / แปลงค่า

จำ per ให้ติดด้วยการเล่น
