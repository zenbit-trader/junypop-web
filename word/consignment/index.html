consignmentคำนาม

/kənˈsaɪnmənt/ · ระดับ B2

คัน-ไซน์-เมนท์

สินค้าที่ส่งเป็นล็อต

ตัวอย่างประโยค

The first consignment of laptops arrives on Monday.

แล็ปท็อปล็อตแรกจะมาถึงวันจันทร์

จุดที่คนไทยพลาดบ่อย

consignment — consignment = ของหนึ่งล็อตที่ส่งไปให้ผู้รับ — ในธุรกิจค้าปลีก on consignment = ฝากขาย จ่ายเงินเมื่อขายได้

คำที่มักสับสนกับ consignment

  • assignment งานที่ได้รับมอบหมาย
  • consent ความยินยอม
  • commitment ความผูกมัด / คำมั่นสัญญา

คำอื่นในบทเดียวกัน (ขนส่งและโลจิสติกส์)

  • freight สินค้าขนส่ง / ค่าระวาง
  • cargo สินค้าบรรทุก(บนเรือ/เครื่อง)
  • dispatch จัดส่งออกจากคลัง
  • courier บริษัทขนส่งพัสดุด่วน
  • tracking number หมายเลขติดตามพัสดุ
  • distribute กระจายสินค้า / แจกจ่าย
  • in transit อยู่ระหว่างขนส่ง
  • fragile แตกง่าย / เปราะบาง
  • customs clearance พิธีการศุลกากร
  • load บรรทุก / ขนของขึ้น
  • expedite เร่งดำเนินการ
  • lead time ระยะเวลารอสินค้า
  • bulk จำนวนมาก / ล็อตใหญ่

จำ consignment ให้ติดด้วยการเล่น
