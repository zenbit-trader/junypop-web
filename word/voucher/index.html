จุดที่คนไทยพลาดบ่อย

voucher — ออกเสียง "เวา-เชอร์" gift voucher = บัตรของขวัญ ส่วน coupon เป็นส่วนลดคล้ายกันแต่มักตัดจากโฆษณา/แอป

  • refund การคืนเงิน

  • return คืนสินค้า
  • installment การผ่อนชำระ / งวด
  • debit card บัตรเดบิต
  • mobile banking โมบายแบงก์กิ้ง / ธนาคารบนมือถือ
  • QR code คิวอาร์โค้ด
  • scan สแกน
  • member card บัตรสมาชิก
  • points แต้มสะสม / คะแนน
  • coupon คูปอง
  • out of stock สินค้าหมด
