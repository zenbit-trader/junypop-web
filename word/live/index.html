live — live มีสองเสียง! "ไลฟ์" = สด (live stream) / "ลิฟว์" = อาศัยอยู่ (I live in Bangkok) สะกดเหมือนกันเป๊ะ

คำอื่นในบทเดียวกัน (สตรีมและแชท)

  • stream สตรีม / ถ่ายทอดสด
  • streamer สตรีมเมอร์
  • viewer ผู้ชม
  • chat แชท / คุยกัน
  • comment คอมเมนต์ / ความคิดเห็น
  • follower ผู้ติดตาม
  • subscribe กดติดตามช่อง
  • channel ช่อง (ยูทูบ/สตรีม)
  • clip คลิปวิดีโอ
  • highlight ช่วงเด็ด / ไฮไลต์
  • donate โดเนท / บริจาค
  • emote อีโมท / ท่าแสดงอารมณ์ในเกม
  • go viral ดังเป็นไวรัล
