จุดที่คนไทยพลาดบ่อย

file a claim — file/make a claim = ยื่นเรื่องขอเงินประกัน (ไทยยืมคำว่า "เคลม" มาตรงๆ) ต้องแนบใบแจ้งความ ใบเสร็จ และรูปถ่าย — file ตรงนี้แปลว่ายื่นเอกสารอย่างเป็นทางการ เช่น file a report, file a complaint
