ledgerคำนาม

/ˈledʒər/ · ระดับ B2

เล็ด-เจอร์

สมุดบัญชีบันทึกรายการ

ตัวอย่างประโยค

The blockchain is a public ledger that anyone can read.

บล็อกเชนคือสมุดบัญชีสาธารณะที่ใครก็อ่านได้

จุดที่คนไทยพลาดบ่อย

ledger — ledger = สมุดบัญชีที่บันทึกทุกรายการเข้าออก (คำนักบัญชี) คริปโตยืมมาใช้ว่า distributed ledger — Ledger ยังเป็นยี่ห้อกระเป๋าฮาร์ดแวร์เก็บคริปโตด้วย

คำที่มักสับสนกับ ledger

  • ladder บันไดพาด
  • leader ผู้นำ
  • lecture การบรรยาย / คาบเลคเชอร์

คำอื่นในบทเดียวกัน (คริปโตและฟินเทค)

  • cryptocurrency สกุลเงินดิจิทัล / คริปโต
  • blockchain บล็อกเชน / ฐานข้อมูลที่แก้ย้อนหลังไม่ได้
  • token โทเคน / เหรียญดิจิทัลบนบล็อกเชน
  • mining การขุดเหรียญคริปโต
  • NFT สินทรัพย์ดิจิทัลที่มีชิ้นเดียว
  • stablecoin เหรียญคริปโตที่ตรึงราคากับเงินจริง
  • fintech เทคโนโลยีการเงิน
  • peer-to-peer ระหว่างบุคคลโดยไม่ผ่านตัวกลาง
  • transaction ธุรกรรม / รายการโอนเงิน
  • decentralized ไร้ศูนย์กลาง / ไม่มีใครควบคุมคนเดียว
  • private key กุญแจลับสำหรับเข้ากระเป๋าคริปโต
  • altcoin เหรียญคริปโตอื่นที่ไม่ใช่บิตคอยน์
  • rug pull โปรเจกต์คริปโตที่ผู้สร้างเชิดเงินหนี
