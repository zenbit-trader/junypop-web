efficientคำคุณศัพท์

/ɪˈfɪʃnt/ · ระดับ B1

อิ-ฟิ-เชินท์

มีประสิทธิภาพ(ไม่สิ้นเปลือง)

ตัวอย่างประโยค

The new system is more efficient than the old one.

ระบบใหม่มีประสิทธิภาพมากกว่าระบบเก่า

จุดที่คนไทยพลาดบ่อย

efficient — efficient = ทำได้ดีโดยไม่เปลืองเวลา/เงิน ส่วน effective = ได้ผลตามเป้า — energy-efficient = ประหยัดพลังงาน

คำที่มักสับสนกับ efficient

  • effective มีผลบังคับใช้ / ได้ผล

คำอื่นในบทเดียวกัน (การผลิตและคุณภาพ)

  • manufacture ผลิต(ในโรงงาน)
  • assembly line สายการประกอบ
  • inspect ตรวจสอบอย่างละเอียด
  • defect ข้อบกพร่อง / ตำหนิ(ในสินค้า)
  • durable ทนทาน
  • raw material วัตถุดิบ
  • machinery เครื่องจักร(โดยรวม)
  • output ผลผลิต / ปริมาณที่ผลิตได้
  • standard มาตรฐาน
  • malfunction ทำงานผิดปกติ / ขัดข้อง
  • shortage การขาดแคลน(สินค้า/แรงงาน)
  • component ชิ้นส่วนประกอบ
  • recall เรียกคืนสินค้า

จำ efficient ให้ติดด้วยการเล่น
