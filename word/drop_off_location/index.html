จุดที่คนไทยพลาดบ่อย

drop-off location — คู่กับ pick-up location (จุดรับรถ) — คืนคนละที่กับที่รับเรียก one-way rental มีค่าธรรมเนียมเพิ่ม และคืนรถหลังเวลาทำการใช้ key drop box

คำอื่นในบทเดียวกัน (เช่ารถและประกัน)

  • rental agreement สัญญาเช่ารถ
  • automatic เกียร์อัตโนมัติ
  • manual เกียร์ธรรมดา / เกียร์กระปุก
  • unlimited mileage ไม่จำกัดระยะทาง
  • full coverage ประกันคุ้มครองเต็ม
  • excess ค่าเสียหายส่วนแรก (ประกัน)
  • scratched เป็นรอยขีดข่วน
  • dent รอยบุบ
  • fuel policy เงื่อนไขน้ำมันตอนคืนรถ
  • international driving permit ใบขับขี่สากล
  • additional driver ผู้ขับร่วม (คนขับคนที่สอง)
  • child seat คาร์ซีทเด็ก
  • GPS ระบบนำทาง GPS
