recommendation letterคำนาม

/ˌrekəmenˈdeɪʃn ˌletər/ · ระดับ B2

เรค-คอม-เมน-เด-ชั่น เล็ท-เทอร์

จดหมายรับรองจากอาจารย์

ตัวอย่างประโยค

Ask for a recommendation letter at least a month before the deadline.

ขอจดหมายรับรองจากอาจารย์อย่างน้อยหนึ่งเดือนก่อนถึงกำหนด

จุดที่คนไทยพลาดบ่อย

recommendation letter — recommendation letter หรือ letter of recommendation = จดหมายจากอาจารย์/หัวหน้าที่รับรองความสามารถ มหาวิทยาลัยมักขอ 2–3 ฉบับ — ส่งข้อมูลให้ผู้เขียนด้วยว่าอยากให้เน้นอะไร

คำที่มักสับสนกับ recommendation letter

  • reference หนังสือรับรอง / คนรับรอง

คำอื่นในบทเดียวกัน (สมัครเรียนต่อ)

  • bachelor's degree ปริญญาตรี
  • master's degree ปริญญาโท
  • PhD ปริญญาเอก
  • tuition fee ค่าเทอม
  • personal statement เรียงความแนะนำตัวเพื่อสมัครเรียน
  • acceptance letter จดหมายตอบรับเข้าเรียน
  • faculty คณะ (ในมหาวิทยาลัย)
  • program หลักสูตร / สาขาที่เรียน
  • intake รอบรับเข้าเรียน
  • prerequisite วิชาที่ต้องเรียนมาก่อน
  • GPA เกรดเฉลี่ยสะสม
  • international student นักศึกษาต่างชาติ
  • student visa วีซ่านักเรียน
