modeคำนาม

/moʊd/ · ระดับ B2

โหมด

ฐานนิยม (ค่าที่พบบ่อยสุด)

ตัวอย่างประโยค

In 2, 3, 3, 5 the mode is three because it appears most often.

ใน 2, 3, 3, 5 ฐานนิยมคือสาม เพราะปรากฏบ่อยที่สุด

จุดที่คนไทยพลาดบ่อย

mode — mode = ค่าที่ซ้ำมากสุด (จำว่า mode = most) — ในชีวิตประจำวัน mode = โหมด (airplane mode, dark mode) คนละความหมายกัน

  • mean ค่าเฉลี่ย (สถิติ)
