seedlessคำคุณศัพท์

/ˈsiːdləs/ · ระดับ B1

ซีด-เลิส

ไม่มีเมล็ด

ตัวอย่างประโยค

I prefer seedless grapes.

ฉันชอบองุ่นไร้เมล็ดมากกว่า

จุดที่คนไทยพลาดบ่อย

seedless — seed + -less (ไม่มี) = ไม่มีเมล็ด เช่น seedless grapes, seedless watermelon — รูปแบบเดียวกับ sugarless (ไม่มีน้ำตาล), boneless (ไม่มีกระดูก)

คำอื่นในบทเดียวกัน (จากสวนสู่ตลาด)

  • bunch พวง / หวี / เครือ (ผลไม้)
  • core แกนกลางผลไม้
  • rind เปลือกหนา (แตงโม / ส้ม / ชีส)
  • pit เมล็ดแข็งตรงกลางผลไม้
  • ripe สุก (ผลไม้)
  • rotten เน่า
  • wilted เหี่ยว (ผัก / ดอกไม้)
  • dried อบแห้ง / ตากแห้ง
  • pick เด็ด / เก็บ (ผลไม้จากต้น)
  • orchard สวนผลไม้
  • farmer เกษตรกร / ชาวไร่ชาวนา
  • pickle ผักดอง / แตงกวาดอง
  • jam แยม

จำ seedless ให้ติดด้วยการเล่น
