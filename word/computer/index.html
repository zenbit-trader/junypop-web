จุดที่คนไทยพลาดบ่อย

computer — คนไทยเรียกสั้นๆ ว่า "คอม" แต่ภาษาอังกฤษต้องพูดเต็ม computer — รีสตาร์ทเครื่อง = restart the computer แก้ได้ทุกปัญหา 90%! 😄

คำที่มักสับสนกับ computer

  • calculator เครื่องคิดเลข

คำอื่นในบทเดียวกัน (ในออฟฟิศ)

  • office ออฟฟิศ / ที่ทำงาน
  • desk โต๊ะทำงาน
  • keyboard คีย์บอร์ด / แป้นพิมพ์
  • mouse เมาส์
  • monitor จอคอมพิวเตอร์
  • printer เครื่องพิมพ์ / ปริ้นเตอร์
  • document เอกสาร
  • folder แฟ้ม / โฟลเดอร์
  • stapler ที่เย็บกระดาษ / แม็ก
  • whiteboard กระดานไวท์บอร์ด
  • calendar ปฏิทิน
  • colleague เพื่อนร่วมงาน
  • boss หัวหน้า / เจ้านาย
