จุดที่คนไทยพลาดบ่อย

challenge — คนไทยพูด "ชาเลนจ์" ในโซเชียลตรงศัพท์ — งานยากแต่น่าลอง = challenging (ท้าทาย ความหมายเชิงบวก)

คำที่มักสับสนกับ challenge

  • change เงินทอน
  • channel ช่อง (ยูทูบ/สตรีม)

คำอื่นในบทเดียวกัน (สู้เพื่อชัยชนะ)

  • win ชนะ
  • lose แพ้
  • victory ชัยชนะ
  • defeat เอาชนะ / ความพ่ายแพ้
  • opponent คู่แข่ง / ฝ่ายตรงข้าม
  • rank แรงค์ / อันดับ
  • tournament ทัวร์นาเมนต์ / การแข่งขัน
  • champion แชมป์
  • prize รางวัล
  • high score คะแนนสูงสุด
  • level up เลเวลอัป / อัปเลเวล
  • practice ฝึกซ้อม
  • improve เก่งขึ้น / พัฒนา

จำ challenge ให้ติดด้วยการเล่น
