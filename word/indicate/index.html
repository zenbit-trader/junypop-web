จุดที่คนไทยพลาดบ่อย

indicate — indicate ใช้กับหลักฐาน ตัวเลข สัญญาณ ที่ "ชี้" ไปทางคำตอบ — คู่กับ show และ suggest ซึ่งออกข้อสอบเป็นชุดเดียวกัน

คำอื่นในบทเดียวกัน (กริยาอ่านจับใจความ)

  • skim อ่านผ่านๆ / อ่านคร่าวๆ
  • portray วาดภาพ / นำเสนอ (ตัวละคร)
  • convey สื่อ / ถ่ายทอด (ความหมาย)
  • define ให้คำจำกัดความ / นิยาม
  • identify ระบุ / ชี้ตัว
  • state กล่าว / ระบุไว้
  • illustrate แสดงให้เห็น / ยกตัวอย่างประกอบ
  • imply บอกเป็นนัย
  • infer อนุมาน / สรุปจากหลักฐาน
  • evaluate ประเมิน / ประเมินค่า
  • conclude สรุป / ลงความเห็น
  • interpret ตีความ
  • refer to หมายถึง / อ้างถึง

จำ indicate ให้ติดด้วยการเล่น
