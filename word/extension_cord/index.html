extension cordคำนาม

/ɪkˈstenʃən kɔːrd/ · ระดับ B1

อิค-สเตน-ชั่น คอร์ด

ปลั๊กพ่วง / สายต่อ

ตัวอย่างประโยค

Run an extension cord from the wall to the desk.

ลากปลั๊กพ่วงจากผนังมาที่โต๊ะทำงาน

จุดที่คนไทยพลาดบ่อย

extension cord — extension cord (อเมริกัน) หรือ extension lead (อังกฤษ) — แบบที่มีหลายช่องเรียก power strip และ cord = สายไฟแบบนุ่ม

คำที่มักสับสนกับ extension cord

  • extension การขอเลื่อนส่งงาน
  • charger สายชาร์จ / ที่ชาร์จ

คำอื่นในบทเดียวกัน (ซ่อมของในบ้าน)

  • spare part อะไหล่
  • plunger ที่ปั๊มชักโครก
  • circuit breaker เบรกเกอร์ / สวิตช์ตัดไฟ
  • unplug ถอดปลั๊ก
  • jammed ติดขัด / ค้าง
  • short circuit ไฟฟ้าลัดวงจร
  • drip หยดติ๋ง
  • rusty เป็นสนิม
  • switch สวิตช์ไฟ
  • plug ปลั๊กไฟ (หัวเสียบ)
  • outlet เต้ารับไฟฟ้า (รูปลั๊กที่ผนัง)
  • loosen คลายให้หลวม
  • tighten ขันให้แน่น
