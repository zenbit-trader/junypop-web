จุดที่คนไทยพลาดบ่อย

update — ทับศัพท์ตรงตัว — patch (แพตช์) = อัปเดตย่อยที่แก้บั๊ก ส่วนข่าวคราวล่าสุดก็เรียก update ได้ (any updates?)

คำอื่นในบทเดียวกัน (เล่นออนไลน์)

  • online ออนไลน์
  • offline ออฟไลน์
  • download ดาวน์โหลด
  • install ติดตั้ง
  • server เซิร์ฟเวอร์
  • lag อาการแล็ก / หน่วง
  • connection การเชื่อมต่อ / สัญญาณเน็ต
  • account บัญชีผู้ใช้ / แอคเคานต์
  • log in เข้าสู่ระบบ
  • username ชื่อผู้ใช้
  • avatar อวตาร / ตัวแทนในเกม
  • match แมตช์ / เกมหนึ่งตา
  • teammate เพื่อนร่วมทีม

จำ update ให้ติดด้วยการเล่น

ทบทวนคำนี้พร้อมอีก 98 คำในหมวดเกมมิ่ง ฟรี ไม่ต้องติดตั้ง
