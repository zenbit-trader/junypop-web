/ɪˈmoʊt/ · ระดับ B1

อี-โมท

อีโมท / ท่าแสดงอารมณ์ในเกม

ตัวอย่างประโยค

He used a dance emote after winning.

ชนะปุ๊บเขาก็กดอีโมทเต้นเลย

จุดที่คนไทยพลาดบ่อย

emote — มาจาก emotion (อารมณ์) — อีโมทในเกม อิโมจิ (emoji) ในแชท เป็นญาติกันหมด

คำที่มักสับสนกับ emote

  • emoji อีโมจิ รูปหน้าแสดงอารมณ์
  • remote ทำงานจากที่บ้านหรือที่ไหนก็ได้

คำอื่นในบทเดียวกัน (สตรีมและแชท)

  • stream สตรีม / ถ่ายทอดสด
  • streamer สตรีมเมอร์
  • live ถ่ายทอดสด / ไลฟ์
  • viewer ผู้ชม
  • chat แชท / คุยกัน
  • comment คอมเมนต์ / ความคิดเห็น
  • follower ผู้ติดตาม
  • subscribe กดติดตามช่อง
  • channel ช่อง (ยูทูบ/สตรีม)
  • clip คลิปวิดีโอ
  • highlight ช่วงเด็ด / ไฮไลต์
  • donate โดเนท / บริจาค
  • go viral ดังเป็นไวรัล

จำ emote ให้ติดด้วยการเล่น
