voice assistantคำนาม

/ˈvɔɪs əˌsɪstənt/ · ระดับ B1

วอยซ์ อะ-ซิส-เทินต์

ผู้ช่วยสั่งงานด้วยเสียง

ตัวอย่างประโยค

Ask the voice assistant to set an alarm for six.

สั่งผู้ช่วยเสียงให้ตั้งนาฬิกาปลุกตอนหกโมง

จุดที่คนไทยพลาดบ่อย

voice assistant — voice assistant = Siri, Alexa, Google Assistant — ใช้คำสั่งแบบ "Hey Siri, call Mom" และ voice command = คำสั่งเสียง, voice recognition = ระบบรู้จำเสียง

คำอื่นในบทเดียวกัน (AI และระบบอัตโนมัติ)

  • artificial intelligence ปัญญาประดิษฐ์ (AI)
  • chatbot แชตบอต / โปรแกรมตอบแชตอัตโนมัติ
  • machine learning การเรียนรู้ของเครื่อง
  • prompt พรอมต์ / คำสั่งที่พิมพ์บอก AI
  • automation ระบบอัตโนมัติ
  • automate ทำให้เป็นอัตโนมัติ
  • generate สร้างขึ้น (โดยโปรแกรม/AI)
  • bot บอต / โปรแกรมทำงานแทนคน
  • workflow ขั้นตอนการทำงาน / ลำดับงาน
  • dataset ชุดข้อมูล (สำหรับสอน AI)
  • predict ทำนาย / คาดการณ์
  • deepfake ดีปเฟก / วิดีโอปลอมที่ AI สร้าง
  • accuracy ความแม่นยำ
