fair useคำนาม

/ˌfer ˈjuːs/ · ระดับ B2

แฟร์ ยูส

การใช้งานลิขสิทธิ์โดยชอบธรรม

ตัวอย่างประโยค

Quoting two lines of a song in a review is usually fair use.

การยกเนื้อเพลงสองบรรทัดมาเขียนรีวิวมักถือเป็นการใช้โดยชอบธรรม

จุดที่คนไทยพลาดบ่อย

fair use — fair use = ใช้งานมีลิขสิทธิ์ได้โดยไม่ขอ ถ้าเพื่อการศึกษา วิจารณ์ หรือข่าว และไม่กระทบรายได้เจ้าของ — ยูทูบเบอร์อ้างคำนี้บ่อย แต่แค่ใส่เครดิตไม่ได้แปลว่า fair use

คำที่มักสับสนกับ fair use

  • fare ค่าโดยสาร

คำอื่นในบทเดียวกัน (ทรัพย์สินทางปัญญา)

  • intellectual property ทรัพย์สินทางปัญญา
  • copyright ลิขสิทธิ์
  • trademark เครื่องหมายการค้า
  • patent สิทธิบัตร
  • license ใบอนุญาต / สิทธิ์การใช้งาน
  • infringement การละเมิดสิทธิ์
  • invention สิ่งประดิษฐ์
  • royalty ค่าลิขสิทธิ์ที่ได้ทุกครั้งที่งานถูกใช้
  • piracy การละเมิดลิขสิทธิ์ / ของเถื่อน
  • trade secret ความลับทางการค้า
  • public domain สมบัติสาธารณะ / งานที่หมดลิขสิทธิ์แล้ว
  • exclusive แต่เพียงผู้เดียว
  • logo โลโก้ / ตราสัญลักษณ์
