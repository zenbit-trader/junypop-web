data breachคำนาม

/ˈdeɪtə briːtʃ/ · ระดับ B2

เด-ตา บรีช

ข้อมูลรั่วไหล

ตัวอย่างประโยค

After the data breach, the bank told everyone to change their passwords.

หลังข้อมูลรั่วไหล ธนาคารแจ้งให้ทุกคนเปลี่ยนรหัสผ่าน

จุดที่คนไทยพลาดบ่อย

data breach — breach = การละเมิด/ทะลุเข้ามา data breach คือข้อมูลหลุดออกไปโดยไม่ได้รับอนุญาต — ข่าวข้อมูลคนไทยหลุดจากหน่วยงานต่างๆ ใช้คำนี้ทั้งนั้น

คำที่มักสับสนกับ data breach

  • beach ชายหาด

คำอื่นในบทเดียวกัน (ความปลอดภัยไซเบอร์)

  • cybersecurity ความปลอดภัยไซเบอร์
  • hacker แฮกเกอร์ / ผู้เจาะระบบ
  • malware มัลแวร์ / โปรแกรมประสงค์ร้าย
  • virus ไวรัสคอมพิวเตอร์
  • firewall ไฟร์วอลล์ / กำแพงกันผู้บุกรุก
  • encrypt เข้ารหัสข้อมูล
  • authentication การยืนยันตัวตน
  • ransomware มัลแวร์เรียกค่าไถ่
  • patch แพตช์ / ตัวแก้ช่องโหว่
  • vulnerability ช่องโหว่ / จุดอ่อนของระบบ
  • antivirus โปรแกรมป้องกันไวรัส
  • VPN เครือข่ายส่วนตัวเสมือน / อุโมงค์เน็ตที่ปลอดภัย
  • access สิทธิ์เข้าใช้ / การเข้าถึง
