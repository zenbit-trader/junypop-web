จุดที่คนไทยพลาดบ่อย

bento — bento = ข้าวกล่องแบบญี่ปุ่นที่จัดเป็นช่องสวยงาม ฝรั่งพูดว่า bento box — ส่วนข้าวกล่องทั่วไปคือ lunch box

คำที่มักสับสนกับ bento

  • bagel เบเกิล (ขนมปังวงแหวน)

คำอื่นในบทเดียวกัน (อาหารญี่ปุ่นและเกาหลี)

  • sushi ซูชิ
  • sashimi ปลาดิบ (ซาชิมิ)
  • ramen ราเมง
  • tempura เทมปุระ (ของทอดชุบแป้ง)
  • wasabi วาซาบิ
  • soy sauce ซีอิ๊ว / โชยุ
  • miso มิโซะ (เต้าเจี้ยวญี่ปุ่น)
  • tofu เต้าหู้
  • seaweed สาหร่ายทะเล
  • kimchi กิมจิ
  • bibimbap ข้าวยำเกาหลี
  • Korean barbecue ปิ้งย่างเกาหลี
  • dumpling เกี๊ยว / ซาลาเปาไส้
