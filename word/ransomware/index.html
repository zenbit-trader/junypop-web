ransomwareคำนาม

/ˈrænsəmwer/ · ระดับ B2

แรน-ซัม-แวร์

มัลแวร์เรียกค่าไถ่

ตัวอย่างประโยค

Ransomware locked every file in the hospital until they paid.

แรนซัมแวร์ล็อกไฟล์ทุกไฟล์ของโรงพยาบาลจนกว่าจะจ่ายเงิน

จุดที่คนไทยพลาดบ่อย

ransomware — ransom = ค่าไถ่ ransomware จึงล็อกไฟล์แล้วเรียกเงิน (มักเป็นคริปโต) — โรงพยาบาลและหน่วยงานไทยโดนบ่อย วิธีกันที่ดีที่สุดคือ backup

คำที่มักสับสนกับ ransomware

  • random สุ่ม

คำอื่นในบทเดียวกัน (ความปลอดภัยไซเบอร์)

  • cybersecurity ความปลอดภัยไซเบอร์
  • hacker แฮกเกอร์ / ผู้เจาะระบบ
  • malware มัลแวร์ / โปรแกรมประสงค์ร้าย
  • virus ไวรัสคอมพิวเตอร์
  • firewall ไฟร์วอลล์ / กำแพงกันผู้บุกรุก
  • encrypt เข้ารหัสข้อมูล
  • data breach ข้อมูลรั่วไหล
  • authentication การยืนยันตัวตน
  • patch แพตช์ / ตัวแก้ช่องโหว่
  • vulnerability ช่องโหว่ / จุดอ่อนของระบบ
  • antivirus โปรแกรมป้องกันไวรัส
  • VPN เครือข่ายส่วนตัวเสมือน / อุโมงค์เน็ตที่ปลอดภัย
  • access สิทธิ์เข้าใช้ / การเข้าถึง
