editคำกริยา

/ˈedɪt/ · ระดับ A2

เอ็ด-ดิท

แก้ไข (โพสต์ รูป หรือคลิป)

ตัวอย่างประโยค

I had to edit my post because of a typo.

ต้องแก้โพสต์เพราะพิมพ์ผิด

จุดที่คนไทยพลาดบ่อย

edit — edited จะขึ้นข้างโพสต์ที่แก้แล้ว — คนทำงานตัดต่อคลิปเรียก editor หรือย่อว่า edit สั้น ๆ ก็ได้

คำที่มักสับสนกับ edit

  • exit ทางออก

คำอื่นในบทเดียวกัน (โพสต์แรกของคุณ)

  • post โพสต์ สิ่งที่เผยแพร่ลงโซเชียล
  • upload อัปโหลด ส่งไฟล์ขึ้นเน็ต
  • caption ข้อความประกอบรูปหรือคลิป
  • hashtag แฮชแท็ก คำค้นที่นำหน้าด้วย #
  • tag แท็ก ติดชื่อคนลงในโพสต์
  • mention เอ่ยถึง พิมพ์ @ ถึงใครสักคน
  • album อัลบั้มรูป
  • filter ฟิลเตอร์แต่งรูปหรือหน้า
  • crop ตัดขอบรูปให้เหลือเฉพาะส่วนที่ต้องการ
  • pin ปักหมุด ตรึงโพสต์ไว้บนสุด
  • delete ลบ
  • feed ฟีด หน้ารวมโพสต์ที่ไหลขึ้นมาเรื่อย ๆ
  • scroll เลื่อนหน้าจอขึ้นลง
