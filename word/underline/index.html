จุดที่คนไทยพลาดบ่อย

underline — the underlined word = คำที่ขีดเส้นใต้ไว้ (โจทย์หาความหมายคำ) — ต่างจาก highlight ที่ใช้ปากกาเน้นสี

คำที่มักสับสนกับ underline

  • outline โครงร่าง (ของรายงาน)
  • understand เข้าใจ

คำอื่นในบทเดียวกัน (คำสั่งในข้อสอบ)

  • choose เลือก
  • complete เติมให้สมบูรณ์ / ทำให้เสร็จ
  • blank ช่องว่าง (ให้เติมคำ)
  • correct ถูกต้อง
  • incorrect ไม่ถูกต้อง / ผิด
  • option ตัวเลือก
  • according to ตามที่ (…กล่าว)
  • the following ต่อไปนี้ / ดังต่อไปนี้
  • except ยกเว้น
  • synonym คำที่มีความหมายเหมือนกัน
  • antonym คำที่มีความหมายตรงข้าม
  • true or false ถูกหรือผิด (ข้อสอบแบบ T/F)
  • open-ended ปลายเปิด / อัตนัย
