argumentคำนาม

/ˈɑːrɡjumənt/ · ระดับ B2

อาร์-กิว-เมนท์

ข้อโต้แย้งเชิงวิชาการ / เหตุผลหลัก

ตัวอย่างประโยค

A good essay has one clear argument supported by evidence.

เรียงความที่ดีมีข้อโต้แย้งหลักที่ชัดเจนหนึ่งข้อพร้อมหลักฐานสนับสนุน

จุดที่คนไทยพลาดบ่อย

argument — argument ในงานวิชาการ = จุดยืนที่คุณพิสูจน์ ไม่ใช่การทะเลาะ — อาจารย์ฝรั่งต้องการให้ "วิพากษ์" (critical) มากกว่าแค่บรรยาย เขียนแค่สรุปหนังสือจะได้เกรดต่ำ

คำที่มักสับสนกับ argument

  • agreement ข้อตกลง / สัญญา

คำอื่นในบทเดียวกัน (เขียนรายงานและวิจัย)

  • thesis วิทยานิพนธ์
  • dissertation สารนิพนธ์ / งานวิจัยจบ
  • citation การอ้างอิงในเนื้อหา
  • cite อ้างอิง (แหล่งที่มา)
  • bibliography บรรณานุกรม
  • plagiarism การลอกผลงาน
  • paraphrase เรียบเรียงใหม่ด้วยคำของตัวเอง
  • word count จำนวนคำที่กำหนด
  • proofread ตรวจทานคำผิด
  • outline โครงร่าง (ของรายงาน)
  • source แหล่งข้อมูลอ้างอิง
  • abstract บทคัดย่อ
  • extension การขอเลื่อนส่งงาน
