ตัวอย่างประโยค

This program takes two years and includes an internship.

หลักสูตรนี้ใช้เวลาสองปีและมีการฝึกงานรวมอยู่ด้วย

จุดที่คนไทยพลาดบ่อย

program — program (อเมริกัน) / programme (อังกฤษ) = หลักสูตรทั้งปริญญา ส่วน course ในอเมริกา = วิชาเดียว แต่ในอังกฤษ course อาจหมายถึงทั้งหลักสูตรได้ — สับสนบ่อยมาก

คำที่มักสับสนกับ program

  • project โปรเจกต์ / โครงการ
  • progress ความคืบหน้า

คำอื่นในบทเดียวกัน (สมัครเรียนต่อ)

  • bachelor's degree ปริญญาตรี
  • master's degree ปริญญาโท
  • PhD ปริญญาเอก
  • tuition fee ค่าเทอม
  • personal statement เรียงความแนะนำตัวเพื่อสมัครเรียน
  • recommendation letter จดหมายรับรองจากอาจารย์
  • acceptance letter จดหมายตอบรับเข้าเรียน
  • faculty คณะ (ในมหาวิทยาลัย)
  • intake รอบรับเข้าเรียน
  • prerequisite วิชาที่ต้องเรียนมาก่อน
  • GPA เกรดเฉลี่ยสะสม
  • international student นักศึกษาต่างชาติ
  • student visa วีซ่านักเรียน
