จุดที่คนไทยพลาดบ่อย

subscribe — "กดซับ" ของชาวยูทูบไทยย่อจาก subscribe — ผู้ติดตามช่องเรียก subscriber (ซับสไครเบอร์)

คำอื่นในบทเดียวกัน (สตรีมและแชท)

  • stream สตรีม / ถ่ายทอดสด
  • streamer สตรีมเมอร์
  • live ถ่ายทอดสด / ไลฟ์
  • viewer ผู้ชม
  • chat แชท / คุยกัน
  • comment คอมเมนต์ / ความคิดเห็น
  • follower ผู้ติดตาม
  • channel ช่อง (ยูทูบ/สตรีม)
  • clip คลิปวิดีโอ
  • highlight ช่วงเด็ด / ไฮไลต์
  • donate โดเนท / บริจาค
  • emote อีโมท / ท่าแสดงอารมณ์ในเกม
  • go viral ดังเป็นไวรัล

จำ subscribe ให้ติดด้วยการเล่น
