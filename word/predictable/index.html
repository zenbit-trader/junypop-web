predictableคำคุณศัพท์

/prɪˈdɪktəbl/ · ระดับ B1

พริ-ดิค-ทะ-เบิล

เดาได้ง่าย

ตัวอย่างประโยค

The ending was predictable, I guessed it on page ten.

ตอนจบเดาง่ายมาก ฉันทายถูกตั้งแต่หน้าสิบ

จุดที่คนไทยพลาดบ่อย

predictable — predict = ทำนาย -able = ได้ — คำติที่สุภาพแต่เจ็บ a bit predictable ส่วนตรงข้ามคือ unpredictable (คาดเดาไม่ได้) ซึ่งเป็นคำชมสำหรับนิยาย

คำที่มักสับสนกับ predictable

  • profitable ทำกำไรได้

คำอื่นในบทเดียวกัน (บรรยายความรู้สึกหลังอ่าน)

  • gripping ตรึงใจ / ชวนติดตามมาก
  • fast-paced ดำเนินเรื่องเร็ว
  • slow-paced ดำเนินเรื่องช้า
  • heartwarming อบอุ่นหัวใจ
  • laugh-out-loud ตลกจนหัวเราะออกมาดังๆ
  • moving ซาบซึ้งจนน้ำตาซึม
  • suspense ความระทึก / ลุ้นว่าจะเกิดอะไร
  • vivid เห็นภาพชัดเจน / สดใส
  • relatable เข้าถึงง่าย / เหมือนชีวิตเราเลย
  • overrated ถูกชมเกินจริง
  • thought-provoking ชวนให้คิด
  • cliché พล็อตหรือสำนวนซ้ำซาก
  • satisfying จบได้สมใจ / ครบรส
