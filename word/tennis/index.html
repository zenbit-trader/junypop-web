จุดที่คนไทยพลาดบ่อย

tennis — คะแนนนับแปลก ๆ คือ 15-30-40 แล้วค่อย game ซึ่งมาจากหน้าปัดนาฬิกา

คำอื่นในบทเดียวกัน (กีฬายอดฮิต)

  • badminton แบดมินตัน
  • volleyball วอลเลย์บอล
  • boxing มวยสากล
  • muay thai มวยไทย
  • swimming ว่ายน้ำ
  • cycling การปั่นจักรยาน
  • jogging การวิ่งเหยาะ ๆ
  • golf กอล์ฟ
  • table tennis ปิงปอง
  • weightlifting กีฬายกน้ำหนัก
  • yoga mat เสื่อโยคะ
  • jump rope เชือกกระโดด
  • fun run งานวิ่งเพื่อสุขภาพระยะสั้น
