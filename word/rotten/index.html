rottenคำคุณศัพท์

/ˈrɑːtən/ · ระดับ A2

รอท-เทิ่น

เน่า

ตัวอย่างประโยค

That banana is rotten, so throw it away.

กล้วยลูกนั้นเน่าแล้ว ทิ้งไปเถอะ

จุดที่คนไทยพลาดบ่อย

rotten — rotten = เน่าเสีย ใช้กับผลไม้ ไข่ เนื้อ ไม้ — a rotten egg = ไข่เน่า; ภาษาพูด feel rotten = รู้สึกแย่มาก; สะกด t สองตัว

คำอื่นในบทเดียวกัน (จากสวนสู่ตลาด)

  • bunch พวง / หวี / เครือ (ผลไม้)
  • core แกนกลางผลไม้
  • rind เปลือกหนา (แตงโม / ส้ม / ชีส)
  • pit เมล็ดแข็งตรงกลางผลไม้
  • ripe สุก (ผลไม้)
  • wilted เหี่ยว (ผัก / ดอกไม้)
  • seedless ไม่มีเมล็ด
  • dried อบแห้ง / ตากแห้ง
  • pick เด็ด / เก็บ (ผลไม้จากต้น)
  • orchard สวนผลไม้
  • farmer เกษตรกร / ชาวไร่ชาวนา
  • pickle ผักดอง / แตงกวาดอง
  • jam แยม

จำ rotten ให้ติดด้วยการเล่น

ทบทวนคำนี้พร้อมอีก 98 คำในหมวดผลไม้และผัก · เล่นฟรี ไม่ต้องติดตั้ง
