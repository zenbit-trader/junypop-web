จุดที่คนไทยพลาดบ่อย

MVP — MVP = minimum viable product เวอร์ชันเล็กที่สุดที่พอให้ลูกค้าทดลองใช้ได้ ไม่ใช่ของสมบูรณ์ — ในกีฬา MVP = most valuable player คนละเรื่อง

คำอื่นในบทเดียวกัน (สร้างโปรดักต์)

  • prototype ต้นแบบ
  • beta เวอร์ชันทดลองก่อนปล่อยจริง
  • user ผู้ใช้
  • roadmap แผนพัฒนาตามลำดับเวลา
  • iterate ปรับปรุงซ้ำเป็นรอบๆ
  • early adopter ผู้ใช้กลุ่มแรกที่กล้าลองของใหม่
  • product-market fit สินค้าตรงใจตลาดจริง
  • demo การสาธิตสินค้า
  • user experience ประสบการณ์ผู้ใช้ (UX)
  • release ปล่อยเวอร์ชันใหม่ออกสู่ผู้ใช้
  • metric ตัวชี้วัด / ตัวเลขที่ใช้วัดผล
  • landing page หน้าเว็บหน้าเดียวสำหรับขายหรือรับสมัคร
  • waitlist รายชื่อรอคิวใช้งาน
