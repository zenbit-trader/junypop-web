interfaceคำนาม

/ˈɪntərfeɪs/ · ระดับ B1

อิน-เทอร์-เฟซ

หน้าจอการใช้งาน / ส่วนติดต่อผู้ใช้

ตัวอย่างประโยค

The new interface is clean and easy to understand.

หน้าจอการใช้งานใหม่ดูสะอาดและเข้าใจง่าย

จุดที่คนไทยพลาดบ่อย

interface — user interface ย่อ UI = หน้าตาที่ผู้ใช้เห็นและกด ส่วน UX = ประสบการณ์การใช้ทั้งหมด — ตำแหน่ง UI/UX designer เป็นงานฮิตในไทย

คำที่มักสับสนกับ interface

  • interview การสัมภาษณ์งาน

คำอื่นในบทเดียวกัน (ซอฟต์แวร์และแอป)

  • software ซอฟต์แวร์ / โปรแกรม
  • app แอปพลิเคชัน
  • operating system ระบบปฏิบัติการ
  • version เวอร์ชัน / รุ่น
  • feature ฟีเจอร์ / ฟังก์ชันการใช้งาน
  • compatible ใช้ร่วมกันได้ / รองรับ
  • default ค่าเริ่มต้น / ค่าตั้งต้น
  • plugin ปลั๊กอิน / ส่วนเสริมโปรแกรม
  • sync ซิงก์ / ทำให้ข้อมูลตรงกันทุกเครื่อง
  • permission สิทธิ์การเข้าถึง / การอนุญาต
  • open source โอเพนซอร์ส / เปิดโค้ดให้ใช้ฟรี
  • upgrade อัปเกรด / เปลี่ยนเป็นรุ่นดีขึ้น
  • user-friendly ใช้งานง่าย
