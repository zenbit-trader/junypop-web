gadgetคำนาม

/ˈɡædʒɪt/ · ระดับ B1

แกด-เจ็ท

แกดเจ็ต / อุปกรณ์ไอทีชิ้นเล็ก

ตัวอย่างประโยค

He spends all his money on new gadgets.

เขาหมดเงินไปกับแกดเจ็ตใหม่ๆ ตลอด

จุดที่คนไทยพลาดบ่อย

gadget — gadget = ของเล่นไฮเทคชิ้นเล็กๆ (หูฟัง นาฬิกา ลำโพง) ออกเสียง "แกด-เจ็ท"

คำที่มักสับสนกับ gadget

  • budget งบประมาณ / งบ
  • gate ประตูขึ้นเครื่อง / เกต

คำอื่นในบทเดียวกัน (แกดเจ็ตไอที)

  • mobile phone โทรศัพท์มือถือ
  • charger สายชาร์จ / ที่ชาร์จ
  • battery แบตเตอรี่
  • power bank พาวเวอร์แบงก์ / แบตสำรอง
  • warranty การรับประกัน
  • model รุ่น (สินค้า)
  • screen หน้าจอ
  • memory หน่วยความจำ / เมมโมรี่
  • wireless ไร้สาย
  • accessory อุปกรณ์เสริม
  • phone case เคสมือถือ
  • earbuds หูฟังไร้สายแบบใส่ในหู
  • smartwatch นาฬิกาอัจฉริยะ / สมาร์ทวอทช์

จำ gadget ให้ติดด้วยการเล่น
