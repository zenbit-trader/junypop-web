จุดที่คนไทยพลาดบ่อย

clip — คนไทยพูด "คลิป" ติดปากอยู่แล้ว — clip เดิมแปลว่า "ตัด" คลิปคือวิดีโอที่ตัดมาสั้นๆ นั่นเอง

คำอื่นในบทเดียวกัน (สตรีมและแชท)

  • stream สตรีม / ถ่ายทอดสด
  • streamer สตรีมเมอร์
  • live ถ่ายทอดสด / ไลฟ์
  • viewer ผู้ชม
  • chat แชท / คุยกัน
  • comment คอมเมนต์ / ความคิดเห็น
  • follower ผู้ติดตาม
  • subscribe กดติดตามช่อง
  • channel ช่อง (ยูทูบ/สตรีม)
  • highlight ช่วงเด็ด / ไฮไลต์
  • donate โดเนท / บริจาค
  • emote อีโมท / ท่าแสดงอารมณ์ในเกม
  • go viral ดังเป็นไวรัล

จำ clip ให้ติดด้วยการเล่น
