premisesคำนาม

/ˈpremɪsɪz/ · ระดับ B2

เพรม-มิส-เซส

บริเวณสถานที่(ของบริษัท/ร้าน)

ตัวอย่างประโยค

Smoking is not allowed anywhere on the premises.

ห้ามสูบบุหรี่ทุกจุดในบริเวณสถานที่

จุดที่คนไทยพลาดบ่อย

premises — premises ใช้รูปพหูพจน์เสมอ = ตัวอาคารพร้อมที่ดินของกิจการ — on the premises = ในบริเวณ, leave the premises = ออกจากพื้นที่

คำที่มักสับสนกับ premises

  • premium ระดับพรีเมียม / คุณภาพสูง

คำอื่นในบทเดียวกัน (อสังหาฯ และอาคารสถานที่)

  • commercial เชิงพาณิชย์ / เพื่อการค้า
  • occupancy การเข้าใช้พื้นที่ / อัตราการเข้าพัก
  • ventilation การระบายอากาศ
  • property อสังหาริมทรัพย์ / ทรัพย์สิน
  • facility สิ่งอำนวยความสะดวก / อาคารสถานที่
  • renovate ปรับปรุงซ่อมแซม(อาคาร)
  • floor space พื้นที่ใช้สอย
  • square meter ตารางเมตร
  • spacious กว้างขวาง
  • relocate ย้ายที่ตั้ง
  • plumbing ระบบประปา
  • real estate agent นายหน้าอสังหาริมทรัพย์
  • vacant ว่าง(ไม่มีคนอยู่/ใช้)

จำ premises ให้ติดด้วยการเล่น
