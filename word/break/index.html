จุดที่คนไทยพลาดบ่อย

break — พักเบรก = take a break / พักเที่ยง = lunch break — break ยังแปลว่า "ทำแตก/หัก" ได้ด้วย ดูบริบท

คำที่มักสับสนกับ break

  • bread ขนมปัง

คำอื่นในบทเดียวกัน (งานประจำวัน)

  • work ทำงาน
  • task งาน (ชิ้นหนึ่ง)
  • deadline กำหนดส่งงาน / เดดไลน์
  • busy ยุ่ง
  • project โปรเจกต์ / โครงการ
  • schedule ตารางงาน / กำหนดการ
  • priority สิ่งสำคัญอันดับแรก
  • finish ทำเสร็จ
  • submit ส่งงาน (อย่างเป็นทางการ)
  • check ตรวจสอบ
  • solve แก้ปัญหา
  • overtime การทำงานล่วงเวลา / โอที
  • day off วันหยุด (ของเรา)

จำ break ให้ติดด้วยการเล่น
