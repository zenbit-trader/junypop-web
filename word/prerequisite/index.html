prerequisiteคำนาม

/ˌpriːˈrekwəzɪt/ · ระดับ B2

พรี-เรค-ควิ-ซิท

วิชาที่ต้องเรียนมาก่อน

ตัวอย่างประโยค

Statistics is a prerequisite for this data course.

วิชาสถิติเป็นวิชาที่ต้องเรียนมาก่อนสำหรับวิชาข้อมูลนี้

จุดที่คนไทยพลาดบ่อย

prerequisite — prerequisite = สิ่งที่ต้องมีมาก่อน (pre- = ก่อน, requisite = จำเป็น) นักศึกษาเรียกสั้นๆ ว่า prereq — ระบบลงทะเบียนจะไม่ให้ลงถ้ายังไม่ผ่าน prereq

คำที่มักสับสนกับ prerequisite

  • requirement สิ่งที่บริษัทกำหนดว่าต้องมี

คำอื่นในบทเดียวกัน (สมัครเรียนต่อ)

  • bachelor's degree ปริญญาตรี
  • master's degree ปริญญาโท
  • PhD ปริญญาเอก
  • tuition fee ค่าเทอม
  • personal statement เรียงความแนะนำตัวเพื่อสมัครเรียน
  • recommendation letter จดหมายรับรองจากอาจารย์
  • acceptance letter จดหมายตอบรับเข้าเรียน
  • faculty คณะ (ในมหาวิทยาลัย)
  • program หลักสูตร / สาขาที่เรียน
  • intake รอบรับเข้าเรียน
  • GPA เกรดเฉลี่ยสะสม
  • international student นักศึกษาต่างชาติ
  • student visa วีซ่านักเรียน
