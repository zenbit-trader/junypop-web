portคำนาม

/pɔːrt/ · ระดับ B1

พอร์ต

ช่องเสียบ / พอร์ต

ตัวอย่างประโยค

This laptop has only one port, so I need an adapter.

แล็ปท็อปเครื่องนี้มีพอร์ตเดียว ฉันเลยต้องใช้ตัวแปลง

จุดที่คนไทยพลาดบ่อย

port — port = ช่องเสียบบนเครื่อง (USB port, HDMI port) และยังแปลว่าท่าเรือด้วย — ถ้าหมายถึงปลั๊กไฟที่ผนังใช้ socket หรือ outlet

คำที่มักสับสนกับ port

  • plug ปลั๊กไฟ (หัวเสียบ)
  • post โพสต์ สิ่งที่เผยแพร่ลงโซเชียล

คำอื่นในบทเดียวกัน (อุปกรณ์และเครือข่าย)

  • hardware ฮาร์ดแวร์ / อุปกรณ์คอมพิวเตอร์
  • device อุปกรณ์ / เครื่อง
  • network เครือข่าย
  • router เราเตอร์ / ตัวกระจายสัญญาณ
  • modem โมเด็ม
  • cable สายเคเบิล / สายไฟ
  • bandwidth แบนด์วิดท์ / ความกว้างช่องสัญญาณ
  • hotspot ฮอตสปอต / จุดแชร์เน็ตจากมือถือ
  • Bluetooth บลูทูธ
  • USB ยูเอสบี / แฟลชไดรฟ์
  • hard drive ฮาร์ดดิสก์ / ที่เก็บข้อมูลในเครื่อง
  • processor หน่วยประมวลผล / ซีพียู
  • Ethernet อีเทอร์เน็ต / เน็ตแบบสาย LAN
