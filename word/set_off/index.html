set offวลี

/set ɔːf/ · ระดับ B1

เซ็ท ออฟ

ออกเดินทาง (เริ่มทริป)

ตัวอย่างประโยค

We set off for Khao Yai at six in the morning.

เราออกเดินทางไปเขาใหญ่ตอนหกโมงเช้า

จุดที่คนไทยพลาดบ่อย

set off — แยกไม่ได้เมื่อแปลว่าออกเดินทาง (ฝั่งอังกฤษใช้บ่อย เหมือน set out) — ระวัง set off the alarm = ทำสัญญาณเตือนดัง

คำอื่นในบทเดียวกัน (ออกเดินทาง)

  • get away หนีไปพักผ่อน หลุดพ้น
  • get in ขึ้นรถ (เก๋ง แท็กซี่) / มาถึง
  • get out ลงจากรถ / ออกไปข้างนอก
  • pull over จอดรถข้างทาง
  • slow down ชะลอความเร็ว ช้าลง
  • speed up เร่งความเร็ว
  • turn around กลับรถ หันกลับ
  • break down รถเสียกลางทาง / ร้องไห้ฟูมฟาย
  • look around เดินดูรอบๆ
  • show around พาเดินชม พาทัวร์
  • see off ไปส่งที่สนามบิน/สถานี
  • run into บังเอิญเจอ
  • come along ไปด้วยกัน ติดสอยห้อยตาม

จำ set off ให้ติดด้วยการเล่น
