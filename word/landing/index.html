landingคำนาม

/ˈlændɪŋ/ · ระดับ A2

แลน-ดิ้ง

การลงจอด

ตัวอย่างประโยค

It was a smooth landing despite the rain.

เครื่องลงจอดได้นุ่มนวลแม้ฝนจะตก

จุดที่คนไทยพลาดบ่อย

landing — กริยาคือ land เช่น The plane landed safely ส่วน landing เป็นคำนาม ตรงข้ามกับ takeoff

คำที่มักสับสนกับ landing

  • arrival การมาถึง / ขาเข้า
  • departure การออกเดินทาง / ขาออก

คำอื่นในบทเดียวกัน (บนเครื่องบิน)

  • cabin crew ลูกเรือ / พนักงานต้อนรับบนเครื่องบิน
  • seatbelt เข็มขัดนิรภัย
  • fasten รัด / คาด (เข็มขัด)
  • turbulence สภาพอากาศแปรปรวน / อาการเครื่องสั่น
  • overhead bin ช่องเก็บสัมภาระเหนือศีรษะ
  • tray table โต๊ะพับหน้าที่นั่ง
  • take off ถอด (เสื้อผ้า รองเท้า)
  • meal มื้ออาหาร
  • pilot นักบิน
  • headphones หูฟัง
  • lavatory ห้องน้ำ (บนเครื่องบิน)
  • blanket ผ้าห่ม
  • airplane เครื่องบิน

จำ landing ให้ติดด้วยการเล่น

ทบทวนคำนี้พร้อมอีก 95 คำในหมวดสนามบิน ฟรี ไม่ต้องติดตั้ง
