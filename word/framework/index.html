frameworkคำนาม

/ˈfreɪmwɜːrk/ · ระดับ B2

เฟรม-เวิร์ก

เฟรมเวิร์ก / โครงสำเร็จรูปสำหรับเขียนโปรแกรม

ตัวอย่างประโยค

Flutter is a framework for building mobile apps.

Flutter เป็นเฟรมเวิร์กสำหรับสร้างแอปมือถือ

จุดที่คนไทยพลาดบ่อย

framework — framework = โครงพร้อมใช้ที่ช่วยให้เขียนแอปเร็วขึ้น (React, Flutter, Laravel) — ในธุรกิจก็ใช้: a framework for decision-making = กรอบแนวคิดในการตัดสินใจ

คำที่มักสับสนกับ framework

  • homework การบ้าน
  • network เครือข่าย

คำอื่นในบทเดียวกัน (เขียนโค้ดเบื้องต้น)

  • code โค้ด / ชุดคำสั่งโปรแกรม
  • bug บั๊ก / ข้อผิดพลาดในโปรแกรม
  • debug ดีบั๊ก / ไล่หาและแก้บั๊ก
  • deploy ดีพลอย / นำระบบขึ้นใช้งานจริง
  • developer นักพัฒนาโปรแกรม / โปรแกรมเมอร์
  • variable ตัวแปร
  • function ฟังก์ชัน / ชุดคำสั่งที่เรียกใช้ซ้ำได้
  • loop ลูป / การวนซ้ำ
  • syntax ไวยากรณ์ของภาษาโปรแกรม
  • compile คอมไพล์ / แปลงโค้ดให้เครื่องรันได้
  • command คำสั่ง (ที่พิมพ์ให้เครื่องทำ)
  • repository ที่เก็บโค้ดของโปรเจกต์
  • front end ฝั่งหน้าบ้าน / ส่วนที่ผู้ใช้เห็น
