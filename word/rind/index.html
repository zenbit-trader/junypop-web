rindคำนาม

/raɪnd/ · ระดับ B2

ไรนด์

เปลือกหนา (แตงโม / ส้ม / ชีส)

ตัวอย่างประโยค

Don't eat the watermelon rind.

อย่ากินเปลือกแตงโม

จุดที่คนไทยพลาดบ่อย

rind — rind = เปลือกหนาแข็ง เช่น watermelon rind, lemon rind, cheese rind — ส่วน peel = เปลือกที่ปอกได้ (กล้วย ส้ม) และ skin = เปลือกบาง (แอปเปิ้ล องุ่น)

คำที่มักสับสนกับ rind

  • ring แหวน

คำอื่นในบทเดียวกัน (จากสวนสู่ตลาด)

  • bunch พวง / หวี / เครือ (ผลไม้)
  • core แกนกลางผลไม้
  • pit เมล็ดแข็งตรงกลางผลไม้
  • ripe สุก (ผลไม้)
  • rotten เน่า
  • wilted เหี่ยว (ผัก / ดอกไม้)
  • seedless ไม่มีเมล็ด
  • dried อบแห้ง / ตากแห้ง
  • pick เด็ด / เก็บ (ผลไม้จากต้น)
  • orchard สวนผลไม้
  • farmer เกษตรกร / ชาวไร่ชาวนา
  • pickle ผักดอง / แตงกวาดอง
  • jam แยม
