casualคำคุณศัพท์

/ˈkæʒuəl/ · ระดับ B1

แคช-ชวล

เล่นง่ายๆ สบายๆ

ตัวอย่างประโยค

I only play casual games on my phone.

ฉันเล่นแค่เกมง่ายๆ ในมือถือ

จุดที่คนไทยพลาดบ่อย

casual — casual = สบายๆ ไม่จริงจัง — ใช้กับเสื้อผ้าได้ด้วย: casual clothes = ชุดลำลอง (ตรงข้าม formal)

คำอื่นในบทเดียวกัน (เลือกแนวเกม)

  • genre แนวเกม / ประเภท
  • action แนวแอ็กชัน / ฉากบู๊
  • racing แนวแข่งรถ / แข่งความเร็ว
  • puzzle เกมปริศนา
  • shooting game เกมยิง
  • horror แนวสยองขวัญ
  • sports game เกมกีฬา
  • strategy แนววางแผน / กลยุทธ์
  • role-playing แนวสวมบทบาท / RPG
  • simulation แนวจำลองชีวิต
  • arcade เกมตู้ / อาร์เคด
  • board game บอร์ดเกม / เกมกระดาน
  • mobile game เกมมือถือ

จำ casual ให้ติดด้วยการเล่น
