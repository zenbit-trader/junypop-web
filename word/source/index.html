sourceคำนาม

/sɔːrs/ · ระดับ B1

ซอร์ส

แหล่งข้อมูลอ้างอิง

ตัวอย่างประโยค

Wikipedia is not an acceptable source for this essay.

วิกิพีเดียไม่ใช่แหล่งข้อมูลอ้างอิงที่ยอมรับได้สำหรับเรียงความนี้

จุดที่คนไทยพลาดบ่อย

source — source = แหล่งที่มาของข้อมูล primary source = ข้อมูลต้นทาง (สัมภาษณ์ สถิติ) secondary source = งานวิเคราะห์ของคนอื่น — ใช้บทความ peer-reviewed จากฐานข้อมูลห้องสมุดจะปลอดภัยที่สุด

คำที่มักสับสนกับ source

  • course วิชา / รายวิชา

คำอื่นในบทเดียวกัน (เขียนรายงานและวิจัย)

  • thesis วิทยานิพนธ์
  • dissertation สารนิพนธ์ / งานวิจัยจบ
  • citation การอ้างอิงในเนื้อหา
  • cite อ้างอิง (แหล่งที่มา)
  • bibliography บรรณานุกรม
  • plagiarism การลอกผลงาน
  • paraphrase เรียบเรียงใหม่ด้วยคำของตัวเอง
  • word count จำนวนคำที่กำหนด
  • proofread ตรวจทานคำผิด
  • outline โครงร่าง (ของรายงาน)
  • argument ข้อโต้แย้งเชิงวิชาการ / เหตุผลหลัก
  • abstract บทคัดย่อ
  • extension การขอเลื่อนส่งงาน
