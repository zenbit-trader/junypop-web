only childคำนาม

/ˈoʊnli tʃaɪld/ · ระดับ A2

โอน-ลี่ ไชลด์

ลูกคนเดียว

ตัวอย่างประโยค

I am an only child, so I never had to share my toys.

ฉันเป็นลูกคนเดียว เลยไม่เคยต้องแบ่งของเล่นกับใคร

จุดที่คนไทยพลาดบ่อย

only child — an only child = ลูกคนเดียวของพ่อแม่ (ใช้ an เสมอ) — อย่าพูดว่า I am a single child ซึ่งฟังแปลกสำหรับฝรั่ง

คำอื่นในบทเดียวกัน (วัยเติบโต)

  • childhood วัยเด็ก
  • upbringing การเลี้ยงดู (ที่หล่อหลอมเรา)
  • kid เด็ก / ลูก (ภาษาพูด)
  • teenager วัยรุ่น (13–19 ปี)
  • adult ผู้ใหญ่
  • pocket money เงินค่าขนม
  • chores งานบ้านที่ต้องทำประจำ
  • curfew เวลาเคอร์ฟิว / เวลาต้องถึงบ้าน
  • strict เข้มงวด
  • spoil ตามใจจนเสียนิสัย
  • naughty ซน / ดื้อ
  • rebellious ขบถ / ชอบต่อต้าน
  • leave the nest ออกจากอ้อมอกพ่อแม่
