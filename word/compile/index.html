compileคำกริยา

/kəmˈpaɪl/ · ระดับ B2

คอม-ไพล์

คอมไพล์ / แปลงโค้ดให้เครื่องรันได้

ตัวอย่างประโยค

It takes five minutes to compile the whole app.

ใช้เวลาห้านาทีในการคอมไพล์แอปทั้งตัว

จุดที่คนไทยพลาดบ่อย

compile — compile = แปลงโค้ดที่คนอ่านออกเป็นไฟล์ที่เครื่องรันได้ — ความหมายทั่วไปคือรวบรวม เช่น compile a report = รวบรวมข้อมูลทำรายงาน

คำที่มักสับสนกับ compile

  • complete เติมให้สมบูรณ์ / ทำให้เสร็จ
  • compare เปรียบเทียบ
  • comply ปฏิบัติตามกฎ

คำอื่นในบทเดียวกัน (เขียนโค้ดเบื้องต้น)

  • code โค้ด / ชุดคำสั่งโปรแกรม
  • bug บั๊ก / ข้อผิดพลาดในโปรแกรม
  • debug ดีบั๊ก / ไล่หาและแก้บั๊ก
  • deploy ดีพลอย / นำระบบขึ้นใช้งานจริง
  • developer นักพัฒนาโปรแกรม / โปรแกรมเมอร์
  • variable ตัวแปร
  • function ฟังก์ชัน / ชุดคำสั่งที่เรียกใช้ซ้ำได้
  • loop ลูป / การวนซ้ำ
  • syntax ไวยากรณ์ของภาษาโปรแกรม
  • command คำสั่ง (ที่พิมพ์ให้เครื่องทำ)
  • framework เฟรมเวิร์ก / โครงสำเร็จรูปสำหรับเขียนโปรแกรม
  • repository ที่เก็บโค้ดของโปรเจกต์
  • front end ฝั่งหน้าบ้าน / ส่วนที่ผู้ใช้เห็น
