จุดที่คนไทยพลาดบ่อย

course catalog — course catalog (อเมริกัน) / module catalogue (อังกฤษ) = รายการทุกวิชาพร้อมคำอธิบายและ prerequisite — อ่านออนไลน์ได้ก่อนเปิดเทอม จะได้เลือกวิชาที่ตารางไม่ชน

คำที่มักสับสนกับ course catalog

  • course วิชา / รายวิชา
  • calendar ปฏิทิน

คำอื่นในบทเดียวกัน (ลงทะเบียนเรียน)

  • course วิชา / รายวิชา
  • module วิชาย่อยในหลักสูตร (อังกฤษ)
  • credit หน่วยกิต
  • elective วิชาเลือก
  • compulsory วิชาบังคับ / ภาคบังคับ
  • register ลงทะเบียน (เรียน)
  • syllabus ประมวลรายวิชา
  • academic year ปีการศึกษา
  • advisor อาจารย์ที่ปรึกษา
  • minor วิชาโท
  • core course วิชาแกนของสาขา
  • drop ถอนวิชา
  • coursework งานเก็บคะแนนระหว่างเทอม
