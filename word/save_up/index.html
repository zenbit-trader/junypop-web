save upวลี

/seɪv ʌp/ · ระดับ A2

เซฟ อัพ

เก็บเงินเพื่อเป้าหมาย

ตัวอย่างประโยค

I save up a little every month for a trip to Japan.

ฉันเก็บเงินทีละนิดทุกเดือนไว้ไปเที่ยวญี่ปุ่น

จุดที่คนไทยพลาดบ่อย

save up — แยกได้ save up money / save it up — ตามด้วย for เป้าหมาย up ทำให้รู้สึกว่าเก็บสะสมจนก้อนโต ต่างจาก save เฉยๆ ที่แค่ประหยัด

คำอื่นในบทเดียวกัน (เรื่องเงิน)

  • pay off จ่ายหนี้หมด / คุ้มค่าที่ลงแรง
  • splash out จ่ายหนักให้รางวัลตัวเอง
  • rip off โก่งราคา หลอกเอาเงิน
  • chip in ลงขัน ช่วยออกเงิน
  • add up รวมยอด / สมเหตุสมผล
  • cut down on ลดการใช้/การกินให้น้อยลง
  • give away ยกให้ฟรี บริจาค
  • take out ถอนเงิน ทำประกัน/กู้ / พาไปเลี้ยง
  • put aside กันเงินแยกไว้ต่างหาก
  • fork out จำใจควักเงินจ่าย
  • take back เอาของไปคืนร้าน / ถอนคำพูด
  • go up ราคาขึ้น เพิ่มขึ้น
  • come down ราคาลดลง

จำ save up ให้ติดด้วยการเล่น
