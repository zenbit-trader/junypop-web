pluginคำนาม

/ˈplʌɡɪn/ · ระดับ B1

ปลั๊ก-อิน

ปลั๊กอิน / ส่วนเสริมโปรแกรม

ตัวอย่างประโยค

Install the plugin to add a chat box to your website.

ติดตั้งปลั๊กอินเพื่อเพิ่มกล่องแชตในเว็บไซต์ของคุณ

จุดที่คนไทยพลาดบ่อย

plugin — plugin / add-on / extension ความหมายใกล้กันมาก = ของเสริมที่ติดเพิ่มในโปรแกรม — เบราว์เซอร์มักใช้ extension ส่วน WordPress ใช้ plugin

คำที่มักสับสนกับ plugin

  • log in เข้าสู่ระบบ

คำอื่นในบทเดียวกัน (ซอฟต์แวร์และแอป)

  • software ซอฟต์แวร์ / โปรแกรม
  • app แอปพลิเคชัน
  • operating system ระบบปฏิบัติการ
  • interface หน้าจอการใช้งาน / ส่วนติดต่อผู้ใช้
  • version เวอร์ชัน / รุ่น
  • feature ฟีเจอร์ / ฟังก์ชันการใช้งาน
  • compatible ใช้ร่วมกันได้ / รองรับ
  • default ค่าเริ่มต้น / ค่าตั้งต้น
  • sync ซิงก์ / ทำให้ข้อมูลตรงกันทุกเครื่อง
  • permission สิทธิ์การเข้าถึง / การอนุญาต
  • open source โอเพนซอร์ส / เปิดโค้ดให้ใช้ฟรี
  • upgrade อัปเกรด / เปลี่ยนเป็นรุ่นดีขึ้น
  • user-friendly ใช้งานง่าย
