word countคำนาม

/ˈwɜːrd kaʊnt/ · ระดับ B1

เวิร์ด เคานท์

จำนวนคำที่กำหนด

ตัวอย่างประโยค

The word count for this essay is 2,000 words, plus or minus ten percent.

จำนวนคำที่กำหนดของเรียงความนี้คือ 2,000 คำ บวกลบสิบเปอร์เซ็นต์

จุดที่คนไทยพลาดบ่อย

word count — word count = จำนวนคำ มักให้เกิน/ขาดได้ 10% (เกินแล้วโดนหักคะแนน) — Word และ Google Docs นับให้ที่มุมล่าง ถามอาจารย์ว่านับ references ด้วยไหม

คำที่มักสับสนกับ word count

  • account บัญชีผู้ใช้ / แอคเคานต์

คำอื่นในบทเดียวกัน (เขียนรายงานและวิจัย)

  • thesis วิทยานิพนธ์
  • dissertation สารนิพนธ์ / งานวิจัยจบ
  • citation การอ้างอิงในเนื้อหา
  • cite อ้างอิง (แหล่งที่มา)
  • bibliography บรรณานุกรม
  • plagiarism การลอกผลงาน
  • paraphrase เรียบเรียงใหม่ด้วยคำของตัวเอง
  • proofread ตรวจทานคำผิด
  • outline โครงร่าง (ของรายงาน)
  • argument ข้อโต้แย้งเชิงวิชาการ / เหตุผลหลัก
  • source แหล่งข้อมูลอ้างอิง
  • abstract บทคัดย่อ
  • extension การขอเลื่อนส่งงาน
