ripeคำคุณศัพท์

/raɪp/ · ระดับ A2

ไรพ์

สุก (ผลไม้)

ตัวอย่างประโยค

These mangoes are ripe and ready to eat.

มะม่วงพวกนี้สุกพร้อมกินแล้ว

จุดที่คนไทยพลาดบ่อย

ripe — ripe = สุกพร้อมกิน ใช้กับผลไม้ ไม่ใช้กับอาหารที่ปรุงสุก (อาหารสุกใช้ cooked) — unripe = ยังดิบ, overripe = สุกงอมเกินไป

คำที่มักสับสนกับ ripe

  • wipe เช็ด

คำอื่นในบทเดียวกัน (จากสวนสู่ตลาด)

  • bunch พวง / หวี / เครือ (ผลไม้)
  • core แกนกลางผลไม้
  • rind เปลือกหนา (แตงโม / ส้ม / ชีส)
  • pit เมล็ดแข็งตรงกลางผลไม้
  • rotten เน่า
  • wilted เหี่ยว (ผัก / ดอกไม้)
  • seedless ไม่มีเมล็ด
  • dried อบแห้ง / ตากแห้ง
  • pick เด็ด / เก็บ (ผลไม้จากต้น)
  • orchard สวนผลไม้
  • farmer เกษตรกร / ชาวไร่ชาวนา
  • pickle ผักดอง / แตงกวาดอง
  • jam แยม

จำ ripe ให้ติดด้วยการเล่น

ทบทวนคำนี้พร้อมอีก 98 คำในหมวดผลไม้และผัก · เล่นฟรี ไม่ต้องติดตั้ง
