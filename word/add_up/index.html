add upวลี

/æd ʌp/ · ระดับ B1

แอด อัพ

รวมยอด / สมเหตุสมผล

ตัวอย่างประโยค

Small daily expenses really add up over a month.

ค่าใช้จ่ายเล็กๆ รายวันรวมกันเป็นก้อนโตได้ในหนึ่งเดือน

จุดที่คนไทยพลาดบ่อย

add up — แยกได้ add up the bills / add them up — ไม่มีกรรมใช้ได้สองแบบ: ยอดสะสมเพิ่ม และ It doesn't add up. = เรื่องนี้มันไม่สมเหตุสมผล

คำอื่นในบทเดียวกัน (เรื่องเงิน)

  • pay off จ่ายหนี้หมด / คุ้มค่าที่ลงแรง
  • save up เก็บเงินเพื่อเป้าหมาย
  • splash out จ่ายหนักให้รางวัลตัวเอง
  • rip off โก่งราคา หลอกเอาเงิน
  • chip in ลงขัน ช่วยออกเงิน
  • cut down on ลดการใช้/การกินให้น้อยลง
  • give away ยกให้ฟรี บริจาค
  • take out ถอนเงิน ทำประกัน/กู้ / พาไปเลี้ยง
  • put aside กันเงินแยกไว้ต่างหาก
  • fork out จำใจควักเงินจ่าย
  • take back เอาของไปคืนร้าน / ถอนคำพูด
  • go up ราคาขึ้น เพิ่มขึ้น
  • come down ราคาลดลง

จำ add up ให้ติดด้วยการเล่น
