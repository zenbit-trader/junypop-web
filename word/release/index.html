releaseคำกริยา

/rɪˈliːs/ · ระดับ B1

รี-ลีส

ปล่อยเวอร์ชันใหม่ออกสู่ผู้ใช้

ตัวอย่างประโยค

We release a new version to the app store every two weeks.

เราปล่อยเวอร์ชันใหม่ขึ้นสโตร์ทุกสองสัปดาห์

จุดที่คนไทยพลาดบ่อย

release — release = ปล่อยออกมา (release notes = รายการสิ่งที่เปลี่ยน, new release = รุ่นใหม่) ใช้กับหนัง เพลง และปล่อยตัวนักโทษได้ด้วย — press release = ข่าวแจก

คำที่มักสับสนกับ release

  • lease สัญญาเช่า
  • relief การบรรเทาทุกข์ / ความช่วยเหลือผู้ประสบภัย

คำอื่นในบทเดียวกัน (สร้างโปรดักต์)

  • MVP ผลิตภัณฑ์ขั้นต่ำที่ใช้งานได้
  • prototype ต้นแบบ
  • beta เวอร์ชันทดลองก่อนปล่อยจริง
  • user ผู้ใช้
  • roadmap แผนพัฒนาตามลำดับเวลา
  • iterate ปรับปรุงซ้ำเป็นรอบๆ
  • early adopter ผู้ใช้กลุ่มแรกที่กล้าลองของใหม่
  • product-market fit สินค้าตรงใจตลาดจริง
  • demo การสาธิตสินค้า
  • user experience ประสบการณ์ผู้ใช้ (UX)
  • metric ตัวชี้วัด / ตัวเลขที่ใช้วัดผล
  • landing page หน้าเว็บหน้าเดียวสำหรับขายหรือรับสมัคร
  • waitlist รายชื่อรอคิวใช้งาน
