permissionคำนาม

/pərˈmɪʃn/ · ระดับ A2

เพอร์-มิช-ชัน

สิทธิ์การเข้าถึง / การอนุญาต

ตัวอย่างประโยค

The app asks for permission to use your camera.

แอปขอสิทธิ์เข้าถึงกล้องของคุณ

จุดที่คนไทยพลาดบ่อย

permission — ask for permission = ขออนุญาต, grant permission = ให้สิทธิ์ — ในแอปมือถือคือ popup ที่ถามว่าให้ใช้กล้อง/ตำแหน่งไหม กด Allow หรือ Deny

คำที่มักสับสนกับ permission

  • permit ใบอนุญาตทำกิจกรรมเฉพาะ
  • commission ค่านายหน้าที่ได้ตามยอดขาย
  • admission การรับเข้าเรียน

คำอื่นในบทเดียวกัน (ซอฟต์แวร์และแอป)

  • software ซอฟต์แวร์ / โปรแกรม
  • app แอปพลิเคชัน
  • operating system ระบบปฏิบัติการ
  • interface หน้าจอการใช้งาน / ส่วนติดต่อผู้ใช้
  • version เวอร์ชัน / รุ่น
  • feature ฟีเจอร์ / ฟังก์ชันการใช้งาน
  • compatible ใช้ร่วมกันได้ / รองรับ
  • default ค่าเริ่มต้น / ค่าตั้งต้น
  • plugin ปลั๊กอิน / ส่วนเสริมโปรแกรม
  • sync ซิงก์ / ทำให้ข้อมูลตรงกันทุกเครื่อง
  • open source โอเพนซอร์ส / เปิดโค้ดให้ใช้ฟรี
  • upgrade อัปเกรด / เปลี่ยนเป็นรุ่นดีขึ้น
  • user-friendly ใช้งานง่าย
