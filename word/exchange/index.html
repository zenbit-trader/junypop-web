จุดที่คนไทยพลาดบ่อย

exchange — exchange = เปลี่ยนเป็นชิ้นอื่น (ได้ของ) / refund = คืนเงิน (ได้เงิน) ร้านมักถามว่า Exchange or refund?

คำที่มักสับสนกับ exchange

  • change เงินทอน
  • refund การคืนเงิน

คำอื่นในบทเดียวกัน (จ่ายเงินและคืนสินค้า)

  • refund การคืนเงิน
  • return คืนสินค้า
  • installment การผ่อนชำระ / งวด
  • debit card บัตรเดบิต
  • mobile banking โมบายแบงก์กิ้ง / ธนาคารบนมือถือ
  • QR code คิวอาร์โค้ด
  • scan สแกน
  • member card บัตรสมาชิก
  • points แต้มสะสม / คะแนน
  • voucher บัตรกำนัล / เวาเชอร์
  • coupon คูปอง
  • out of stock สินค้าหมด
  • in stock มีสินค้า / ของพร้อมส่ง

จำ exchange ให้ติดด้วยการเล่น

ทบทวนคำนี้พร้อมอีก 98 คำในหมวดช้อปปิ้ง ฟรี ไม่ต้องติดตั้ง
