จุดที่คนไทยพลาดบ่อย

student ID — student ID (card) = บัตรนักศึกษา ใช้เข้าห้องสมุด ยิมและสอบ — ส่วนลดนักศึกษาต่างประเทศเยอะมาก ถามได้ทุกร้านว่า "Do you do a student discount?"

คำที่มักสับสนกับ student ID

  • studio ห้องสตูดิโอ (ห้องเดียวรวมครัว)

คำอื่นในบทเดียวกัน (รอบรั้วแคมปัส)

  • campus พื้นที่มหาวิทยาลัย
  • lecture hall ห้องบรรยายใหญ่
  • student union องค์การนักศึกษา / อาคารกิจกรรม
  • cafeteria โรงอาหารมหาวิทยาลัย
  • orientation ปฐมนิเทศ
  • computer lab ห้องคอมพิวเตอร์
  • study room ห้องอ่านหนังสือ (จองได้)
  • bookstore ร้านหนังสือมหาวิทยาลัย
  • counseling บริการให้คำปรึกษา (สุขภาพใจ)
  • career center ศูนย์แนะแนวอาชีพ
  • sports center ศูนย์กีฬามหาวิทยาลัย
  • common room ห้องนั่งเล่นรวม (หอพัก/คณะ)
  • shuttle bus รถรับส่งระหว่างแคมปัส
