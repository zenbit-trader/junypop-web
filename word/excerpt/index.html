จุดที่คนไทยพลาดบ่อย

excerpt — excerpt = ส่วนที่ตัดมาจากหนังสือ บทความ หรือสุนทรพจน์ — ข้อสอบมักเขียนว่า "Read the following excerpt" แล้วถามว่ามาจากแหล่งใด อย่าสับสนกับ except (ยกเว้น)

คำที่มักสับสนกับ excerpt

  • except ยกเว้น

คำอื่นในบทเดียวกัน (คำนามในข้อสอบ)

  • passage บทความ (ที่ให้อ่านในข้อสอบ)
  • paragraph ย่อหน้า
  • topic หัวข้อ
  • main idea ใจความสำคัญ
  • detail รายละเอียด
  • purpose จุดประสงค์
  • tone น้ำเสียง (ของผู้เขียน)
  • attitude ทัศนคติ / ท่าที
  • author ผู้เขียน / ผู้แต่ง
  • title ชื่อเรื่อง
  • column คอลัมน์ (ในหนังสือพิมพ์)
  • context บริบท
  • origin ต้นกำเนิด / ที่มา
