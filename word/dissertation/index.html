dissertationคำนาม

/ˌdɪsərˈteɪʃn/ · ระดับ B2

ดิส-เซอร์-เท-ชั่น

สารนิพนธ์ / งานวิจัยจบ

ตัวอย่างประโยค

The dissertation must be between ten and fifteen thousand words.

สารนิพนธ์ต้องมีความยาวหนึ่งหมื่นถึงหนึ่งหมื่นห้าพันคำ

จุดที่คนไทยพลาดบ่อย

dissertation — อังกฤษ: dissertation = งานจบปริญญาตรี/โท ส่วน thesis = ปริญญาเอก (อเมริกาสลับกัน!) — เขียนตลอดช่วงหน้าร้อน มี supervisor คอยดูแล ส่งงานหน้าร้อนช้า = จบช้า

คำที่มักสับสนกับ dissertation

  • presentation การนำเสนอ / พรีเซนต์

คำอื่นในบทเดียวกัน (เขียนรายงานและวิจัย)

  • thesis วิทยานิพนธ์
  • citation การอ้างอิงในเนื้อหา
  • cite อ้างอิง (แหล่งที่มา)
  • bibliography บรรณานุกรม
  • plagiarism การลอกผลงาน
  • paraphrase เรียบเรียงใหม่ด้วยคำของตัวเอง
  • word count จำนวนคำที่กำหนด
  • proofread ตรวจทานคำผิด
  • outline โครงร่าง (ของรายงาน)
  • argument ข้อโต้แย้งเชิงวิชาการ / เหตุผลหลัก
  • source แหล่งข้อมูลอ้างอิง
  • abstract บทคัดย่อ
  • extension การขอเลื่อนส่งงาน
