priorityคำนาม

/praɪˈɔːrəti/ · ระดับ B1

ไพร-ออ-ริ-ตี้

สิ่งสำคัญอันดับแรก

ตัวอย่างประโยค

This task is our top priority.

งานนี้คือความสำคัญอันดับหนึ่งของเรา

จุดที่คนไทยพลาดบ่อย

priority — top priority = สำคัญสุด — จัดลำดับความสำคัญ = prioritize ทักษะที่วัยทำงานทุกคนต้องมี

คำอื่นในบทเดียวกัน (งานประจำวัน)

  • work ทำงาน
  • task งาน (ชิ้นหนึ่ง)
  • deadline กำหนดส่งงาน / เดดไลน์
  • busy ยุ่ง
  • project โปรเจกต์ / โครงการ
  • schedule ตารางงาน / กำหนดการ
  • finish ทำเสร็จ
  • submit ส่งงาน (อย่างเป็นทางการ)
  • check ตรวจสอบ
  • solve แก้ปัญหา
  • overtime การทำงานล่วงเวลา / โอที
  • break พักเบรก
  • day off วันหยุด (ของเรา)

จำ priority ให้ติดด้วยการเล่น

ทบทวนคำนี้พร้อมอีก 98 คำในหมวดออฟฟิศ ฟรี ไม่ต้องติดตั้ง
