woundคำนาม

/wuːnd/ · ระดับ B1

วูนด์

ตัวอย่างประโยค

Clean the wound before putting on a bandage.

ล้างแผลก่อนปิดผ้าพันแผล

จุดที่คนไทยพลาดบ่อย

wound — ออกเสียง "วูนด์" (ไม่ใช่ "วาวด์"!) — ล้างแผล = clean the wound / แผลหาย = the wound healed

คำอื่นในบทเดียวกัน (บาดเจ็บและแผล)

  • injury การบาดเจ็บ
  • cut แผลบาด / มีดบาด
  • burn แผลไหม้ / น้ำร้อนลวก
  • bruise รอยช้ำ / ฟกช้ำ
  • bleed เลือดออก
  • swollen บวม
  • sprain แพลง (ข้อเท้า/ข้อมือ)
  • X-ray เอกซเรย์
  • cast เฝือก
  • crutches ไม้ค้ำยัน
  • stitches การเย็บแผล / ไหมเย็บแผล
  • ice pack ถุงประคบเย็น
  • heal หาย (แผล) / รักษา
