จุดที่คนไทยพลาดบ่อย

result — as a result = ผลก็คือ... (คำเชื่อมยอดฮิตในการเขียน) — ผลสอบ ผลแข่ง ผลประกอบการ ใช้ result หมด

คำอื่นในบทเดียวกัน (ตัวเลขและกราฟ)

  • percent เปอร์เซ็นต์ / ร้อยละ
  • increase เพิ่มขึ้น
  • decrease ลดลง
  • double เพิ่มเป็นสองเท่า
  • average ค่าเฉลี่ย
  • chart แผนภูมิ / ชาร์ต
  • graph กราฟ
  • data ข้อมูล
  • growth การเติบโต
  • target เป้าหมาย / เป้ายอดขาย
  • compare เปรียบเทียบ
  • estimate ประเมิน / กะประมาณ
  • calculate คำนวณ
