waitressคำนาม

/ˈweɪtrəs/ · ระดับ A1

เวท-เทรส

พนักงานเสิร์ฟ (หญิง)

ตัวอย่างประโยค

The waitress recommended the fried rice.

จุดที่คนไทยพลาดบ่อย

waitress — waiter (ชาย) / waitress (หญิง) ปัจจุบันนิยมใช้ server แทนทั้งคู่

คำที่มักสับสนกับ waitress

  • waiter พนักงานเสิร์ฟ (ชาย)
  • actress นักแสดงหญิง

คำอื่นในบทเดียวกัน (สั่งอาหาร)

  • menu เมนู / รายการอาหาร
  • order สั่ง (อาหาร)
  • waiter พนักงานเสิร์ฟ (ชาย)
  • chef เชฟ / หัวหน้าพ่อครัว
  • customer ลูกค้า
  • reservation การจองโต๊ะ / การจองล่วงหน้า
  • recommend แนะนำ (ว่าอะไรดี)
  • appetizer อาหารเรียกน้ำย่อย / ของทานเล่นก่อนมื้อหลัก
  • main course อาหารจานหลัก
  • dessert ของหวาน
  • drink เครื่องดื่ม
  • takeaway อาหารกลับบ้าน / ใส่กล่องกลับ
