visualคำนาม

/ˈvɪʒuəl/ · ระดับ B1

วิ-ชวล

ภาพประกอบในงานโฆษณา

ตัวอย่างประโยค

The visual should show the product being used.

ภาพประกอบควรแสดงสินค้าตอนถูกใช้งานจริง

จุดที่คนไทยพลาดบ่อย

visual — ในทีมครีเอทีฟ visual = ภาพหรือกราฟิกของชิ้นงาน คู่กับ copy ที่เป็นตัวหนังสือ — key visual (KV) คือภาพหลักของแคมเปญที่ใช้ซ้ำทุกช่องทาง

คำที่มักสับสนกับ visual

  • virtual เสมือน(ผ่านคอมพิวเตอร์)
  • vision วิสัยทัศน์

คำอื่นในบทเดียวกัน (แคมเปญและคอนเทนต์)

  • content calendar ตารางวางแผนคอนเทนต์
  • copywriting การเขียนคำโฆษณา
  • copy ข้อความโฆษณา (ตัวหนังสือ)
  • headline พาดหัว
  • call to action ข้อความชวนให้ทำทันที
  • storytelling การเล่าเรื่องเพื่อสร้างแบรนด์
  • teaser ตัวอย่างเรียกน้ำย่อย
  • pop-up หน้าต่าง/ร้านที่โผล่ขึ้นชั่วคราว
  • banner ป้ายโฆษณา (เว็บ/ผ้า)
  • evergreen ที่ใช้ได้ตลอด ไม่ล้าสมัย
  • UGC คอนเทนต์ที่ลูกค้าทำเอง
  • brief เอกสารสรุปโจทย์งาน
  • repurpose นำคอนเทนต์เดิมมาทำใหม่

จำ visual ให้ติดด้วยการเล่น
