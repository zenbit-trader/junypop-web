fictionคำนาม

/ˈfɪkʃn/ · ระดับ B1

ฟิค-ชั่น

เรื่องแต่ง / บันเทิงคดี

ตัวอย่างประโยค

I prefer fiction to history books.

ฉันชอบเรื่องแต่งมากกว่าหนังสือประวัติศาสตร์

จุดที่คนไทยพลาดบ่อย

fiction — fiction = เรื่องที่แต่งขึ้น ตรงข้ามกับ non-fiction (สารคดี ชีวประวัติ) — science fiction ย่อเป็น sci-fi

คำที่มักสับสนกับ fiction

  • friction แรงเสียดทาน
  • function ฟังก์ชัน / ชุดคำสั่งที่เรียกใช้ซ้ำได้

คำอื่นในบทเดียวกัน (วรรณกรรมและเรื่องเล่า)

  • novel นวนิยาย
  • chapter บท (ของหนังสือ)
  • poem บทกวี / กลอน
  • poet กวี / นักกลอน
  • narrator ผู้เล่าเรื่อง
  • theme แก่นเรื่อง / แนวคิดหลัก
  • moral คติสอนใจ / ข้อคิด
  • villain ตัวร้าย
  • legend ตำนาน
  • myth เทพปกรณัม / ความเชื่อผิดๆ
  • fable นิทานสอนใจ (ตัวละครสัตว์)
  • metaphor อุปลักษณ์ / การเปรียบเป็น
  • tragedy โศกนาฏกรรม
