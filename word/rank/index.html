จุดที่คนไทยพลาดบ่อย

rank — เกมเมอร์ไทยพูด "ดันแรงค์" ตรงศัพท์ — ตารางอันดับ = ranking / leaderboard (ลีดเดอร์บอร์ดในเกมนี้ก็มี!)

คำที่มักสับสนกับ rank

  • bank ธนาคาร

คำอื่นในบทเดียวกัน (สู้เพื่อชัยชนะ)

  • win ชนะ
  • lose แพ้
  • victory ชัยชนะ
  • defeat เอาชนะ / ความพ่ายแพ้
  • challenge ความท้าทาย / คำท้า
  • opponent คู่แข่ง / ฝ่ายตรงข้าม
  • tournament ทัวร์นาเมนต์ / การแข่งขัน
  • champion แชมป์
  • prize รางวัล
  • high score คะแนนสูงสุด
  • level up เลเวลอัป / อัปเลเวล
  • practice ฝึกซ้อม
  • improve เก่งขึ้น / พัฒนา

จำ rank ให้ติดด้วยการเล่น

ทบทวนคำนี้พร้อมอีก 98 คำในหมวดเกมมิ่ง ฟรี ไม่ต้องติดตั้ง
