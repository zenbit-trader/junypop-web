จุดที่คนไทยพลาดบ่อย

classify — classify = จัดเข้ากลุ่มตามลักษณะร่วม (คำนาม classification) — นักชีววิทยา classify สิ่งมีชีวิตเป็น kingdom → species และเอกสาร classified = ชั้นความลับ

คำที่มักสับสนกับ classify

  • clarify อธิบายให้ชัดเจนขึ้น
  • classic วรรณกรรมคลาสสิก

คำอื่นในบทเดียวกัน (ในห้องทดลอง)

  • scientist นักวิทยาศาสตร์
  • experiment การทดลอง
  • procedure ขั้นตอน (การทดลอง)
  • test tube หลอดทดลอง
  • beaker บีกเกอร์ / แก้วตวงทดลอง
  • microscope กล้องจุลทรรศน์
  • goggles แว่นนิรภัย / แว่นกันสารเคมี
  • thermometer เทอร์โมมิเตอร์ / ที่วัดอุณหภูมิ
  • magnet แม่เหล็ก
  • flame เปลวไฟ
  • sample ตัวอย่าง (ที่เก็บมาทดสอบ)
  • measure วัด (ขนาด/ปริมาณ)
  • observe สังเกต
