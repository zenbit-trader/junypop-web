first aidคำนาม

/ˌfɜːrst ˈeɪd/ · ระดับ B1

เฟิร์สท์-เอด

การปฐมพยาบาล

ตัวอย่างประโยค

Every tour bus has a first aid kit.

รถทัวร์ทุกคันมีชุดปฐมพยาบาล

จุดที่คนไทยพลาดบ่อย

first aid — first (แรก) + aid (ความช่วยเหลือ) = ช่วยเหลือขั้นแรก — กล่องยา = first aid kit สัญลักษณ์กากบาท

คำอื่นในบทเดียวกัน (เหตุฉุกเฉินนักเดินทาง)

  • help ช่วยเหลือ
  • emergency เหตุฉุกเฉิน
  • police ตำรวจ
  • accident อุบัติเหตุ
  • hurt เจ็บ / บาดเจ็บ
  • dangerous อันตราย
  • be careful ระวัง / ระมัดระวัง
  • sunburn ผิวไหม้แดด
  • mosquito ยุง
  • insurance ประกัน (การเดินทาง)
  • embassy สถานทูต
  • stolen ถูกขโมย
  • report แจ้งความ / รายงาน

จำ first aid ให้ติดด้วยการเล่น

ทบทวนคำนี้พร้อมอีก 98 คำในหมวดการท่องเที่ยว ฟรี ไม่ต้องติดตั้ง
