written noticeคำนาม

/ˌrɪtn ˈnoʊtɪs/ · ระดับ B1

ริท-เทิน โน-ทิส

หนังสือแจ้งล่วงหน้าเป็นลายลักษณ์อักษร

ตัวอย่างประโยค

The landlord needs written notice two months before you leave.

เจ้าของบ้านต้องได้รับหนังสือแจ้งล่วงหน้าเป็นลายลักษณ์อักษรสองเดือนก่อนคุณย้ายออก

จุดที่คนไทยพลาดบ่อย

written notice — written notice = แจ้งเป็นอีเมลหรือจดหมาย (ไม่ใช่บอกปากเปล่า) ใช้ทั้งตอนผู้เช่าจะออกและเจ้าของบ้านจะขึ้นค่าเช่า — เก็บสำเนาและวันที่ส่งไว้เสมอ เป็นหลักฐานถ้ามีข้อพิพาท

คำอื่นในบทเดียวกัน (สัญญาเช่า)

  • lease สัญญาเช่า
  • tenancy การเช่าอยู่ / ระยะเวลาเช่า
  • security deposit เงินประกันห้อง
  • guarantor ผู้ค้ำประกัน
  • break clause ข้อสัญญาให้ยกเลิกก่อนกำหนด
  • fixed-term แบบกำหนดระยะเวลาแน่นอน
  • extend ต่ออายุ / ขยายเวลา (สัญญา)
  • break the lease ยกเลิกสัญญาเช่าก่อนกำหนด
  • reference หนังสือรับรอง / คนรับรอง
  • inventory รายการทรัพย์สินในห้อง
  • sublet ปล่อยเช่าช่วง
  • fine print ข้อความตัวเล็กในสัญญา
  • in advance ล่วงหน้า
