actionคำนาม

/ˈækʃən/ · ระดับ A2

แอ็ค-ชั่น

แนวแอ็กชัน / ฉากบู๊

ตัวอย่างประโยค

Action games are exciting but tiring.

เกมแอ็กชันมันส์แต่ก็เหนื่อยเอาเรื่อง

จุดที่คนไทยพลาดบ่อย

action — action = การกระทำ/ฉากบู๊ — ผู้กำกับหนังตะโกน Action! (เริ่มถ่าย) ก็คำเดียวกันนี้

คำอื่นในบทเดียวกัน (เลือกแนวเกม)

  • genre แนวเกม / ประเภท
  • racing แนวแข่งรถ / แข่งความเร็ว
  • puzzle เกมปริศนา
  • shooting game เกมยิง
  • horror แนวสยองขวัญ
  • sports game เกมกีฬา
  • strategy แนววางแผน / กลยุทธ์
  • role-playing แนวสวมบทบาท / RPG
  • simulation แนวจำลองชีวิต
  • arcade เกมตู้ / อาร์เคด
  • board game บอร์ดเกม / เกมกระดาน
  • casual เล่นง่ายๆ สบายๆ
  • mobile game เกมมือถือ

จำ action ให้ติดด้วยการเล่น
