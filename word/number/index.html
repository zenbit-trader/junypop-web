numberคำนาม

/ˈnʌmbər/ · ระดับ A1

นัม-เบอร์

ตัวเลข / จำนวน

ตัวอย่างประโยค

Pick a number between one and ten.

เลือกตัวเลขระหว่างหนึ่งถึงสิบ

จุดที่คนไทยพลาดบ่อย

number — a number of + พหูพจน์ = หลาย (ใช้กริยาพหูพจน์) แต่ the number of = จำนวนของ (ใช้กริยาเอกพจน์) — ข้อสอบ subject-verb agreement ชอบออก

คำที่มักสับสนกับ number

  • numb ชา / ไร้ความรู้สึก
  • amount จำนวน / ยอดเงิน

คำอื่นในบทเดียวกัน (ตัวเลขใหญ่และลำดับที่)

  • zero ศูนย์
  • dozen โหล (สิบสอง)
  • hundred ร้อย
  • thousand พัน
  • million ล้าน
  • billion พันล้าน
  • digit หลัก / ตัวเลขหลักเดียว (0–9)
  • count นับ
  • first ที่หนึ่ง / แรก
  • second ที่สอง
  • third ที่สาม
  • fifth ที่ห้า
  • twentieth ที่ยี่สิบ
