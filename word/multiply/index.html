multiplyคำกริยา

/ˈmʌltɪplaɪ/ · ระดับ A2

มัล-ทิ-พลาย

คูณ

ตัวอย่างประโยค

Multiply the length by the width to find the area.

คูณความยาวด้วยความกว้างเพื่อหาพื้นที่

จุดที่คนไทยพลาดบ่อย

multiply — multiply A by B = เอา A คูณ B คำนาม multiplication (สูตรคูณ = multiplication table) — ความหมายรอง = เพิ่มจำนวนอย่างรวดเร็ว (germs multiply)

คำที่มักสับสนกับ multiply

  • supply ปริมาณสินค้า / ซัพพลาย
  • divide หาร / แบ่ง

คำอื่นในบทเดียวกัน (บวกลบคูณหาร)

  • add บวก / เพิ่ม
  • plus บวก (เครื่องหมาย +)
  • subtract ลบ / หักออก
  • minus ลบ (เครื่องหมาย −)
  • times คูณ (เครื่องหมาย ×) / เท่า
  • divide หาร / แบ่ง
  • equals เท่ากับ (เครื่องหมาย =)
  • sum ผลบวก / ผลรวม
  • remainder เศษ (ที่เหลือจากการหาร)
  • even เลขคู่
  • odd เลขคี่
  • equation สมการ
  • formula สูตร
