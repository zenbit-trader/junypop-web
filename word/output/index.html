outputคำนาม

/ˈaʊtpʊt/ · ระดับ B1

เอาท์-พุท

ผลผลิต / ปริมาณที่ผลิตได้

ตัวอย่างประโยค

Factory output increased after the new machines arrived.

ผลผลิตของโรงงานเพิ่มขึ้นหลังเครื่องจักรใหม่มาถึง

จุดที่คนไทยพลาดบ่อย

output — output = ปริมาณที่ผลิตออกมา ตรงข้ามกับ input — ในงานคอมพิวเตอร์ก็ใช้คำเดียวกัน (ข้อมูลเข้า/ออก)

คำที่มักสับสนกับ output

  • outlet เต้ารับไฟฟ้า (รูปลั๊กที่ผนัง)

คำอื่นในบทเดียวกัน (การผลิตและคุณภาพ)

  • manufacture ผลิต(ในโรงงาน)
  • assembly line สายการประกอบ
  • inspect ตรวจสอบอย่างละเอียด
  • defect ข้อบกพร่อง / ตำหนิ(ในสินค้า)
  • durable ทนทาน
  • raw material วัตถุดิบ
  • machinery เครื่องจักร(โดยรวม)
  • standard มาตรฐาน
  • malfunction ทำงานผิดปกติ / ขัดข้อง
  • efficient มีประสิทธิภาพ(ไม่สิ้นเปลือง)
  • shortage การขาดแคลน(สินค้า/แรงงาน)
  • component ชิ้นส่วนประกอบ
  • recall เรียกคืนสินค้า

จำ output ให้ติดด้วยการเล่น
