VATคำนาม

/ˌviː eɪ ˈtiː/ · ระดับ B1

วี-เอ-ที / แวท

ภาษีมูลค่าเพิ่ม

ตัวอย่างประโยค

The price on the menu already includes 7% VAT.

ราคาในเมนูรวมภาษีมูลค่าเพิ่ม 7% แล้ว

จุดที่คนไทยพลาดบ่อย

VAT — VAT = value added tax ไทยเก็บ 7% — price includes VAT = รวมแวทแล้ว, excludes VAT / plus VAT = ยังไม่รวม (ต้องบวกเพิ่มอีก 7%) ระวังตอนดูราคาโรงแรมและร้านอาหาร

คำที่มักสับสนกับ VAT

  • vet สัตวแพทย์

คำอื่นในบทเดียวกัน (คำนวณเงินในชีวิตจริง)

  • amount จำนวน / ยอดเงิน
  • quantity ปริมาณ / จำนวนชิ้น
  • each แต่ละ / ชิ้นละ
  • per ต่อ (หน่วย)
  • unit price ราคาต่อหน่วย
  • subtotal ยอดรวมย่อย (ก่อนภาษี)
  • altogether ทั้งหมดรวมกัน
  • twice สองเท่า / สองครั้ง
  • triple สามเท่า
  • exact ตรงเป๊ะ / แน่นอน
  • roughly คร่าวๆ / ราวๆ
  • figure ตัวเลข (สถิติ) / จำนวนเงิน
  • convert แปลงหน่วย / แปลงค่า
