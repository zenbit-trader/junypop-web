go viralวลี

/ˌɡoʊ ˈvaɪrəl/ · ระดับ B1

โก-ไว-รัล

ดังเป็นไวรัล

ตัวอย่างประโยค

Her clip went viral overnight.

คลิปของเธอดังเป็นไวรัลข้ามคืน

จุดที่คนไทยพลาดบ่อย

go viral — viral มาจาก virus — แพร่ไวเหมือนไวรัส! "คลิปไวรัล" ที่คนไทยพูดคือคำนี้ (go-went-gone)

คำอื่นในบทเดียวกัน (สตรีมและแชท)

  • stream สตรีม / ถ่ายทอดสด
  • streamer สตรีมเมอร์
  • live ถ่ายทอดสด / ไลฟ์
  • viewer ผู้ชม
  • chat แชท / คุยกัน
  • comment คอมเมนต์ / ความคิดเห็น
  • follower ผู้ติดตาม
  • subscribe กดติดตามช่อง
  • channel ช่อง (ยูทูบ/สตรีม)
  • clip คลิปวิดีโอ
  • highlight ช่วงเด็ด / ไฮไลต์
  • donate โดเนท / บริจาค
  • emote อีโมท / ท่าแสดงอารมณ์ในเกม

จำ go viral ให้ติดด้วยการเล่น
