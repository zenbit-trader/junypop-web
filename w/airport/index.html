เริ่มแบบทดสอบ

คำศัพท์ทั้งหมดในหมวดนี้

เตรียมตัวเดินทาง · Preparing

  • passport หนังสือเดินทาง / พาสปอร์ต
  • ticket ตั๋ว
  • booking การจอง
  • luggage กระเป๋าเดินทาง / สัมภาระ
  • suitcase กระเป๋าเดินทาง (ใบแข็งหรือมีล้อลาก)
  • backpack กระเป๋าเป้
  • pack จัดกระเป๋า / เก็บของใส่กระเป๋า
  • visa วีซ่า
  • itinerary กำหนดการเดินทาง
  • destination จุดหมายปลายทาง
  • round trip การเดินทางไป-กลับ / ตั๋วไป-กลับ
  • one-way เที่ยวเดียว (ตั๋ว)
  • flight เที่ยวบิน
  • airline สายการบิน

เช็คอิน · Check-in

  • check-in การเช็คอิน / จุดเช็คอิน
  • check in เช็คอิน / ลงทะเบียนขึ้นเครื่อง
  • counter เคาน์เตอร์
  • boarding pass บัตรขึ้นเครื่อง / บอร์ดดิ้งพาส
  • seat ที่นั่ง
  • window seat ที่นั่งริมหน้าต่าง
  • aisle seat ที่นั่งริมทางเดิน
  • baggage สัมภาระ / กระเป๋าเดินทาง
  • baggage allowance น้ำหนักสัมภาระที่อนุญาต
  • overweight น้ำหนักเกิน
  • carry-on กระเป๋าถือขึ้นเครื่อง
  • checked baggage กระเป๋าโหลดใต้เครื่อง
  • scale เครื่องชั่ง / ตาชั่ง
  • weigh ชั่งน้ำหนัก / มีน้ำหนัก

ตรวจความปลอดภัย · Security

  • security check การตรวจความปลอดภัย / จุดตรวจ
  • scanner เครื่องสแกน
  • tray ถาด
  • liquids ของเหลว
  • belt เข็มขัด
  • metal detector เครื่องตรวจจับโลหะ
  • remove ถอด / เอาออก
  • prohibited ต้องห้าม / ไม่อนุญาต
  • allowed ได้รับอนุญาต
  • laptop แล็ปท็อป / คอมพิวเตอร์โน้ตบุ๊ก
  • jacket เสื้อแจ็กเก็ต / เสื้อคลุม
  • empty เอาของออกให้หมด / ทำให้ว่าง
  • shoes รองเท้า
  • scissors กรรไกร

ตรวจคนเข้าเมือง · Immigration

  • immigration ด่านตรวจคนเข้าเมือง / ตม.
  • customs ศุลกากร / ด่านตรวจสินค้า
  • declare สำแดง (สิ่งของต่อศุลกากร)
  • purpose of visit วัตถุประสงค์ในการมาเยือน
  • stamp ตราประทับ (ในหนังสือเดินทาง)
  • queue แถว / คิว
  • officer เจ้าหน้าที่
  • arrival card บัตรขาเข้า
  • nationality สัญชาติ
  • fill in กรอก (แบบฟอร์ม)
  • stay พัก / อยู่ (ชั่วคราว)
  • duty-free ปลอดภาษี
  • fingerprint ลายนิ้วมือ
  • camera กล้อง

ขึ้นเครื่อง · Boarding

  • gate ประตูขึ้นเครื่อง / เกต
  • boarding การขึ้นเครื่อง
  • departure การออกเดินทาง / ขาออก
  • delay ความล่าช้า / การดีเลย์
  • cancel ยกเลิก
  • announcement ประกาศ
  • final call การเรียกครั้งสุดท้าย (ให้ขึ้นเครื่อง)
  • terminal อาคารผู้โดยสาร
  • on time ตรงเวลา
  • connecting flight เที่ยวบินต่อ
  • transit การเปลี่ยนเครื่อง / การแวะพักระหว่างทาง
  • miss พลาด / ตก (เครื่อง รถ)
  • row แถว (ที่นั่ง)
  • lounge ห้องรับรอง / เลานจ์

บนเครื่องบิน · On the Plane

  • cabin crew ลูกเรือ / พนักงานต้อนรับบนเครื่องบิน
  • seatbelt เข็มขัดนิรภัย
  • fasten รัด / คาด (เข็มขัด)
  • turbulence สภาพอากาศแปรปรวน / อาการเครื่องสั่น
  • overhead bin ช่องเก็บสัมภาระเหนือศีรษะ
  • tray table โต๊ะพับหน้าที่นั่ง
  • landing การลงจอด
  • take off ถอด (เสื้อผ้า รองเท้า)
  • meal มื้ออาหาร
  • pilot นักบิน
  • headphones หูฟัง
  • lavatory ห้องน้ำ (บนเครื่องบิน)
  • blanket ผ้าห่ม
  • airplane เครื่องบิน

ถึงที่หมาย · Arrival

  • arrival การมาถึง / ขาเข้า
  • baggage claim จุดรับกระเป๋า
  • carousel สายพานรับกระเป๋า
  • lost luggage กระเป๋าหาย / สัมภาระสูญหาย
  • exit ทางออก
  • taxi stand จุดจอดแท็กซี่
  • currency exchange ที่แลกเงิน / การแลกเปลี่ยนเงินตรา
  • SIM card ซิมการ์ด
  • trolley รถเข็นกระเป๋า
  • exchange rate อัตราแลกเปลี่ยน
  • ATM ตู้เอทีเอ็ม
  • pick up ไปรับ (คน) / หยิบขึ้นมา
  • credit card บัตรเครดิต
  • jet lag อาการเจ็ตแล็ก / อาการอ่อนเพลียจากการบินข้ามเขตเวลา
