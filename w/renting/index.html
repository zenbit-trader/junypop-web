  • landlord เจ้าของบ้านเช่า
  • tenant ผู้เช่า
  • agent นายหน้า / ตัวแทน
  • listing ประกาศให้เช่า
  • viewing การนัดดูห้อง
  • furnished มีเฟอร์นิเจอร์ครบ
  • unfurnished ห้องเปล่า ไม่มีเฟอร์นิเจอร์
  • neighborhood ย่าน / ละแวกบ้าน
  • roommate เพื่อนร่วมห้อง / ร่วมบ้าน

สัญญาเช่า · The Lease

  • lease สัญญาเช่า
  • tenancy การเช่าอยู่ / ระยะเวลาเช่า
  • security deposit เงินประกันห้อง
  • guarantor ผู้ค้ำประกัน
  • break clause ข้อสัญญาให้ยกเลิกก่อนกำหนด

  • extend ต่ออายุ / ขยายเวลา (สัญญา)

  • written notice หนังสือแจ้งล่วงหน้าเป็นลายลักษณ์อักษร
  • reference หนังสือรับรอง / คนรับรอง
  • inventory รายการทรัพย์สินในห้อง
  • sublet ปล่อยเช่าช่วง
  • fine print ข้อความตัวเล็กในสัญญา
  • in advance ล่วงหน้า
