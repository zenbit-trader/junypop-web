คำศัพท์ทั้งหมดในหมวดนี้

ในห้าง · At the Mall

  • mall ห้างสรรพสินค้า / ศูนย์การค้า
  • shop ร้านค้า
  • department store ห้างสรรพสินค้า (แบบมีแผนก)
  • floor ชั้น (ของอาคาร) / พื้น
  • escalator บันไดเลื่อน
  • elevator ลิฟต์
  • fitting room ห้องลองเสื้อ
  • cashier แคชเชียร์ / พนักงานเก็บเงิน
  • entrance ทางเข้า
  • food court ศูนย์อาหาร
  • parking ที่จอดรถ
  • restroom ห้องน้ำ (ในที่สาธารณะ)
  • open เปิด (ทำการ)
  • closed ปิด (ทำการ)

  • large ใหญ่ / ไซซ์ L
  • try on ลอง (เสื้อผ้า/รองเท้า)
  • fit พอดี (ขนาด)
  • tight คับ / แน่น
  • loose หลวม
  • color สี
  • style สไตล์ / แบบ
  • brand ยี่ห้อ / แบรนด์
  • fashion แฟชั่น
  • mirror กระจกเงา
  • sweater เสื้อกันหนาวไหมพรม / สเวตเตอร์

  • cost มีราคา / ราคา...บาท
  • afford มีเงินพอซื้อ
  • budget งบประมาณ / งบ
  • sale การลดราคา / เซล
  • on sale กำลังลดราคา
  • promotion โปรโมชั่น
  • special offer ข้อเสนอพิเศษ
  • buy one get one free ซื้อ 1 แถม 1

  • bargain ต่อราคา / ต่อรอง
  • wallet กระเป๋าสตางค์
  • coin เหรียญ
  • banknote ธนบัตร / แบงก์
  • purse กระเป๋าถือเล็ก / กระเป๋าตังค์ผู้หญิง

ซูเปอร์มาร์เก็ต · At the Supermarket

  • supermarket ซูเปอร์มาร์เก็ต
  • cart รถเข็น (ซื้อของ)
  • basket ตะกร้า
  • shelf ชั้นวางของ
  • aisle ช่องทางเดิน (ระหว่างชั้นวาง)
  • checkout จุดชำระเงิน / เช็คเอาท์
  • barcode บาร์โค้ด
  • plastic bag ถุงพลาสติก
  • frozen แช่แข็ง
  • expiry date วันหมดอายุ
  • fresh market ตลาดสด
  • instant noodles บะหมี่กึ่งสำเร็จรูป / มาม่า
  • shampoo แชมพู / ยาสระผม
  • soap สบู่

แกดเจ็ตไอที · Gadgets

  • mobile phone โทรศัพท์มือถือ
  • charger สายชาร์จ / ที่ชาร์จ
  • battery แบตเตอรี่
  • power bank พาวเวอร์แบงก์ / แบตสำรอง
  • warranty การรับประกัน
  • model รุ่น (สินค้า)
  • screen หน้าจอ
  • memory หน่วยความจำ / เมมโมรี่
  • wireless ไร้สาย
  • gadget แกดเจ็ต / อุปกรณ์ไอทีชิ้นเล็ก
  • accessory อุปกรณ์เสริม
  • phone case เคสมือถือ
  • earbuds หูฟังไร้สายแบบใส่ในหู
  • smartwatch นาฬิกาอัจฉริยะ / สมาร์ทวอทช์

  • coupon คูปอง
  • out of stock สินค้าหมด
