การผลิตและคุณภาพ · Manufacturing & Quality

  • manufacture ผลิต(ในโรงงาน)
  • assembly line สายการประกอบ
  • inspect ตรวจสอบอย่างละเอียด
  • defect ข้อบกพร่อง / ตำหนิ(ในสินค้า)
  • durable ทนทาน
  • raw material วัตถุดิบ
  • machinery เครื่องจักร(โดยรวม)
  • output ผลผลิต / ปริมาณที่ผลิตได้
  • standard มาตรฐาน
  • malfunction ทำงานผิดปกติ / ขัดข้อง
  • efficient มีประสิทธิภาพ(ไม่สิ้นเปลือง)
  • shortage การขาดแคลน(สินค้า/แรงงาน)
  • component ชิ้นส่วนประกอบ
  • recall เรียกคืนสินค้า

ขนส่งและโลจิสติกส์ · Shipping & Logistics

  • freight สินค้าขนส่ง / ค่าระวาง
  • cargo สินค้าบรรทุก(บนเรือ/เครื่อง)
  • dispatch จัดส่งออกจากคลัง
  • courier บริษัทขนส่งพัสดุด่วน
  • tracking number หมายเลขติดตามพัสดุ
  • consignment สินค้าที่ส่งเป็นล็อต
  • distribute กระจายสินค้า / แจกจ่าย
  • in transit อยู่ระหว่างขนส่ง
  • fragile แตกง่าย / เปราะบาง
  • customs clearance พิธีการศุลกากร
  • load บรรทุก / ขนของขึ้น
  • expedite เร่งดำเนินการ
  • lead time ระยะเวลารอสินค้า
  • bulk จำนวนมาก / ล็อตใหญ่

อสังหาฯ และอาคารสถานที่ · Real Estate & Facilities

  • commercial เชิงพาณิชย์ / เพื่อการค้า
  • occupancy การเข้าใช้พื้นที่ / อัตราการเข้าพัก
  • ventilation การระบายอากาศ
  • property อสังหาริมทรัพย์ / ทรัพย์สิน
  • facility สิ่งอำนวยความสะดวก / อาคารสถานที่
  • renovate ปรับปรุงซ่อมแซม(อาคาร)
  • floor space พื้นที่ใช้สอย
  • square meter ตารางเมตร
  • premises บริเวณสถานที่(ของบริษัท/ร้าน)
  • spacious กว้างขวาง
  • relocate ย้ายที่ตั้ง
  • plumbing ระบบประปา
  • real estate agent นายหน้าอสังหาริมทรัพย์
  • vacant ว่าง(ไม่มีคนอยู่/ใช้)

คำสั่งซื้อและใบแจ้งหนี้ · Orders & Invoices

  • purchase order ใบสั่งซื้อ
  • quotation ใบเสนอราคา
  • place an order สั่งซื้อสินค้า
  • merchandise สินค้า(ที่วางขาย)
  • retailer ผู้ค้าปลีก
  • payment terms เงื่อนไขการชำระเงิน
  • wire transfer การโอนเงินผ่านธนาคาร
  • prepaid ชำระล่วงหน้าแล้ว
  • discrepancy ความไม่ตรงกัน(ของตัวเลข)
  • surcharge ค่าธรรมเนียมเพิ่ม
  • net สุทธิ(หลังหักแล้ว)
  • itemized แยกรายการ(ทีละชิ้น)
  • backorder สินค้าสั่งจองรอของเข้า
  • remit ส่งเงินชำระ

นโยบายและกฎระเบียบ · Policies & Regulations

  • policy นโยบาย
  • guideline แนวทางปฏิบัติ
  • mandatory บังคับ / ต้องทำ
  • compliance การปฏิบัติตามกฎ
  • violation การฝ่าฝืน / ละเมิด
  • restrict จำกัด / ควบคุมไม่ให้เกิน
  • code of conduct จรรยาบรรณ / ระเบียบความประพฤติ
  • impose กำหนด(ภาษี/ค่าปรับ)ให้ต้องรับ
  • liability ความรับผิด(ตามกฎหมาย) / หนี้สิน
  • strictly อย่างเคร่งครัด
  • exempt ได้รับยกเว้น
  • sanction มาตรการลงโทษ
  • disclose เปิดเผย(ข้อมูล)
  • in accordance with ตามที่กำหนดใน

สื่อและอีเวนต์ · Media & Events

  • fundraiser งานระดมทุน
  • journalist นักข่าว
  • editorial บทบรรณาธิการ
  • circulation ยอดจำหน่าย(หนังสือพิมพ์)
  • coverage การรายงานข่าว / ความครอบคลุม
  • exhibitor ผู้ออกบูธแสดงสินค้า
  • commemorate จัดงานรำลึก / ฉลองวาระ
  • broadcast ออกอากาศ / แพร่ภาพ
  • press conference การแถลงข่าว
  • catering บริการจัดเลี้ยง

คำเชื่อมและกริยาทางการ · Connectors & Formal Verbs

  • meanwhile ในขณะเดียวกัน
  • implement นำไปปฏิบัติ / เริ่มใช้จริง
  • accommodate รองรับ(จำนวน/ความต้องการ)
  • ensure ทำให้แน่ใจว่า / รับรองว่า
  • acquire ได้มา / ซื้อกิจการ
  • anticipate คาดการณ์ล่วงหน้า
  • accordingly ตามนั้น / อย่างสอดคล้องกัน
  • nevertheless ถึงกระนั้นก็ตาม
