ศัพท์ภาษาอังกฤษหมวดไอทีและโปรแกรมมิ่ง

ศัพท์สายไอที ซอฟต์แวร์ คลาวด์ ความปลอดภัย และการพัฒนาแอป ที่ใช้ในที่ทำงานยุคใหม่ รวม 98 คำ ใน 7 บทเรียน ทุกคำมีคำอ่านไทย เสียงเจ้าของภาษา ตัวอย่างประโยค และจุดที่คนไทยพลาดบ่อย · หมวดนี้เป็นเวิลด์ JUNYPOP Plus: บทที่ 1 เล่นฟรี ที่เหลือสำหรับสมาชิก

เริ่มแบบทดสอบ

คำศัพท์ทั้งหมดในหมวดนี้

อุปกรณ์และเครือข่าย · Devices & Networks

  • hardware ฮาร์ดแวร์ / อุปกรณ์คอมพิวเตอร์
  • device อุปกรณ์ / เครื่อง
  • network เครือข่าย
  • router เราเตอร์ / ตัวกระจายสัญญาณ
  • modem โมเด็ม
  • cable สายเคเบิล / สายไฟ
  • port ช่องเสียบ / พอร์ต
  • bandwidth แบนด์วิดท์ / ความกว้างช่องสัญญาณ
  • hotspot ฮอตสปอต / จุดแชร์เน็ตจากมือถือ
  • Bluetooth บลูทูธ
  • USB ยูเอสบี / แฟลชไดรฟ์
  • hard drive ฮาร์ดดิสก์ / ที่เก็บข้อมูลในเครื่อง
  • processor หน่วยประมวลผล / ซีพียู
  • Ethernet อีเทอร์เน็ต / เน็ตแบบสาย LAN

ซอฟต์แวร์และแอป · Software & Apps

  • software ซอฟต์แวร์ / โปรแกรม
  • app แอปพลิเคชัน
  • operating system ระบบปฏิบัติการ
  • interface หน้าจอการใช้งาน / ส่วนติดต่อผู้ใช้
  • version เวอร์ชัน / รุ่น
  • feature ฟีเจอร์ / ฟังก์ชันการใช้งาน
  • compatible ใช้ร่วมกันได้ / รองรับ
  • default ค่าเริ่มต้น / ค่าตั้งต้น
  • plugin ปลั๊กอิน / ส่วนเสริมโปรแกรม
  • sync ซิงก์ / ทำให้ข้อมูลตรงกันทุกเครื่อง
  • permission สิทธิ์การเข้าถึง / การอนุญาต
  • open source โอเพนซอร์ส / เปิดโค้ดให้ใช้ฟรี
  • upgrade อัปเกรด / เปลี่ยนเป็นรุ่นดีขึ้น
  • user-friendly ใช้งานง่าย

เขียนโค้ดเบื้องต้น · Coding Basics

  • code โค้ด / ชุดคำสั่งโปรแกรม
  • bug บั๊ก / ข้อผิดพลาดในโปรแกรม
  • debug ดีบั๊ก / ไล่หาและแก้บั๊ก
  • deploy ดีพลอย / นำระบบขึ้นใช้งานจริง
  • developer นักพัฒนาโปรแกรม / โปรแกรมเมอร์
  • variable ตัวแปร
  • function ฟังก์ชัน / ชุดคำสั่งที่เรียกใช้ซ้ำได้
  • loop ลูป / การวนซ้ำ
  • syntax ไวยากรณ์ของภาษาโปรแกรม
  • compile คอมไพล์ / แปลงโค้ดให้เครื่องรันได้
  • command คำสั่ง (ที่พิมพ์ให้เครื่องทำ)
  • framework เฟรมเวิร์ก / โครงสำเร็จรูปสำหรับเขียนโปรแกรม
  • repository ที่เก็บโค้ดของโปรเจกต์
  • front end ฝั่งหน้าบ้าน / ส่วนที่ผู้ใช้เห็น

ข้อมูลและคลาวด์ · Data & Cloud

  • database ฐานข้อมูล
  • cloud คลาวด์ / เก็บข้อมูลบนอินเทอร์เน็ต
  • backup ข้อมูลสำรอง
  • data center ศูนย์ข้อมูล / ตึกเก็บเซิร์ฟเวอร์
  • spreadsheet ตารางคำนวณ (Excel)
  • dashboard แดชบอร์ด / หน้าสรุปข้อมูล
  • analytics การวิเคราะห์ข้อมูล / สถิติการใช้งาน
  • storage พื้นที่เก็บข้อมูล
  • API ช่องทางให้โปรแกรมคุยกัน
  • query คำสั่งค้นหาข้อมูล
  • big data บิ๊กดาต้า / ข้อมูลมหาศาล
  • cache แคช / ข้อมูลที่เก็บไว้ให้โหลดเร็ว
  • real-time แบบทันที / ตามเวลาจริง
  • archive เก็บเข้าคลัง / ย้ายไปเก็บถาวร

ความปลอดภัยไซเบอร์ · Cybersecurity

  • cybersecurity ความปลอดภัยไซเบอร์
  • hacker แฮกเกอร์ / ผู้เจาะระบบ
  • malware มัลแวร์ / โปรแกรมประสงค์ร้าย
  • virus ไวรัสคอมพิวเตอร์
  • firewall ไฟร์วอลล์ / กำแพงกันผู้บุกรุก
  • encrypt เข้ารหัสข้อมูล
  • data breach ข้อมูลรั่วไหล
  • authentication การยืนยันตัวตน
  • ransomware มัลแวร์เรียกค่าไถ่
  • patch แพตช์ / ตัวแก้ช่องโหว่
  • vulnerability ช่องโหว่ / จุดอ่อนของระบบ
  • antivirus โปรแกรมป้องกันไวรัส
  • VPN เครือข่ายส่วนตัวเสมือน / อุโมงค์เน็ตที่ปลอดภัย
  • access สิทธิ์เข้าใช้ / การเข้าถึง

AI และระบบอัตโนมัติ · AI & Automation

  • artificial intelligence ปัญญาประดิษฐ์ (AI)
  • chatbot แชตบอต / โปรแกรมตอบแชตอัตโนมัติ
  • machine learning การเรียนรู้ของเครื่อง
  • prompt พรอมต์ / คำสั่งที่พิมพ์บอก AI
  • automation ระบบอัตโนมัติ
  • automate ทำให้เป็นอัตโนมัติ
  • generate สร้างขึ้น (โดยโปรแกรม/AI)
  • bot บอต / โปรแกรมทำงานแทนคน
  • workflow ขั้นตอนการทำงาน / ลำดับงาน
  • dataset ชุดข้อมูล (สำหรับสอน AI)
  • predict ทำนาย / คาดการณ์
  • deepfake ดีปเฟก / วิดีโอปลอมที่ AI สร้าง
  • accuracy ความแม่นยำ
  • voice assistant ผู้ช่วยสั่งงานด้วยเสียง

ซัพพอร์ตและแก้ปัญหา · IT Support

  • troubleshoot ไล่หาสาเหตุปัญหา / แก้ปัญหาทีละขั้น
  • crash โปรแกรมเด้ง / ล่มกะทันหัน
  • freeze ค้าง / หน้าจอไม่ขยับ
  • reboot บูตเครื่องใหม่
  • glitch ข้อผิดพลาดชั่วคราว / อาการรวน
  • factory reset ล้างเครื่องกลับเป็นค่าโรงงาน
  • error ข้อผิดพลาด (ข้อความแจ้งเตือน)
  • help desk ฝ่ายช่วยเหลือไอที
  • reset รีเซ็ต / ตั้งค่าใหม่
  • technician ช่างเทคนิค
  • downtime ช่วงที่ระบบใช้งานไม่ได้
  • workaround วิธีแก้ชั่วคราว / ทางเลี่ยงปัญหา
  • overheat เครื่องร้อนเกินไป
  • corrupted ไฟล์เสีย / เปิดไม่ได้
